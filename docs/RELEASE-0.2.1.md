# 0.2.1 — Android 업데이트 자동 확인

앱을 실행하면 로그인 전에도 병원 서버에서 배포 정보를 확인합니다. 설치된 Android 버전 코드보다 새 버전일 때만 안내합니다. 앱을 계속 켜 두면 화면이 보이는 동안 15분 간격으로 재확인하며, 인터넷 연결 복구와 앱 복귀 시에도 확인합니다(최근 확인 후 15분 이내는 생략).

- ‘업데이트 설치’: 상담을 저장했는지 확인한 뒤 APK를 다운로드하고 SHA-256을 검증하여 Android 설치 화면을 엽니다. 설치 승인까지 자동으로 누르지는 않습니다.
- ‘나중에’: 현재 실행 중에는 같은 버전 안내를 숨깁니다. 앱을 완전히 종료했다 다시 열면 다시 안내합니다. 상단 ‘업데이트’ 버튼으로 언제든 수동 재확인할 수 있습니다.
- 저장 처리·대기 동기화·사진 업로드 중에는 설치를 차단합니다. 그 외 아직 저장하지 않은 입력은 설치 전 사용자가 저장해야 합니다.
- 자동 확인의 네트워크 오류는 상담을 방해하지 않습니다. 수동 확인에서는 오류를 표시하고 재시도할 수 있습니다.
- 같은 버전/이전 버전에는 설치 안내를 하지 않습니다. 다운로드된 파일도 코디메이트 패키지이며 더 높은 버전 코드인지 확인합니다.
- 웹용 서비스 워커와 Android APK 업데이트를 분리했습니다. 이전 APK의 웹 코드 캐시가 남아 있으면 제거하고 내장 코드를 다시 엽니다. IndexedDB 초안·로그인 설정·Keystore는 지우지 않습니다.

## 기존 앱에서 시작하기

0.2.0 사용자는 로그인 후 상단 **업데이트** 버튼으로 0.2.1을 받거나 [APK 링크](https://raw.githubusercontent.com/peppermint1231/grand-codimate-web/main/releases/codimate-0.2.1.apk)로 설치합니다. 기존 앱을 삭제하지 않습니다. 자동 확인은 0.2.1 설치 후부터 동작합니다.

## 배포 정보

`releases/android-latest.json`에는 최신 APK의 버전·버전 코드·HTTPS 주소·SHA-256·변경 내용만 둡니다. APK 생성/서명 검증 후 이 파일을 갱신해 서버와 같이 배포합니다. 정적 APK는 `releases/`에 보관하고 `public/`에는 넣지 않습니다.

`GET /api/app-release`는 로그인 없이 공개 배포 정보만 반환하고 캐시하지 않습니다. 기존 앱의 `GET /api/update`도 같은 최신 정보를 반환합니다. 관리자 설정에서 더 높은 버전을 게시하면 우선 사용합니다. 게시 POST는 계속 관리자 인증과 기존 OneDrive 기록을 요구합니다. 환자·계정 정보와 게시자 식별자는 공개하지 않습니다.

버전: 0.2.1 / versionCode 4. 기존 앱과 서명 키가 같습니다.

## 검증

- 자동 테스트 39개 및 TypeScript·웹 빌드.
- 브라우저의 Android 브리지 모의 시험: 시작 안내, 미루기, 수동 재확인, 설치 취소, 대기 저장 차단, 설치 권한 오류 후 재시도, URL/해시 전달, 동일·구버전 안내 제외, 네트워크 복구, 잘못된 배포 정보 차단.
- APK 빌드·서명 인증서 일치·내장 웹 파일 일치 확인.
- 실제 Android 설치 확인 화면과 기기별 설치 권한 절차는 실기기 확인이 필요합니다.

## 사용자 확인

- [ ] 0.2.0에서 상단 업데이트 버튼으로 0.2.1 설치 화면이 열린다.
- [ ] 0.2.1을 설치한 뒤 앱을 열면 같은 버전 안내가 반복되지 않는다.
- [ ] 상단 업데이트 버튼을 누르면 현재 버전과 새 업데이트 없음이 표시된다.
- [ ] 이후 더 높은 버전 게시 시 앱을 다시 열면 안내된다.
- [ ] 나중에를 누르면 상담을 계속할 수 있고 수동 확인으로 다시 안내를 열 수 있다.
- [ ] 사진 전송 중에는 설치가 차단된다. 상담 저장 후 설치할 수 있다.
