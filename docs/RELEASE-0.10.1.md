# 0.10.1 — 상품 관리·편집 취소·의견 요청 사진

단가표 편집 중 각 상품 행의 **삭제**, 상품 편집 창의 **상품 삭제**를 사용할 수 있습니다. 여러 상품을 체크하면 **선택 상품 삭제 (개수)** 버튼으로 함께 삭제합니다. 확인 창에 삭제할 상품 이름과 옵션 개수를 표시하며, 삭제 후 선택을 해제합니다. 필터로 보이지 않게 된 선택 상품도 선택 개수와 삭제 확인 대상에 포함됩니다.

상품 목록에서는 **Delete**로 선택 상품을, 상품 편집 창에서는 **Delete**로 현재 상품을 삭제합니다. 글자 입력 중에는 문자 삭제가 우선입니다. 편집 화면의 **?** 배지에서 단축키를 확인할 수 있습니다.

삭제는 편집 중인 초안에 먼저 적용합니다. 저장 전에는 **되돌리기/다시 실행**(Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z 또는 Ctrl+Y)을 사용할 수 있습니다. **초안 저장** 후 수정 이력에 삭제한 상품 이름이 남으며, **검증 후 게시**해야 상담·추천기에 적용됩니다. 기존 상담과 이전 게시본은 보존됩니다. 링크로 공유된 상품은 원본 상품이 삭제되므로 연결된 폴더에서도 사라집니다.

검색 기본값은 **폴더명 + 상품명**입니다. 검색 대상에서 **폴더명만**, **상품명만**으로 전환할 수 있습니다. 폴더 검색은 상위·하위 경로 및 링크 폴더 경로를 포함합니다. 상품명 검색은 상품 이름만 대조합니다. 검색어의 공백·영문 대소문자는 구분하지 않습니다. 폴더를 선택한 상태에서는 그 폴더 안을 검색하며, 검색창 아래 **전체 폴더에서 검색**으로 범위를 넓힐 수 있습니다.


## 편집 취소

상단 **초안 저장** 옆의 **편집 취소**로 저장하지 않은 변경을 버리고 마지막 저장 상태로 돌아갑니다. 변경이 있으면 취소 확인을 거칩니다. 취소하면 수정 모드를 종료하며 **단가표 수정**으로 다시 시작합니다. 상품 목록의 Alt+Escape도 같은 취소 기능입니다.

## 의견 요청 사진과 상담 연결

의견 요청 카드에 환자 이름, 상담자, 요청자, 상담 구분·날짜와 **해당 상담 열기**를 표시합니다. 상담의 모든 사진(비선택 사진 포함)을 썸네일로 보여주며 클릭하면 크게 볼 수 있습니다. 담당 의사 또는 관리자는 **편집**으로 전체화면 주석 편집기를 바로 열 수 있습니다.

**사진 편집 저장**은 해당 상담에 내 주석을 저장합니다. 사진 원본·회전/자르기·다른 작성자의 주석은 유지합니다. 다른 기기에서 상담이 수정되면 충돌을 표시하고 재확인을 요구합니다. 확정/취소 상담에서는 요청 사진을 조회할 수 있고 새 의견 주석을 저장하지 않습니다. 기존 의견 작성칸을 유지하며 사진 편집 중에도 작성하던 답변이 남아 있습니다. 사진 주석과 텍스트 답변은 각각 저장합니다.
