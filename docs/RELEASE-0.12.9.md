# 0.12.9 · 병원 확정 연락처 반영

사용자가 확정한 병원명·대표전화·주소·진료시간·평일 점심시간·휴일 및 진료시간 외 상담 미운영 문구를 동의서 본문과 도움말에 반영했다. 연락처에는 추가 검토를 요구하지 않으며 시술별 미확정 항목은 유지한다.

운영 최신 미게시 임상 초안 13개에서 연락처 표식만 변경했다. 직접 수정·게시한 8개 양식, 이전 초안, 계약 안내, 서명 및 다른 업무 데이터는 보존했다. 병원 원문의 주의사항 누락 대조는 별도 감사 결과로 기록했고, 이 버전에서 의료 주의사항을 다시 작성하거나 자동 게시하지 않았다.

검증: 45개 테스트 파일·290개 테스트 및 웹 빌드 통과. 1440/768/390px 브라우저에서 확정 연락처, 남은 시술별 검토, 편집·게시·복제 흐름과 가로 넘침을 확인했다.
