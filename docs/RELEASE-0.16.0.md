# 0.16.0 — VIP 환자용 조회 QR

- 환자 상세 → VIP·포인트 → 환자용 VIP 조회 QR에서 생성·다시 보기·재발급·폐기, 링크 복사, 환자 화면 열기를 제공합니다.
- 사용자 요청대로 유효기간 없음. 같은 QR의 매 조회마다 서버의 현재 잔액, 승급일, 기간별 이용 실적·추가 적립까지 남은 금액, 혜택, 최근 20건의 포인트 내역을 표시합니다. 휴대폰에서 로그인 없이 확인하고 새로고침할 수 있습니다.
- 이름은 마스킹하며 시술·사진·연락처·직원 메모·조정 사유·소개 환자의 신원은 응답에 포함하지 않습니다. 조회 시각과 실제 수납/환불 기준, 포인트 결제 및 최초 승급 수납 제외를 안내합니다.
- 256비트 무작위 토큰, 저장 시 토큰 해시 색인 및 암호화된 발급 기록, no-store/noindex/no-referrer/CSP 응답을 사용합니다. QR 관리에는 금액 열람·내보내기 권한이 필요합니다. 발급자 비활성화/권한 회수, 환자 삭제·병합, VIP 계정 소멸, 복구 진행 시 조회를 차단합니다.
- 환자별 활성 링크는 하나이며 재발급·폐기 즉시 이전 QR을 무효화합니다. 재구축·복구 시 기존 조회 링크도 폐기됩니다. 조회 링크는 원본 재구축 대상 임상 자료에 포함되지 않습니다. 관리 작업은 감사 기록을 남깁니다.
- 신규 서버 검증 6개 포함 전체 404개 테스트·프로덕션 빌드 통과. 1440/768/390px에서 직원 QR 생성·재발급·폐기와 환자 화면 표시·넘침 여부 확인.
- Android 0.16.0 (67), 18,388,407바이트. 웹 자산 48개 일치. SHA-256 `d74214f3d2249f58cc807c0f51551e22608c4c5c61dbd6b48c9b371c51eb26f1`.
