# 0.9.1 · 홈페이지 이벤트 SSOT 갱신

단가표 관리 → 이벤트 SSOT → **이벤트 단가표 갱신**에서 병원 홈페이지 자료를 가져옵니다.

1. 배너명 **또는 분류명**에 ‘이벤트’가 있는 항목만 가져옵니다. ‘추석맞이 한가위 이벤트’ 안의 ‘한가위 핫딜’ 같은 세부 배너도 포함합니다. 일반 미용 가격표는 제외하며 미용·보험 SSOT는 수정하지 않습니다.
2. 신규·변경·동일·원문 제외·기간 종료 수와 가져온 내용을 확인하고 **갱신 초안 저장**을 누릅니다.
3. 가격·부가세·판매 조건을 검토하고 판매 활성화 후 **검증 후 게시**를 누르면 상담·맞춤 시술 찾기에 반영됩니다. 가격이 검토되지 않은 새 상품은 자동 게시하지 않습니다.

가져오는 항목은 시술명·설명, 이벤트 기간, 정가, 홈페이지에 표시된 할인율, 할인가, 출처 주소, 포스터 주소입니다. 목록의 ‘~원부터’ 가격 대신 상세 페이지의 개별 상품 가격을 사용합니다. 정가·할인율이 원문에 없으면 임의로 계산해 넣지 않습니다. 범위 가격·상담가는 미확정으로 남기고, 부가세는 상품 또는 이벤트 설명의 명시적인 표기만 따릅니다. 표기가 없으면 항목별 확인 대상입니다.

포스터 파일을 서버·OneDrive·APK에 복사하지 않습니다. 홈페이지 이미지 URL을 저장하고 화면에서 직접 불러옵니다. 상품 상세에서 포스터를 펼치거나 원본 링크를 열 수 있습니다. 홈페이지가 링크를 변경·삭제하면 다음 갱신이 필요할 수 있습니다.

상품 목록·상세·상담 선택 화면에 기간, 취소선 정가, 할인율, 할인가를 표시합니다. 상담에는 SSOT의 적용 가격을 사용하고, 직접 수정해 원문 할인가와 달라졌다면 별도로 표시합니다. 공개·검토된 이벤트는 맞춤 시술 찾기에도 기간·가격을 표시합니다. 시작 전·기간 종료·홈페이지 제외 상품은 새 상담 선택에서 제한하고 기존 상담의 저장된 견적은 보존합니다.

홈페이지 이벤트 ID·상품 ID를 기준으로 중복 생성을 방지합니다. 원문이 동일하면 검토 상태·개별 수정·폴더 배치·공개 여부를 유지합니다. 원문이 변경되면 새 가격을 검토할 수 있도록 비활성 초안으로 갱신합니다. 홈페이지에서 사라진 상품은 삭제 대신 비활성화하며 수동 등록 상품은 보존합니다. 변경 전·후는 기존 수정 이력에서 확인하고 복원할 수 있습니다.

단가표 관리 권한이 있는 계정만 가져오기·저장을 할 수 있습니다. 수집 중 오류·형식 변경·빈 응답이 있으면 일부 결과로 SSOT를 덮어쓰지 않습니다. 편집 중에는 먼저 저장/취소해야 하며 다른 기기에서 기준 단가표가 바뀌었으면 다시 갱신하도록 안내합니다.

검증: 155개 자동 테스트, 실제 홈페이지 수집 및 로컬 앱 초안 저장, 일반 단가표·상담 보존, 이력 기록, 포스터 원격 표시, 모바일 가로 넘침 검사. 2026-09-22 확인 시 대상은 14개 배너·162개 상품입니다. 홈페이지 변경에 따라 수는 달라집니다.
