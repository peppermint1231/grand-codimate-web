# 0.10.2 — 의사 답변 알림·상담이력·메모 저장

- 의사 답변이 저장되면 요청자와 상담 담당자에게 상단 새 답변 안내와 종 숫자가 표시됩니다. **답변 확인**을 누르면 해당 요청으로 이동하고 본인 계정의 읽음 상태를 저장합니다.
- 종 목록은 전체 요청·답변 / 새 답변 / 내 답변 대기로 구분됩니다. 목록의 **새 답변 · 읽음 표시**로도 확인할 수 있습니다. 답변을 수정하면 다시 알림이 표시되며, 사진 주석 저장만으로는 답변 알림이 반복되지 않습니다.
- 상담이력의 사진 행 아래에 **의사 의견 N건 · 펼치기**가 표시됩니다. 기본은 접혀 있고, 펼치면 담당 의사·답변 시각·요청과 답변을 볼 수 있습니다. 해당 상담이력을 보는 다른 직원도 열람할 수 있으며, 답변이 없는 상담은 이 영역을 생략합니다.
- 02 상담의 메모 입력칸 아래에 **상담메모 저장** 버튼을 추가했습니다. 기존 상담 저장과 동일하게 메모·사진·장바구니의 현재 변경사항을 함께 저장하며 기존 권한·충돌·확정 상담 변경 사유 검사를 유지합니다.

알림은 앱 화면이 열려 있고 온라인일 때 15초 간격 및 화면 복귀 시 갱신됩니다. 앱을 닫은 상태의 OS 푸시는 포함하지 않습니다. 의견만 조회하는 경량 API를 사용해 상담 작성 중에도 입력 내용을 건드리지 않고 새 답변을 가져옵니다. 읽음 표시는 계정별로 OneDrive의 기존 암호화 저장 흐름을 따릅니다.

자동 테스트 184개 통과. 화면에서 답변 도착·요청 이동·계정별 읽음·수정 답변 재알림·폴링과 읽음 저장 중 메모 유지·다른 직원의 접힌 이력 열람·메모 저장·모바일 표시를 확인했습니다. 기존 의사 주석 및 답변 저장도 회귀 검증했습니다.
