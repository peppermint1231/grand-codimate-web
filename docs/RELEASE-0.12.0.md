# 0.12.0 · 항목별 할인·임의 가격·공통 사유·의사 직접 의견

장바구니와 견적서의 항목별 금액을 동일한 계산으로 표시합니다. 상품 할인, 항목별 추가 할인, 전체 할인 배분과 최종 할인가가 화면·병원용 PDF·환자용 JPG에 표시됩니다. 전체 할인은 항목별 남은 금액 비율로 배분하며 1원 반올림 오차도 기존 총액 계산과 동일하게 처리합니다.

장바구니 항목의 **임의 가격**을 체크하면 단가 입력이 활성화됩니다. 체크하지 않았을 때는 입력할 수 없고 기존 상품 단가를 사용합니다. 체크를 해제하면 원래 단가로 복귀합니다. 수량과 부가세 기준은 유지하며, 입력 단가에 기존 항목 할인·전체 할인을 순서대로 적용합니다. 서버에도 금액·사유 검증을 적용했습니다. 새 연장상담은 최신 SSOT 단가를 사용하므로 이전 임의 가격은 자동 승계하지 않습니다.

견적서에는 책정한 금액과 실제 할인만 표시하며 **임의 가격 표시와 내부 책정 사유는 출력하지 않습니다**. 사유와 원래 단가/책정 단가는 상담 데이터에 보관됩니다. 기존 상담의 금액이나 원본 SSOT 단가는 변경하지 않습니다.

**자주 쓰는 사유** 드롭다운은 모든 계정의 저장된 상담을 집계하여 빈도순 상위 10개를 표시합니다. 같은 상담에서 같은 사유는 한 번 집계하여 메모만 반복 저장해도 빈도가 늘지 않습니다. 앞뒤/연속 공백은 정리하고 동률은 이름순입니다. 기존 상담의 현재 사유를 바로 활용하며, 이번 버전부터 변경 전 사유도 상담 내부 이력에 보존합니다. 직접 입력도 가능합니다. 금액 열람 권한이 없는 계정에는 사유 목록/새 사유 이력을 제공하지 않습니다.

상담메모가 있으면 메모 버튼에 점이 부드럽게 움직입니다. 동작 줄이기 설정에서는 정지 표시합니다. 의사 역할 계정에는 **의견 달기** 버튼이 추가됩니다. 요청 없이 전체 의견 또는 사진별 코멘트를 저장할 수 있으며 상담 사진 아래의 접힌 의사 의견에 연결됩니다. 사진을 재배치하면 사진 번호도 변경됩니다. 상담자는 기존 새 답변 알림으로 확인합니다. 보류·확정 상담 모두 직접 의견을 남길 수 있으며 취소된 상담에는 추가할 수 없습니다. 미저장 사진/상담 변경은 먼저 저장해야 합니다. 직접 의견은 금액이나 상담 확정 상태를 변경하지 않습니다.

검증: 금액 계산, 원단가 보존/복귀, 사유 필수, 공통 사유 순위·권한, 의사 역할·취소/버전 충돌·사진 참조, 확정 상담의 금액 보존 자동 테스트. 합성 브라우저에서 장바구니, PDF/JPG 금액과 내부 사유 제외, 메모 표시, 요청 없는 의견, 사진 재배치·상담자 알림 및 360/390/768/1440px 화면을 확인했습니다. 실제 Android·프린터는 연결되지 않아 물리 동작 검증은 별도입니다.

배포 완료: 웹·APK 0.12.0/versionCode41. 자동 테스트 269개 및 웹·Android 빌드 통과. 운영 장바구니 입력/사유 목록 확인, 웹·APK 파일48개 및 공개 다운로드 일치. 운영 확인 중 업무 자료 쓰기0건, 기존 전체 State 해시 동일.
