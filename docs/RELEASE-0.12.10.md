# 0.12.10 · 병원 원문 누락 주의사항 보완

기존 양식에서 빠지거나 지나치게 축약된 세안·화장, 음주·흡연, 사우나·수영·운동, 마사지·접촉, 보습·자외선 차단, 드레싱·두피 관리, 회복 경과·리터치 설명을 해당 시술별로 보완했다. 이소트레티노인의 피임 방법·검사·남은 약 처리 설명과 계약 안내의 원문 운영 기준 참고도 보충했다. 해당 원문이 없는 정맥 주사에는 얼굴 시술 주의사항을 전용하지 않는다.

원문 기간·횟수는 ‘병원 원문 참고 · 기간 확인 필요’ 도움말에 보존한다. 환자 본문에는 행동 안내와 검토 표식을 넣고, 제품·장비·부위별 기간과 예외를 작성하기 전 게시를 차단한다. 원문의 무조건 장기 드레싱 유지·덧붙이기, 회복 보장, 포괄 책임 면제·정액 환불은 그대로 복원하지 않는다. 출처: 병원 제공 DOCX, 기존 양식별 AAD/FDA/ASPS 자료 및 식약처 이소트레티노인 안전사용 안내.

병원에서 작성한 본문·양식명·확인란·상품 연결을 유지하며 추가 항목만 합성한다. 현재 미게시 초안은 업데이트하고, 게시본은 별도 개정 초안으로 만든다. 기존 게시본과 환자 서명은 변경하지 않는다. 반복 실행 시 중복 추가하지 않으며 옛 초안은 이력으로 보존한다. 화면에서 ‘보완 개정 초안 있음’과 ‘게시본을 보완한 개정 초안’을 구분한다.

검증: 46개 테스트 파일·294개 테스트, 웹 빌드, 1440/768/390px 브라우저 통과. 기존 병원 수정 보존·게시본 불변·초안 갱신·중복 실행·미확정 게시 차단 및 원문 참고값/환자 본문 분리를 확인했다.
