# 0.12.8 · 병원 안내 이미지 기반 연락처 예시 보충

사용자가 제공한 병원 안내 이미지의 그랜드아름다운의원, 대표전화 1899-5109, 강원특별자치도 춘천시 중앙로 68 4층, 월~금 10:00~20:00·토요일 09:00~15:00(점심시간 없음)을 동의서 검토 도움말의 연락처 예시에 반영했다.

이미지에 없는 일요일·공휴일 운영, 진료시간 외 연락·응답 방법, 계약 문의 접수시간·정산 처리기한은 확인 항목으로 유지한다. 토요일 뒤에 표기된 점심시간 안내를 평일에 확대 적용하지 않는다. 기존 초안·게시본·서명은 변경하지 않는다.

검증: 44개 테스트 파일·288개 테스트 및 웹 빌드 통과. 1440/768/390px 브라우저에서 실제 전화·진료시간과 미확정 휴일 표식 표시, 예시/본문 분리·본문 보존·게시 검증·가로 넘침 없음을 확인했다. APK 빌드·기존 인증서 서명 검증 및 내장 웹 파일 48개 일치 확인.
