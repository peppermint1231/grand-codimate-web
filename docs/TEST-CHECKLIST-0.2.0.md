# 코디메이트 0.2.0 사용자 테스트 체크리스트

작성일: 2026-09-19 · 대상: PC 웹 / Android APK 0.2.0

웹: https://grand-codimate.peppermint-3.workers.dev/

각 항목은 **동작과 저장된 결과까지 맞을 때** 체크합니다. 실패하면 번호와 재현 순서를 기록합니다. 실행하지 못한 항목은 ‘미확인’으로 남깁니다.

## 준비

- 검사자 / 날짜: ____________________
- 기기 / 운영체제 / 브라우저: ____________________
- 사용 계정 역할: 직원 / 관리자 / 의사
- 실제 환자 대신 `테스트남`, `테스트여` 환자를 사용합니다. 사진은 얼굴 정보가 없는 테스트 사진을 준비합니다.
- 서로 구분되는 사진 5장, 실제 태블릿으로 찍은 고해상도 사진, 촬영 시각을 아는 JPEG 1장을 준비합니다.
- 별도 PC 또는 태블릿 1대와 병원 OneDrive를 열어 둡니다.
- 열려 있던 상담을 저장한 뒤 모든 코디메이트 탭을 닫고 다시 접속합니다. APK는 기존 앱 위에 0.2.0을 설치합니다.
- 성공/실패 확정 시험은 관리자 수정이 필요한 상태를 만들므로 테스트 상담에서 진행합니다. 테스트 상담은 통계에도 반영될 수 있습니다.

## 1. 먼저 할 핵심 시험 — 약 15~20분

이 구간이 모두 통과하면 아래 상세 시험으로 넘어갑니다.

- [ ] **A01 주소 검색:** 환자 등록 → 주소 검색 → 도로명 또는 지번 검색 → 결과 선택. 주소가 동·읍·면까지 채워지고 환자 저장·재열람 후에도 유지된다.
- [ ] **A02 사진 추가:** 첫 상담에 서로 다른 사진 5장을 한 번에 추가한다. 파일명과 썸네일이 표시되고, 업로드 중에도 화면을 조작할 수 있다. 미리보기까지 ___초 / 업로드 완료까지 ___초.
- [ ] **A03 선택과 비교:** 썸네일을 눌러 5장을 선택한다. 선택 사진이 비교 화면에 나타나며, 다시 누른 사진은 비교·출력 대상에서 빠진다.
- [ ] **A04 배치:** 아래 1~4열 배치가 맞다. 사진 손잡이를 끌어 순서를 바꾸면 비교 화면 순서도 바뀐다.

  | 열 수 | 사진 5장의 행별 개수 |
  |---|---|
  | 1열 | 1 / 1 / 1 / 1 / 1 |
  | 2열 | 2 / 2 / 1 |
  | 3열 | 3 / 2 |
  | 4열 | 4 / 1 |

- [ ] **A05 주석 저장:** 사진에 점선 도형·글자를 추가하고 회전한다. 메모 입력 → 보류·변경 저장 → 목록으로 나갔다가 다시 연다. 사진 순서·선택·열 수·주석·회전·메모가 유지된다.
- [ ] **A06 실제 OneDrive 저장:** OneDrive의 `상담/미용/환자번호M테스트남` 폴더에 사진과 `상담_<상담ID>.json`이 있다. 사진 파일을 직접 열 수 있다. 이 상담 저장만으로 PDF가 자동 생성되지는 않는다.
- [ ] **A07 다른 기기 재열람:** 다른 PC/태블릿에서 같은 환자의 상담을 연다. A05의 저장 결과와 일치한다. 이미 열려 있던 화면은 새로고침하고 확인한다.
- [ ] **A08 성공 → 진행 중:** 시술을 담고 저장한 뒤 성공 확정한다. 환자목록과 상세에 미용 패키지가 ‘진행 중’으로 표시된다.
- [ ] **A09 중간상담:** 해당 환자에서 중간상담을 시작한다. 과거 사진과 주석이 불러와지고, 비교할 사진을 선택할 수 있다. 장바구니 없이 메모를 저장·완료할 수 있으며 기존 패키지는 진행 중을 유지한다.
- [ ] **A10 연장상담:** 기존 성공 상담을 골라 연장상담을 시작한다. 기존 시술·옵션이 채워진다. 저장 후 ‘연장 안 함 · 완료’를 확정하면 기존 패키지가 완료로 바뀌고, 수동으로 다시 진행 중으로 전환할 수 있다.

## 2. 환자 정보·주소 검색

- [ ] **B01** 도로명 검색과 지번 검색을 각각 해 본다. 선택 결과에 맞는 시·도 / 시·군·구 / 동·읍·면이 입력된다. 아파트 동·호수 등 상세주소는 저장하지 않는다.
- [ ] **B02** 검색창을 닫거나 검색을 취소해도 이미 입력한 환자 정보가 사라지지 않는다.
- [ ] **B03** 주소 검색이 안 되는 환경에서 동·읍·면을 직접 입력하고 저장할 수 있다.
- [ ] **B04** 필수 정보 누락 시 등록이 차단되고, 생년월일에 따른 나이가 맞다. 같은 이름의 다른 환자를 환자번호로 구분할 수 있다.

## 3. 사진 추가·선택·비교

- [ ] **C01** 실제 고해상도 사진 5장을 추가해 미리보기 속도와 화면 반응을 확인한다. 파일당 크기 ___MB / 미리보기 ___초 / 전체 업로드 ___초. 처리 중 브라우저가 장시간 멈추지 않는다.
- [ ] **C02** 업로드 중 표시가 완료 시 사라진다. 업로드 중 저장을 눌러도 사진 업로드가 끝나기 전에 공유 저장 완료로 오인할 안내가 나오지 않는다.
- [ ] **C03** 0장 / 1장 / 5장 선택이 가능하다. 선택 해제는 사진 삭제가 아니며, 다시 선택할 수 있다.
- [ ] **C04** 썸네일과 비교 사진의 순서를 바꾼 뒤 저장·재열람하면 순서가 유지된다. PC 마우스 드래그와 태블릿 손잡이 드래그를 각각 확인한다.
- [ ] **C05** 비교 크게 보기를 열고 닫아도 선택·배치가 유지된다. 가로·세로 화면에서 사진과 버튼이 잘리지 않는다.
- [ ] **C06** 다른 환자 사진 또는 미용/보험 반대 구분의 사진이 이전 사진 선택 목록에 섞이지 않는다.

## 4. 사진 편집 도구

편집 후 저장·재열람까지 확인합니다.

- [ ] **D01** 펜 / 화살표 / 사각형 / 원 각각 실선과 점선으로 그려진다.
- [ ] **D02** 굵기와 투명도를 바꾸면 새 주석에 반영된다. 기존 주석도 저장 후 같은 모습이다.
- [ ] **D03** 한글 글자를 고딕 / 명조 / 고정폭으로 입력할 수 있다. 기기에 따라 폰트 모양은 달라도 글자가 깨지지 않는다.
- [ ] **D04** 모자이크 영역이 비교 화면과 병원용 PDF에 반영된다. 모자이크는 원본 사진을 삭제·변조하는 기능이 아니라 주석으로 저장된다.
- [ ] **D05** 주석 지우개로 원하는 주석을 지운다. 다른 주석이나 원본 사진은 사라지지 않는다. 실행 취소로 복구된다.
- [ ] **D06** 확대·축소 슬라이더를 0~100으로 움직이고, 이동 도구로 사진을 움직일 수 있다. 확대 후에도 펜이 포인터 위치에 맞게 그려진다.
- [ ] **D07 PC** Space+드래그 / 가운데 버튼 / 오른쪽 버튼 드래그로 이동하고 Ctrl+휠로 확대·축소할 수 있다. + / − / 0(화면 맞춤)이 동작한다.
- [ ] **D08 PC** P/A/R/O/T/M/E/H 도구 단축키, Ctrl+Z, Ctrl+Shift+Z가 동작한다. 메모·글자 입력 중에는 입력 문자가 도구 전환을 일으키지 않는다.
- [ ] **D09** 좌·우 90도와 −180~180도 자유회전이 동작한다. 회전 후 사진과 주석 위치가 함께 맞고 저장 후에도 유지된다.
- [ ] **D10** 자르기 / 원본 보기 / 실행 취소·다시 실행 후 사진과 주석이 예상대로 보인다. 원본 보기를 편집 내용 삭제로 오인하지 않도록 결과를 확인한다.

## 5. 중간·연장상담과 패키지 상태

- [ ] **E01** 중간상담에서 이전 사진 몇 장만 선택하고 새 사진을 추가해 전후 비교가 가능하다. 사진 날짜와 이전 상담 표시로 구분할 수 있다.
- [ ] **E02** 중간상담의 복사된 사진 주석을 수정해도 원래 상담의 주석·선택 상태는 바뀌지 않는다.
- [ ] **E03** 중간상담을 완료해도 시술 매출이나 매출 상담 성공률의 분모가 불필요하게 증가하지 않는다.
- [ ] **E04** 연장상담은 기존 시술·옵션을 현재 게시 단가로 채운다. 과거 할인은 자동으로 재적용되지 않는다. 수량·시술·할인을 변경할 수 있다.
- [ ] **E05** 연장 확정 시 새 상담은 진행 중, 기준이 된 이전 패키지는 완료가 된다. 환자목록은 진행 중 표시를 유지한다.
- [ ] **E06** 연장상담을 보류로 저장하는 것만으로 기존 패키지가 완료되지 않는다. 연장 안 함을 확정해야 완료된다.
- [ ] **E07** 진행 중 ↔ 완료 수동 전환이 저장·재접속 후에도 유지된다. 다른 진행 중 패키지가 있으면 환자의 진행 중 표시가 남는다.
- [ ] **E08** 과거 여러 상담 중 기준 상담을 바꿔 선택할 수 있다. 불러온 사진과 연장 장바구니가 선택한 기준 상담에 맞는다.

## 6. OneDrive 저장·미용/보험 분리 — 중요

- [ ] **F01** 남자 테스트 환자는 `상담/미용/환자번호M테스트남`, 여자 테스트 환자는 `상담/미용/환자번호F테스트여`에 저장된다. 신규 환자의 실제 환자번호를 사용해 확인한다.
- [ ] **F02** 같은 환자의 첫 상담·중간상담·연장상담 사진과 상담 JSON이 같은 환자 폴더에 모인다. 상담 JSON은 상담별로 구분된다.
- [ ] **F03** 촬영 시각을 아는 JPEG로 파일명을 확인한다. 예: 2026-09-19 14:22:56 한국 시각 촬영 → `260919_1422_56_M_테스트남.jpg`. 촬영 정보가 없는 파일은 파일 수정 시각을 사용한다.
- [ ] **F04** 같은 초에 촬영한 서로 다른 사진 2장을 저장해도 덮어쓰지 않는다. 충돌한 이름에 고유 접미사가 붙고 두 사진 모두 열 수 있다.
- [ ] **F05** 보험 상담을 만들고 보험으로 구분된 Lunula / INVT 등 시술을 선택한다. 미용 상품 목록과 구분되며 `상담/보험/환자번호M테스트남`에 저장된다.
- [ ] **F06** 보험 상담의 확정·연장·완료 처리가 같은 환자의 미용 진행 상태를 바꾸지 않는다.
- [ ] **F07 기존 자료가 있을 때** 이전 버전의 테스트 상담을 열 수 있다. 다시 저장하면 새 환자 폴더에 사진이 복사되고, 기존 OneDrive 파일도 남아 있다.
- [ ] **F08** 같은 환자의 이름을 수정해도 사진을 다시 찾을 수 있으며 이미 정해진 저장 폴더가 불필요하게 갈라지지 않는다. 기존 환자는 신규 6자리 번호 대신 기존 고유 ID가 폴더명에 사용될 수 있다.

## 7. 출력·금액·권한

- [ ] **G01** PDF 없이 보류 저장과 성공/실패 확정이 가능하다. 앱에서 상담 내용과 선택 사진을 다시 볼 수 있다.
- [ ] **G02** 병원용 PDF에는 선택한 사진만 선택 순서·열 수대로 출력되고 주석·회전이 반영된다. 페이지 경계에서 사진·한글·금액이 잘리지 않는다.
- [ ] **G03** 환자용 JPG의 시술·수량·할인·부가세·최종 금액이 화면 견적과 일치한다. 인쇄 미리보기도 확인한다.
- [ ] **G04** 직원은 본인의 보류 상담을 수정할 수 있다. 성공/실패 확정 후 상담 원문 수정·취소는 관리자 권한으로 제한된다. 패키지 상태 전환 권한과 원문 수정 권한은 구분한다.
- [ ] **G05 계정이 준비된 경우** 다른 작성자의 주석은 일반 직원이 지우거나 바꿀 수 없고, 본인의 주석은 수정할 수 있다. 관리자는 전체 주석 관리가 가능하다.

## 8. 저장 실패·여러 기기 — 테스트 상담에서만

- [ ] **H01** 사진 업로드 중 인터넷을 끊으면 실패·대기 상태가 표시되고 정상 저장 완료로 보이지 않는다. 연결 복구 후 재시도·저장하면 사진과 상담이 모두 재열람된다.
- [ ] **H02** 기기 암호화 보관을 켠 상태에서 보류 상담의 메모·사진을 변경하고 연결을 끊는다. 초안/대기 보관 후 앱을 다시 열어 복구·재전송되는지 확인한다. ‘기기 초안 저장’과 ‘공유 저장 완료’를 구분한다.
- [ ] **H03** 저장 버튼을 빠르게 두 번 눌러도 같은 상담·같은 업로드가 중복 생성되거나 금액이 중복 반영되지 않는다.
- [ ] **H04** 두 기기에서 같은 보류 상담을 연 뒤 A에서 저장하고 B에서 오래된 내용을 저장한다. A의 변경을 말없이 덮어쓰지 않고 충돌 안내가 나온다. 최신 내용을 다시 열어 확인한다.

## 9. Android 태블릿 추가 시험

- [ ] **I01** 기존 앱 위에 APK 0.2.0이 설치된다. 같은 계정으로 로그인 후 기존 환자·상담을 조회할 수 있다.
- [ ] **I02** 카메라 권한 승인 → 촬영 → 상담에 추가가 동작한다. 권한 거절·촬영 취소 후에도 앱을 계속 사용할 수 있다.
- [ ] **I03** 갤러리에서 여러 사진을 추가하고 손가락/펜으로 선택·정렬·주석·확대·이동을 조작할 수 있다.
- [ ] **I04** 가로는 사진 왼쪽·장바구니 오른쪽, 세로는 사진 위·장바구니 아래로 나온다. 비율 조절과 화면 회전/고정이 동작하며 입력 내용이 사라지지 않는다.
