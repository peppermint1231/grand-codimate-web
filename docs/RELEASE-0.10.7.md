# 0.10.7 — 단가표 일괄 수정·삭제 확인·이벤트 정가 편집

단가표 편집에서 상품을 여러 개 선택하고 **선택 상품 일괄 수정** 영역에서 변경할 항목을 선택하세요.

- 부가세 정책: 별도 / 포함 / 면세 / 확인 필요. 선택 상품의 모든 옵션에 적용되며 입력 가격은 유지됩니다.
- 맞춤 시술 찾기: 표시 / 숨김. 변경 안 함을 고르면 기존 값을 유지합니다.
- 선택 상품 일괄 검토완료: 모든 옵션을 검토완료 처리합니다. 옵션명·가격·부가세가 미확정인 상품이 있으면 해당 상품을 안내하고 이번 변경 전체를 적용하지 않습니다. 부가세 확정과 검토완료를 함께 적용할 수 있습니다.

**선택 상품 일괄 적용** 또는 **Alt+B** → **초안 저장** → **검증 후 게시** 순서로 반영합니다. 단축키는 기존 ? 안내에도 표시됩니다. 판매 활성 여부는 기존 상태를 유지합니다. 검색·폴더 밖의 선택 상품도 포함되므로 선택 개수를 확인하세요.

한 번의 일괄 적용은 되돌리기/다시 실행 한 단계로 기록됩니다. 저장 이력에서 부가세·추천기 공개·옵션별 검토완료 변경을 확인할 수 있습니다.

상품 개별/선택 삭제와 폴더 삭제 경고창에서 삭제 확인 버튼에 기본 초점이 놓입니다. Enter로 삭제 확인, Esc 또는 취소 버튼으로 닫습니다.

이벤트 상품의 옵션별 **정가 (원)**와 **이벤트가 (원)**를 목록 및 상품 상세에서 각각 수정할 수 있습니다. 현재 두 금액으로 할인율을 자동 계산하며, 정가가 없거나 이벤트가보다 낮으면 할인율을 표시하지 않습니다. 수정한 가격은 게시 후 상담·맞춤 시술 찾기에 반영됩니다. 홈페이지 원문 가격은 별도로 보존하며, 직접 입력한 정가는 홈페이지 갱신 후에도 유지됩니다.
