# 0.2.0 — 사진 비교·중간/연장상담

## 사용 흐름

- 사진 추가 시 썸네일과 원본 미리보기를 먼저 표시하고 업로드를 진행한다. 업로드 중·실패 대기는 사진별로 표시되며, 보류 저장은 필요한 업로드 완료를 확인한다. 대기 업로드가 있으면 탭 종료 확인이 나온다. 기기 암호화 보관을 켜야 재접속 후 오프라인 대기를 복구할 수 있다.
- 썸네일 클릭으로 상담·출력 포함/제외. 선택한 사진이 즉시 비교 화면에 나타난다. 1~4열 선택과 사진 순서를 상담에 저장한다. 손잡이를 끌거나 손잡이에 초점을 두고 좌우 화살표로 이동한다. ‘편집’에서 개별 사진을 수정한다.
- 펜·화살표·사각형·원: 실선/점선, 굵기·투명도. 글자: 고딕/명조/고정폭(기기 폰트 사용). 영역 모자이크와 주석 단위 지우개. 관리자는 전체, 직원은 본인 주석만 지울 수 있다.
- 0~100 확대/축소 조절, 이동 도구, Space/가운데·오른쪽 버튼 드래그, Ctrl+휠, +/−, 0 화면 맞춤. P/A/R/O/T/M/E/H 도구 단축키, Ctrl/Cmd+Z 및 Shift+Z. 좌우 90도와 −180~180도 자유회전. 자르기·회전·주석은 원본과 별도로 보관한다.
- 환자 상세에서 미용/보험을 선택해 첫 상담·중간상담·연장상담 시작. 이전 상담 사진·주석은 복사된 편집 기록으로 불러오므로 원래 상담에 덮어쓰지 않는다. 다른 과거 상담의 사진도 추가 선택 가능하다.
- 중간상담은 경과 메모와 사진 비교 중심이며 장바구니 없이 완료할 수 있다. 중간상담은 매출 상담 성공률 통계에서 제외한다.
- 연장상담은 기존 시술/옵션을 현재 게시 단가로 채운다. 과거 할인은 자동 적용하지 않으며 추가·삭제·변경 가능하다. 현재 판매하지 않는 옵션은 명시적으로 오류를 보여 단가표 검토를 요구한다.
- 성공 확정은 진행 중, 연장 성공은 새 상담을 진행 중으로 이어가며 이전 패키지는 완료, 연장 미진행은 이전 패키지 완료. 중간상담은 이 상태를 바꾸지 않는다. 환자 상세에서 수동 진행 중/완료 전환 가능. 미용과 보험은 별도 표시한다.
- Lunula/루눌라·INVT는 보험 상담 구분을 기본 제안하며 단가표 상품 편집에서 명시적으로 구분을 지정할 수 있다. 미용 상담에는 보험 상품이 나타나지 않는다.
- 상담 저장·성공/실패 확정에는 PDF가 필요하지 않다. ‘병원용 PDF’로 선택 사진·배치를 반영한 PDF를 필요할 때 내려받는다.
- 환자 주소는 카카오 주소 검색에서 동·읍·면까지 입력한다. 오프라인/검색 장애 시 직접 입력한다. 환자 이름이나 전화번호를 검색 서비스에 보내지 않는다.

## OneDrive 폴더와 호환성

신규 사진: `상담/미용/000001M환자이름/260919_1422_56_M_환자이름.jpg` (보험은 `상담/보험/...`). 새 환자는 순번을 부여하며 기존 환자는 기존 고유 ID를 사용한다. 환자 이름 변경 후에도 기존 폴더명을 유지한다. 성별 미상은 U이다.

촬영 시각은 JPEG EXIF의 촬영 시각을 우선 사용한다. 시간대가 없는 EXIF는 한국 시각으로 해석하며, 촬영 메타데이터가 없으면 파일 수정 시각을 사용한다. 같은 초에 촬영한 동명 파일에는 충돌한 파일만 고유 ID 접미사를 붙인다. 파일명 예약과 업로드 ID로 재시도를 처리한다.

상담 내용·사진 선택·배치·주석은 같은 환자 폴더의 `상담_<상담ID>.json`에 기록한다. 복구용 암호화 기록은 `상담/_codimate`에 계속 저장한다. 환자 폴더의 JSON과 사진은 OneDrive에서 읽을 수 있는 파일이다. PDF는 자동 생성하지 않는다.

기존 상담 폴더의 사진은 해당 상담 저장 시 새 환자 폴더로 복사하고 파일 크기를 확인한다. 앱의 미디어 ID는 유지하고 이전 파일은 지우지 않는다. 아직 다시 저장하지 않은 과거 자료도 기존 미디어 ID로 계속 조회된다.

일반 JPG/PNG 원본은 유지한다. 7.8MB 초과 파일은 업로드 상한에 맞춰 최대 긴 변 3200px JPEG로 변환하며 WebP도 JPEG로 변환한다. 이미지 파일 자체에 모자이크를 덮어쓰지 않으므로 원본 보관과 별개로 외부 전달할 때는 주석을 반영한 출력물을 사용한다.

## 검증 범위

- 도메인/저장 테스트: PDF 없는 확정, 최신 가격 연장, 진행 상태/수동 전환, 타 환자·구분 차단, 주석 작성자 권한, 정렬·배치·회전·스타일 직렬화, 파일명·중복·재시도, 스냅샷 저장 실패 보존.
- 브라우저: 5장 업로드를 4초 지연했을 때 약 270ms 내 썸네일 표시(작은 합성 이미지); 1/2/3/4열이 각각 1+1+1+1+1, 2+2+1, 3+2, 4+1; 재로그인 후 재열람; 점선·투명도·폰트·모자이크·회전; 중간/연장상담과 PDF 출력; 주소 검색 콜백과 모바일 화면.
- Microsoft Graph 업로드/실패 테스트는 모의 응답이며 실제 병원 계정의 파일을 생성·이동하지 않았다. 실제 대용량 촬영 파일, 카카오 실주소 검색 및 Android 실기기 검증은 사용자 기기에서 이어서 확인한다.
