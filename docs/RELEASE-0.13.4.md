# 0.13.4 · 메뉴 판매 상태 통합과 보험 항목 확장

단가표 상품 목록에 미검토·판매 활성·판매 비활성 필터를 추가했다. 상품별 판매 버튼과 선택 도구 옆 일괄수정 창으로 판매 상태를 변경한다. 선택 도구는 스크롤할 때 고정되며, 현재 목록 밖에서 선택된 상품 수도 표시한다. Alt+B는 일괄수정 열기, Alt+Shift+B는 선택 상품에 변경 내용 반영, Ctrl/Cmd+S는 저장·적용이다.

버전 선택·새 메뉴 구성·복사·수정 이력은 ‘추가 관리’ 안에 묶고 기본적으로 접는다. SSOT 탭을 바꿀 때도 접힌 상태로 시작한다.

일반 상품 수정은 ‘저장하고 적용’ 한 번으로 현재 상담·추천기 메뉴에 반영한다. 기존 버전과 기존 상담 견적은 보존한다. 서버는 활성 상품의 가격·세금·검토완료를 확인하고, 다른 기기에서 바뀐 단가표를 덮어쓰지 않도록 버전을 비교한다. 검증 실패 시 일부만 저장하지 않는다. 홈페이지 갱신도 ‘동기화하고 적용’으로 정리했다. 기존 버전 선택과 수정이력 복원은 유지한다.

보험 SSOT는 기존 상품에 신규 6개 상품·10개 옵션, 기존 레이저에 한발 10회 옵션 2개를 추가한다. 기존 제균 상품은 중복 생성하지 않고 ‘발톱무좀 제균’으로 정리한다. 사용자가 확인한 이번 요청 항목은 부가세 포함이다. IVNT·초음파·MD는 비급여·실비 청구 가능으로 표시하며 기존 실비 조건 안내를 유지한다.

수액은 장바구니 수량 1에 묶음 총액을 사용하고, 상품 설명에 회당 단가를 적는다. 피부질환 수액은 1회 105,000원 / 6회 567,000원(회당 94,500원) / 10회 892,500원(회당 89,250원), 대상포진은 1회 95,000원 / 6회 513,000원(회당 85,500원) / 10회 807,500원(회당 80,750원)이다. 패키지 정가는 1회 단가×횟수로 계산해 할인 내역이 견적에 나타난다.

초음파 80,000원, 덱세릴MD 500g 90,000원, 이지듀MD크림 85g 40,000원, 이지듀MD로션 200g 48,000원. 한발 레이저 10회 베이직 720,000원·프리미엄 900,000원. 기존 양발 옵션은 양발로 표시한다. 제균은 1회 50,000원이다.

검증: 51개 파일·325개 테스트, 웹 빌드. PC 1440px·태블릿 768px·모바일 390px 브라우저에서 필터, 일괄수정, 저장·적용, 개별 판매 전환 및 이전 버전 보존을 확인했다. APK 버전 코드 57. 실제 Android 기기 설치 검사는 수행하지 않았다.

운영 보험 데이터 등록 완료: 기존 8개에서 14개로 확장, 판매 활성 10개·기존 미완료 4개 유지. 기존 단가표 버전과 다른 SSOT의 ID·revision·버전은 변하지 않았다. 제균은 기존 상품을 재사용했다. 서버 대기 작업 0건이며 실제 운영 브라우저에서 대상포진 10회 807,500원과 VAT 포함 표시, 3개 화면 너비를 확인했다. 데이터 등록은 기존 서버의 호환 저장·게시 API로 완료했으며, 확인 중 추가 업무 쓰기는 0건이었다. 새 화면 배포는 별도로 최종 검증한다.

운영 배포 최종 확인: PR #1 병합 커밋 `2966c001861a36e65305ecdad5974a795d38671a`의 GitHub 검증과 Workers Builds가 모두 성공했다. 운영 0.13.4에서 추가 관리 기본 접기, 세 필터, 선택 옆 일괄수정, 14개 보험 상품과 부가세 포함 가격을 3개 화면 너비에서 확인했다. 웹 파일 48개와 공개 APK SHA-256이 로컬 빌드와 일치한다. 검증 기록은 `artifacts/deployment-0.13.4.json`이다.
