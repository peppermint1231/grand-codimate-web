# 0.11.1 · 견적서 PDF·JPG 출력 수정

상담을 저장한 직후 병원용 PDF 또는 환자용 JPG 출력을 누르면, 진행 중인 서버 전송을 실패로 처리하여 출력을 막던 문제를 수정했습니다. 이제 저장 완료를 기다린 뒤 내보내기를 진행하며 대기 이유를 안내합니다. 저장이 실제 실패하거나 동의·권한 확인이 실패한 경우에는 출력하지 않고 오류를 표시합니다.

- PDF 한글 글꼴 다운로드가 한 번 실패하면 같은 화면에서 계속 실패하던 캐시를 수정했습니다. 다시 누르면 글꼴부터 재시도합니다. 글꼴 대신 HTML/빈 응답을 받는 경우도 검사합니다.
- 환자용 JPG는 한글 글꼴이 준비되었는지 확인한 후 생성합니다. 페이지별 저장 버튼은 이미 생성한 파일을 바로 저장하여 불필요한 재생성과 다운로드 차단 가능성을 줄였습니다.
- 견적 내용이나 디자인 변경 시 기존 출력 파일의 재저장 버튼을 초기화합니다.
- 환자용 인쇄는 실제 인쇄 이미지의 준비를 기다리고 A4 페이지와 여백을 고정합니다. 인쇄가 끝나면 이전 견적 이미지를 정리합니다. Android 인쇄도 인쇄 화면이 끝난 뒤 정리합니다.
- 병원용 PDF도 내보내기 기록이 서버에 저장되지 않으면 다운로드 성공으로 진행하지 않습니다.

검증: 수정 전 저장 중 출력 차단, PDF 글꼴 재시도 실패, 인쇄 자료 잔류를 브라우저에서 재현했습니다. 수정 후 PDF/JPG 각각 저장 직후 출력, 글꼴 실패 후 재시도, 서명·동의와 7일 QR/즉시 만료, 여러 페이지 JPG 저장, A4 1장/2장 실제 인쇄 PDF 생성과 화면 정리를 확인했습니다. 생성한 병원용 PDF는 텍스트 추출과 렌더링으로 한글·금액을 확인했습니다. 물리 Android 저장 창과 실제 프린터 검증은 별도입니다.
