# 코디메이트 0.4.0 — 사진 편집 흐름 개선

Android versionCode 6. 웹과 APK가 같은 편집·상담 저장 방식을 사용합니다.

## 사용법

- 로그인 화면에서 등록된 활성 아이디를 선택하거나 직접 입력합니다. 비밀번호는 항상 필요합니다. 선택 목록에는 아이디만 내려오며 비밀번호·권한·개인정보는 포함하지 않습니다.
- 상단 **새로고침**은 최신 서버 자료를 읽습니다. 작업 중인 상담은 유지하므로, 다른 기기에서 수정됐다면 저장 시 기존 충돌 검사가 적용됩니다. **← 뒤로**와 Android 뒤로가기는 설정창·비교 화면을 먼저 닫고 이전 앱 화면으로 이동합니다.
- 사진 목록의 ✎는 해당 편집기로 스크롤합니다. 선택한 사진은 편집기 왼쪽에 한 줄 세로 썸네일로 표시됩니다. 목록을 스크롤하고 썸네일을 누르면 바로 편집합니다.
- ⠿를 끌면 사진 미리보기가 손가락/마우스를 따라가며, 다른 썸네일이 애니메이션으로 자리를 바꿉니다. 키보드 좌우 화살표도 지원합니다.
- **비교 크게 보기**에서만 1·2·3·4열을 고릅니다. 사진은 원래 출력 비율로 각 열 너비를 채웁니다.
- **글자** 도구로 원하는 위치를 누르면 입력·폰트·크기·색상·투명도 설정창이 열립니다. 기존 글자는 박스를 선택해 이동하거나 오른쪽 아래 손잡이로 크기를 바꾸고, 박스의 ✎/×로 수정·삭제합니다.
- **선택** 도구는 펜·화살표·사각형·원·모자이크·스탬프도 지원합니다. 주석을 선택하고 끌어 이동하거나 크기 손잡이를 사용합니다. ✎에서 스타일을 바꾸고 × 또는 Delete로 삭제합니다. 다른 작성자의 주석을 바꾸려면 관리자 권한이 필요합니다.
- **사진 편집 저장**은 현재 사진의 편집을 작업 중인 상담에 반영합니다. **보류·변경 저장**까지 눌러야 서버/OneDrive 상담에 저장됩니다. 사진만 저장한 뒤 상담을 나갔다 다시 열면 마지막 상담 저장 상태입니다. 사진 편집 미저장 상태에서는 상담 저장을 막고 편집 저장을 안내합니다. 오프라인 보관함도 사진 편집의 미확정 상태를 자동 복원하지 않습니다. 사용자가 상담 저장을 누른 오프라인 명령은 기존 대기 전송 방식대로 보존합니다.
- **영역 자르기**는 주석 색상·굵기·투명도와 무관한 흰색 점선으로 표시됩니다.
- **영역 자르기 (포트레이트)**는 화면 기준으로 반듯한 프레임, 3분할 안내선, 바깥 영역 음영을 표시합니다. 모서리/변으로 크기를 조절하고 안쪽을 끌어 옮깁니다. 아래 자유회전으로 사진을 돌려도 프레임은 돌지 않습니다. **자르기 적용 → 사진 편집 저장 → 상담 저장** 순서로 반영합니다. 원본 사진을 덮어쓰지 않으며 **자르기 해제**로 복원할 수 있습니다.
- 썸네일 왼쪽 위 **☆**를 누르면 **★ 대표사진**이 됩니다. 상담마다 한 장이며 다시 누르면 해제합니다. 상담 저장 후 환자 상세의 상담이력에 주석 포함 대표사진이 나옵니다.
- 썸네일 오른쪽 위 **×**는 현재 상담에서 사진을 삭제합니다. 상담 저장 전까지 서버 기록은 유지됩니다. 다른 상담에서 같은 사진을 사용해도 영향이 없으며, 원본 OneDrive 파일을 영구 삭제하지 않습니다. 다른 작성자의 주석이 있는 사진은 관리자만 삭제할 수 있습니다.

## 태블릿·웹 확인 체크리스트

테스트 환자로 확인합니다.

| 확인 | 기대 결과 |
| --- | --- |
| 등록 아이디 선택·직접 입력 | 선택값이 입력칸에 반영되고 비밀번호 없이는 로그인되지 않음 |
| 새로고침 | 새 자료를 표시하며 편집 중인 상담은 유지 |
| Android 뒤로가기 | 텍스트 설정 → 편집기, 비교 화면 → 상담, 상담 → 이전 화면으로 이동 |
| ✎ 사진 편집 | 해당 사진 편집기가 보이는 위치로 이동 |
| 왼쪽 선택 사진 목록 | 한 줄 세로 목록, 많은 사진은 세로 스크롤, 누르면 바로 편집 |
| ⠿ 순서 이동 | 이동 미리보기와 자리 이동 애니메이션, 상담 저장 후 순서 유지 |
| 비교 1~4열 | 크게 보기 안에서만 선택, 각 열의 사진이 열 너비를 채움 |
| 텍스트 신규·수정 | 위치 선택 시 설정창, 박스 이동/크기 변경, ✎ 수정과 × 삭제 |
| 일반 주석 선택 | 펜·도형·화살표 등을 이동/확대/스타일 수정/삭제 |
| 두 손가락 | 펜 사용 중 확대·이동해도 불필요한 선이 남지 않음 |
| 사진 저장만 하고 재진입 | 이전 상담 저장 상태로 복원 |
| 사진 저장 후 상담 저장 | 재진입·다른 기기 조회에서도 변경 유지 |
| 기본 자르기 | 주석 투명도를 100%로 해도 흰 점선이 보임 |
| 포트레이트 자르기 | 회전 중 프레임은 반듯하게 유지, 모서리 조절, 출력 JPG/PDF에도 같은 영역 |
| 대표사진 | 한 상담에 ★ 한 장, 저장 후 상담이력 썸네일 표시 |
| 사진 삭제 | 저장 후 현재 상담에서 제외, 다른 상담과 원본 사진 보존 |

## 개발 검증

51개 자동 테스트, 실제 Chromium UI/API 시험, 다중 터치 이벤트, 텍스트 크기·일반 주석 이동/수정, 기본 크롭의 불투명 점선, 회전 후 크롭 출력 크기, 저장 단계 분리, 대표사진/삭제 및 로그인 복원 모의 시험을 실행합니다. `scripts/verify-editor-040.ts`가 0.4.0 편집 화면의 최신 시험이며 0.3.0 이전 화면용 스크립트의 버튼 위치와 다릅니다.

실제 Android 시스템 뒤로가기·앱 복귀는 태블릿에서 추가 확인이 필요합니다. 개발 브라우저에서 동일한 앱 뒤로가기 이벤트와 암호화 로그인 브리지를 검증하며, 실제 병원 OneDrive 데이터에 시험용 변경을 하지 않습니다.

## 참고

사용자가 첨부한 갤럭시 사진 편집 화면의 고정 프레임·음영·3분할 안내선을 반영했습니다. Android 뒤로가기는 [공식 OnBackPressedDispatcher](https://developer.android.com/guide/navigation/navigation-custom-back)를 사용합니다. 자르기/회전 동작은 [삼성 Gallery 안내](https://www.samsung.com/uk/support/mobile-devices/how-do-i-use-the-gallery-app/)도 참고했습니다.
