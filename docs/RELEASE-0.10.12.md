# 0.10.12 — 저장 진행 안내와 고정된 시술 검색

상담·사진·단가표·서명 등을 저장할 때 화면 가운데 진행 안내창이 나타납니다. 파일 전송은 실제 전송량에 따른 0~100%와 진행 막대로 표시하고, 여러 사진은 총 전송량과 서버 저장이 확인된 사진 수를 함께 표시합니다. 추가 직후 아직 업로드 중인 사진도 상담 저장 시 같은 안내창에서 기다립니다.

100%는 해당 자료의 전송 완료를 뜻합니다. 그 뒤 서버 저장 확인과 최신 화면 반영을 마칠 때까지 안내창을 유지합니다. 진행률을 측정할 수 없는 서버/OneDrive 저장·화면 갱신 단계는 처리 중 표시와 경과 시간을 보여줍니다. PDF/JPG 준비와 Android 저장 위치 선택도 현재 단계로 안내합니다. 임의의 시간으로 백분율을 올리지 않습니다.

완료되면 안내창이 자동으로 닫힙니다. 실패나 충돌은 기존 오류 안내를 표시하고 편집 내용을 유지하며, 기기 보관을 설정한 경우 기존 동기화 대기 동작을 유지합니다. 진행 중 중복 클릭·단축키·뒤로가기를 막고 창을 닫으려 하면 브라우저 확인을 요청합니다. 15초 이상 걸리면 추가 안내를 보여줍니다.

상담 시술 선택 상단은 **미용·보험·이벤트 / 검색창 / 전체 분류 선택** 한 줄로 압축했습니다. 검색 결과 수와 단가표 날짜는 작은 보조 줄로 표시합니다. 상품 목록 안을 스크롤해도 상단은 고정되고, 검색·분류·단가표 구분을 바꾸면 목록 처음으로 돌아갑니다. 폭이 좁은 휴대폰/분할 화면은 입력 공간을 확보하기 위해 탭과 검색·분류를 두 줄로 배치합니다.

검증: 자동 테스트 232개, 실제 XMLHttpRequest를 느린 네트워크로 전송하여 중간 백분율과 서버 응답 전 100% 대기 확인, 두 사진의 업로드 대기/저장 수/상담 저장 순서 확인, 충돌 후 편집 유지, PC·태블릿·휴대폰 5개 크기에서 검색 고정·필터·가로 넘침 확인. 브라우저 전송 진행 이벤트는 [MDN XMLHttpRequest upload 문서](https://developer.mozilla.org/en-US/docs/Web/API/XMLHttpRequest/upload)를 따릅니다.

팝업 안에서 저장하여 팝업이 닫힌 뒤에도 페이지가 계속 잠기는 문제를 함께 수정했습니다.
