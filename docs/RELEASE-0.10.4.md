# 0.10.4 — 상담 사진 아래 의사 의견·사진별 코멘트

- 의사 의견을 환자 상담이력 목록에서 **상담상세 → 02 상담 → 상담 사진 아래**로 옮겼습니다. 기본은 접혀 있고 답변이 없으면 표시하지 않습니다. 상담을 보는 다른 직원도 펼쳐서 읽을 수 있습니다.
- 답변 작성의 **사진별 코멘트 추가**에서 사진을 선택하고 해당 사진에 대한 의견을 입력하세요. 여러 사진에 각각 남길 수 있으며 전체 의견 없이 사진별 코멘트만 저장할 수도 있습니다.
- 사진별 코멘트는 사진의 고유 ID에 연결됩니다. 표시되는 번호는 상담에 선택한 사진의 현재 배치 순서로 계산하므로, 상담 화면에서 재배치하면 저장 전에도 즉시 바뀝니다. 배치를 저장하면 다른 직원에게도 같은 번호로 표시됩니다.
- 코멘트의 썸네일을 누르면 해당 사진을 확대합니다. 비교에서 제외된 사진은 ‘비교 제외 사진’, 삭제된 사진은 ‘삭제된 사진’과 원래 이름으로 표시해 다른 사진을 잘못 가리키지 않습니다. 기존 코멘트는 보존됩니다.
- 사진별 코멘트만 있는 답변도 새 답변 알림·계정별 읽음 처리에 포함합니다. 상담 기록 PDF에도 현재 번호와 코멘트가 출력됩니다.

자동 테스트 188개, 실제 화면의 사진 지정/복수 코멘트/사진만 있는 답변/재배치 전후 번호/제외 사진/확대/다른 직원 열람/모바일 및 기존 주석 편집 중 답변 초안 보존을 검증했습니다. 운영 검증은 읽기 전용으로 수행합니다.
