# 0.18.13 — 누락값과 비교 대상 분리

- 미입력·확인 필요·미선택·지역 누락·미분류는 인원수를 별도 안내에 보존하고, 도넛 구성비·막대 크기·히트맵 색상과 비교 순위에서는 제외한다. 전체 환자 수와 원본 통계 데이터는 유지한다.
- 비교할 값이 없는 경우 빈 비교 상태를 표시한다. 연령×카테고리의 제외 인원은 카테고리별 합계로 중복될 수 있음을 안내한다.
- 환자통계 Excel의 분포 시트에는 비교 포함 여부를 기록한다. 통계 해석 프롬프트에도 같은 제외 기준을 안내한다.
- 자동 테스트 486개 통과. 미입력 6만 명과 실제 유입경로 500명 사례를 포함해 PC 1440px / 태블릿 800px / 모바일 390px에서 막대 비율·누락 인원·도넛 조각·필터·가로 넘침을 확인했다.
