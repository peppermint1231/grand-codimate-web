# 0.18.6 — 확정 패키지 구성·상품 통합

상품의 공통 일정과 다른 옵션별 구성을 저장하고 추천기·신규 장바구니·견적서에 동일하게 표시합니다. 월별 반복과 병원이 확인한 간격 진료를 지원합니다. 2/4/6개월 프로그램은 8/12/14회 방문으로 나누며 실제 8/16/24주차 번호를 보존합니다. 회차 중복·역순·옵션 방문 횟수 불일치는 저장 시 차단합니다. 번호가 없는 집중관리 설명에는 가상의 회차 번호를 붙이지 않습니다.

사용자 첨부와 추가 확인에 따라 미용 18상품/46옵션을 수정할 후보를 준비했습니다. 눈가·목 구성이 반복되는 탄력·광채 및 연령별 프로그램은 사용자 확인대로 유지합니다. 루비스타 5상품을 7옵션으로, 굿바이 여드름 2상품을 서로 다른 4/8주 옵션으로, 튼살 5상품을 부위×4/8회 10옵션으로 통합합니다. 유지관리 프로그램은 월 1회, 6개월은 3회 순서 2회 반복입니다. 내맘대로 피부관리는 모든 차감 메뉴를 공통 설명에 표시합니다.

가격·정가·부가세·옵션 ID·판매 조건과 수동 폴더 트리는 전후 대조합니다. 굿바이 통합 상품은 기존 8주 상품의 여드름/모공 연결 폴더에 놓습니다. 수정 전 상품은 이전 게시본과 기존 상담에 보존됩니다. 새 게시본 생성 직전에 전체 원본 비교와 catalogApplyGuard로 동시 변경을 확인합니다. 현재 미용 499상품은 통합 후 490상품이며 검토 보류된 패키지 23건은 모두 해소됩니다. 개인 데이터·인증정보·전체 카탈로그 스냅샷은 커밋하지 않습니다.
