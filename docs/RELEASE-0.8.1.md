# 0.8.1 · 폴더 편집과 단가표 변경 이력

단가표 관리에서 폴더 목록과 상품 목록 사이 선을 끌어 너비를 조절합니다. 키보드 좌우 방향키도 지원하고 너비는 기기에 보관합니다. 작은 세로 화면에서는 위·아래 배치를 사용합니다.

**폴더 목록 수정**을 누르면 편집 모드가 됩니다. 게시본에서도 시작할 수 있습니다. 작성 중인 상품 변경이 있다면 먼저 초안을 저장합니다.

- 폴더 이름을 두 번 눌러 그 자리에서 이름과 색상을 변경하고 적용합니다.
- 폴더 손잡이를 대상의 위·아래로 끌면 순서를 바꾸고 가운데로 끌면 안으로 이동합니다. ‘전체 상품 / 최상위 위치’에 놓으면 최상위로 이동합니다. 이동 위치 선택과 버튼도 사용할 수 있습니다.
- 같은 이름이 겹치면 하위 항목 합치기 또는 대상 덮어쓰기를 선택합니다. 합치기는 같은 이름의 하위 폴더도 재귀적으로 합치며 양쪽 상품을 보존합니다. 덮어쓰기는 대상 하위 폴더·상품을 제거하고 원본으로 교체합니다. 영향받는 개수를 먼저 표시합니다.
- 폴더 생성·복사·삭제를 지원합니다. 삭제 경고에서 하위 폴더와 상품 수를 확인하거나 취소하고 먼저 이동할 수 있습니다. 복사는 폴더·상품·옵션에 새로운 ID를 부여하며 복사한 상품은 비활성·추천기 숨김으로 시작합니다.
- 상위 폴더도 이름·색·순서·위치를 수정할 수 있습니다. 폴더 깊이는 최상위 아래 3단계를 유지하고 자기 하위로의 이동을 차단합니다.

**폴더 저장**을 눌러야 SSOT와 추천기에 반영됩니다. 취소는 저장하지 않습니다. 저장은 새 게시 버전과 변경 이력을 한 작업으로 기록하므로 중간 상태가 공개되지 않습니다. 다른 기기가 먼저 게시한 경우 덮어쓰지 않고 충돌을 알립니다. 추천기의 고민 분류와 세부 폴더는 해당 SSOT의 게시 구조를 사용합니다. 기존 고민명이 바뀌면 이전 이름에 연결된 고정 질문은 자동 제시하지 않습니다. 환자 접수에는 선택 당시 이름을 보관합니다.

**수정 이력 · 되돌리기**에서 저장 시각·담당자와 폴더 이름/색/순서/위치, 상품 추가/삭제/이동, 가격·부가세·공개 설정 변경 내역을 확인합니다. 게시 이력을 복원하면 새 게시본으로 반영하고, 초안 이력은 새 초안으로 복원합니다. 복원도 이력에 남으며 기존 상담 가격 스냅샷은 유지합니다. 이번 업데이트부터 저장별 이력을 기록하고 첫 수정 전 상태도 보관합니다. 이전 게시본은 기존 버전 선택 메뉴에도 남아 있습니다.

권한 없는 사용자는 초안과 복원 스냅샷을 조회하거나 수정할 수 없습니다. 이력은 기존 OneDrive 암호화 작업 기록에 함께 저장되어 복구 대상에 포함됩니다. 실제 단가·임상 기록을 소스 저장소에 추가하지 않습니다.

검증: 자동 테스트 113개, TypeScript·웹 빌드, 격벽 포인터/키보드·너비 유지, 인라인 이름/색상, 다중 단계 병합·복사·삭제 경고·취소·저장 전 미반영·공개 추천기 동기화·게시본 복원 브라우저 검증. `scripts/verify-folders-081.ts`와 `artifacts/folders-browser-081.json` 참조.
