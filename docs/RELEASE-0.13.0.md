# 0.13.0 · 홈페이지 SSOT와 미용 독립 관리

이벤트 SSOT의 표시 이름을 홈페이지 SSOT로 바꾸고 기본 순서를 홈페이지 → 미용 → 보험으로 유지한다. 상담·장바구니·추천기·단가표·통계 화면과 관련 내보내기 표시를 맞췄다. 저장된 단가표 구분 ID는 유지하여 기존 견적·상담·백업의 연결을 보존한다.

홈페이지 갱신은 모든 분류와 페이지의 배너·상품을 조회한다. 이벤트 키워드 유무와 관계없이 홈페이지 SSOT에 반영하며 정가·판매가·기간·할인율·포스터 원본 링크를 유지한다. 원문이 같은 상품의 직접 편집·검토·분류를 보존하고, 신규/변경 상품은 검토 대상 초안으로 둔다. 이미 홈페이지에서 제외된 항목은 기존처럼 비활성 상태와 게시 상태 색상으로 구분한다. 이미지 파일을 서버에 복사하지 않는다. 분류 기준으로 미용 SSOT를 읽지만 갱신은 홈페이지 SSOT에만 저장한다. 이전 앱의 미용·이벤트 동시 갱신 요청은 업데이트 안내로 차단한다.

미용 SSOT는 홈페이지 자동 추가 상품만 분리하고 수동 구성·가격·옵션·폴더를 유지한다. 홈페이지 점검 색상과 갱신 버튼도 미용에서는 표시하지 않는다. 분리 전 버전은 보존하며 상담에 저장된 금액/상품 스냅샷을 변경하지 않는다. 미게시 수동 변경이 있으면 자동 게시를 차단한다.

상품 목록에 ‘미검토 항목만 선택’(Alt+U)을 추가했다. 현재 검색·폴더에 보이는 미검토 상품만 선택하며, 검토 표시뿐 아니라 미확정 부가세/가격·옵션 누락도 포함한다. 일괄 검토/판매 활성화는 상품 단위로 검사하여 가능한 상품부터 적용하고, 불가능한 상품은 기존 상태를 유지한다. 결과에 적용 수·미적용 수·상품별 사유를 표시하고 ‘미완료 상품만 선택’으로 이어서 수정할 수 있다. 한 상품의 실패 때문에 완료된 다른 상품을 취소하지 않는다. 부가세를 임의로 확정하지 않는다. 기존 초안 저장·게시 및 되돌리기/다시실행 흐름을 유지한다.

검증: 자동 테스트 48개 파일·311개, 웹 빌드. 1440/768/390px 브라우저에서 전체 상품 가져오기, 홈페이지 전용 갱신, 미검토 선택/단축키, 혼합 일괄 검토 부분 성공, 미완료 재선택·보완, 되돌리기/다시실행·저장, 화면 넘침 없음 확인. 운영 자료 계획에서 홈페이지 88개 배너/417개 상품, 미용 기존 수동 503개와 자동 추가 723개를 구분했고, 보존할 수동 상품·분류는 기존 게시본과 동일함을 확인했다.
