# 0.18.7 — 상담 신청·상품 만들기·패키지 블록

추천기 관심 시술 목록을 모든 고민 탐색 단계에 고정 표시합니다. 목록에서 삭제하거나 상담 신청으로 바로 이동할 수 있습니다. 연락처는 숫자 입력을 010-xxxx-xxxx로, 생년월일은 YYYY-MM-DD로 자동 정리합니다. 생년월일은 달력 없이 입력하며 실제 날짜·미래 날짜를 검증합니다. 재방문은 이름·연락처만 묻고 첫 방문에서 입력했던 성별·생년월일·주소도 전송하지 않습니다. 첫 방문은 세 항목이 필수이고 서버에서도 성별·생년월일·주소를 검증합니다. 주소 검색으로 동·읍·면까지만 저장합니다. 희망 일정은 월 달력과 시간 버튼으로 선택하며 일요일·공휴일·휴진일·지난 시간·점심시간을 제외합니다.

상품 추가는 기본 정보→옵션/구성→확인의 세 단계입니다. 상품명 입력칸과 옵션 편집 레이아웃의 최소 폭을 수정했습니다. 일반/패키지/멤버십/블록 타입과 목록 필터를 추가했고 일반 상품 외에는 타입 태그를 표시합니다. 기존 상품은 구조화된 유형·회차 정보·명칭에서 표시 유형을 추론하며 원본을 일괄 변경하지 않습니다. 명시적으로 지정한 타입이 우선합니다. 블록은 추천기에서 제외합니다.

패키지 구성기는 블록 타입의 개별 옵션을 카테고리별로 제공하며 기간·회차·총 수량·회차별 배치를 설정합니다. 수량 균형 자동 배치, 마우스/포인터 드래그 손잡이, 회차 선택 이동을 지원합니다. 미배치·빈 회차·수량 불일치·중복 식별자·초과 할인은 저장 전에 차단합니다. 자동 배치는 의학적 순서를 추론하지 않습니다. 부족한 블록은 즉시 생성하거나 일반 상품을 복사해 등록합니다. 원래 상품은 유지하며 새 블록도 단가표 저장 전에는 다른 기기에 반영되지 않습니다.

병원 확인에 따라 모든 과세 블록과 패키지 가격은 부가세 별도 기준입니다. 포함 가격은 공급가로 환산하며 정가=선택 시점의 블록 합계, 판매가=할인액/할인율 적용 결과로 저장합니다. 면세끼리는 면세로 구성하고 면세·과세 혼합은 별도 패키지를 안내합니다. 블록 참조·가격·수량·배치·할인 설정을 옵션에 저장하여 다시 편집할 수 있습니다. 기존 패키지와 가격을 자동 변경하지 않습니다. 환자 안내와 새 장바구니/견적의 구성에도 저장된 회차 및 실제 블록 수량을 사용합니다.

검증: 전체 454테스트/71파일 통과 후 수량 합계 표시 회귀 테스트 추가 및 관련 11테스트 통과(최종 455개). TypeScript/Vite 빌드. 1440/768/390px에서 관심 목록 유지, 숫자 형식, 주소 검색 응답, 재방문 정보 최소화, 달력·시간, 단계별 생성, 미완성 배치 방지, 할인 계산, 드래그 이동, 즉석 블록 등록, catalog.apply 저장, 타입 태그·필터, 입력칸 너비, 가로 넘침·페이지 오류 없음을 검증했습니다. 브라우저 주소 검색은 공급자 응답을 모의하여 개인정보를 외부에 보내지 않았습니다.
