# 0.9.3 · 미용 기준 분류와 홈페이지 상품 대조

이벤트의 신규 상품 분류는 게시된 미용 SSOT의 대분류와 실제 상품 배치를 기준으로 합니다. 상품명·개별 설명·전용 배너를 순서대로 참고하며, 판단이 어려운 상품은 ‘미분류·검토 필요’에 둡니다. 기존 이벤트의 수동 폴더 배치는 홈페이지 재갱신 시 유지합니다. 추천기는 게시된 분류를 사용하며 동일 ID의 이벤트 대분류 이름·순서·색상도 최신 미용 게시본을 따릅니다.

홈페이지의 모든 배너 상세를 조회하여 배너명·분류명뿐 아니라 **개별 상품명에 ‘이벤트’ 또는 ‘EVENT’(대소문자 무관)**가 있는지 검사합니다. 일반 배너 안에서는 해당 상품만 이벤트로 가져옵니다. 이미지 파일은 복사하지 않고 원본 링크로 불러옵니다.

이벤트 하위 폴더 이름의 색상은 마지막 갱신 시 홈페이지 게시 상태를 표시합니다.

- 청록: 홈페이지 게시 확인
- 회색: 홈페이지에서 제외됨
- 보라: 수동 등록 등으로 게시 여부 미확인
- 주황: 여러 게시 상태가 혼합됨

대분류에는 사용자가 지정한 색상을 유지합니다. 게시 여부와 이벤트 기간 종료는 별개이며 기간은 상품에 따로 표시됩니다. 폴더 색상 안내와 마우스를 올렸을 때의 설명을 제공합니다.

미용 홈페이지 대조는 원본 상품 ID와 상품명·옵션·용량·회차를 비교해 일치 항목을 제외합니다. 이름만으로 동일성을 확정하기 어려운 신규 후보는 중복·구성 검토 안내를 붙여 비활성 초안에 추가합니다. 기존 상품의 가격·옵션·폴더·판매 여부는 보존합니다. 새 후보의 가격·부가세·중복·분류를 확인한 뒤 게시해야 상담과 추천기에 판매 상품으로 반영됩니다.
