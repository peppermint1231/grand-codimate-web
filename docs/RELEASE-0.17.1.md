# 0.17.1 — 추천 상품 중복 정리

- 환자 추천에서 같은 이름의 홈페이지·미용 상품이 있으면 홈페이지 상품을 우선하고 미용 상품은 숨깁니다. 가격·할인·옵션 이름 차이로 중복이 남지 않으며, 띄어쓰기·기호 차이를 정규화합니다.
- 4주/8주, 용량·샷 수 등 이름의 숫자는 유지하여 다른 구성은 숨기지 않습니다. 홈페이지 상품이 공개 대상에서 제외되면 미용 상품으로 돌아갑니다. 원본 SSOT나 기존 관심 선택·접수 기록은 변경하지 않습니다.
- 이미 등록된 홈페이지 상품의 ‘홈페이지 가격’ 옵션은 환자 화면에서 ‘이벤트가’로 표시합니다. 다음 홈페이지 갱신으로 생성되는 옵션도 ‘이벤트가’를 사용합니다.
- 전체 413개 테스트, TypeScript 및 프로덕션 빌드 통과. 현재 공개 상품으로 PC·모바일에서 4주·8주 상품 각각 하나만 표시되고, 이벤트가·관심 담기·접수 화면이 정상임을 확인했습니다.
