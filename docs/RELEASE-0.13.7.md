# 0.13.7 · 갱신 복구·상담 가격·멤버십 옵션·동의서 추천

홈페이지 갱신 중 100/101개까지 확인한 뒤 마지막 배너의 응답 오류로 전체 재조회가 필요했던 문제를 보완했다. 원본 홈페이지의 일시적인 403·406 응답, CDN 52x 등 모든 서버 오류, HTML이 아닌 응답을 재시도 가능한 오류로 구분한다. 코디메이트 로그인·권한 오류는 재시도하지 않는다. 실제 HTTP 상태를 오류에 포함하며, 원본 홈페이지의 동일 페이지·동일 상품으로 이동하는 리디렉션만 최대 두 번 허용한다.

한 배너가 끝내 실패해도 다른 배너의 조회를 계속하고, 성공한 상세 결과를 현재 화면 메모리에 최대 10분간 보관한다. ‘실패 항목 다시 확인’을 누르면 분류·목록을 새로 읽어 삭제·추가·이동·이름 변경을 반영하고, 확인되지 않은 상세만 요청한다. ‘홈페이지 갱신’은 항상 처음부터 조회한다. 전체 배너가 확인되기 전에는 동기화 미리보기나 적용을 허용하지 않으며 기존 SSOT를 유지한다. 기한 만료 또는 화면 재진입 시 이전 조회 결과를 재사용하지 않는다.

제보된 ‘비만 부위 집중 패키지’는 홈페이지 분류 2120, 배너 10199이며 조사 시 원본 요청 세 번 모두 HTTP 200/HTML이었다. 지속적인 상품 삭제가 아닌 응답 변동에 견딜 수 있도록 처리했다. 원본 홈페이지가 계속 응답하지 않는 경우 오류를 표시하고 재확인을 제공하며 가격을 추정하거나 실패한 상품을 누락한 채 적용하지 않는다.

## 상담 시 가격 입력

기존 `priceKind: quote`를 ‘상담 시 가격 입력’으로 명확히 표시한다. 상품별 가격 방식과 선택 상품 일괄 수정에서 지정할 수 있으며, 전환 시 기존 고정 가격·정가를 지운다. 부가세는 별도 지정해야 하고 옵션 없는 멤버십 안내나 단순 가격 누락은 자동 전환하지 않는다. 활성 상품의 고정 가격·부가세 검증은 유지한다.

상담 시 해당 상품을 누르면 장바구니가 열리며 빈 가격 입력칸과 사유를 채워야 저장·확정·출력할 수 있다. 필수 입력 여부는 서버가 단가표에서 판정해 상담 항목에 저장하므로 클라이언트에서 해제할 수 없다. 견적서에는 정해진 금액만 표시하고 임의 가격 표시는 추가하지 않는다. 홈페이지 원본이 동일하면 사용자가 설정한 가격 입력 방식도 유지한다. 자동 연장 복사에서는 이전 협의 가격을 재사용하지 않으며 새 상담에서 가격을 입력하도록 안내한다.

## 멤버십 구성 저장

‘구성 추가’ 후 아무것도 입력하지 않은 기본 행(이름 공백·수량 1·기본 단위)은 저장 시 제외한다. 수량·단위를 변경한 행은 삭제하지 않고, 이름 등 누락된 항목을 상품명·원래 행 번호와 한국어 설명으로 안내한다. 화면에서도 즉시 표시하며 기본 이용금액·혜택·조건은 보존한다.

## 옵션별 패키지·멤버십 및 삭제

각 옵션에 패키지·멤버십 구성(회차·이용기간·기본 이용금액·추가 혜택·조건)을 입력할 수 있다. 옵션별 구성이 있으면 상품 공통 구조화 구성 대신 사용하고, 공통 설명·회차별 문구는 함께 표시한다. GOLD/PLATINUM 등급별 판매 가격과 혜택 금액은 별개로 관리하며 선택한 등급의 구성만 서버가 상담·견적에 기록한다. 기존 상담은 옵션 삭제·수정 후에도 저장된 구성과 금액을 유지한다. 옵션별 구성·가격 방식 변경도 수정이력에 기록한다.

옵션마다 삭제 버튼과 확인창을 제공하며 마지막 옵션을 삭제하면 상품을 비활성화한다. 저장 전 되돌리기로 복구할 수 있다. 옵션이 없으면 등급 옵션의 이름·판매 가격·부가세를 입력하라는 안내를 표시한다. 홈페이지 SSOT는 원본 전체 동기화 정책을 유지하므로 병원이 독자 구성하는 멤버십은 수동 관리용 미용 SSOT에서 관리한다.

## 장바구니에 맞는 시술동의서 추천

견적서에서 게시된 최신 동의서를 상품 연결, 시술명·옵션, 실제 구성, 분류 순으로 기계적으로 매칭한다. 동의서 본문의 위험·대안 언급은 추천 근거로 쓰지 않는다. 복합 시술은 관련 양식을 여러 개 추천하며 일치 근거를 보여준다. 초안은 제외하고 동일 계열의 최신 게시 버전만 추천한다. 원래 전체 양식 선택도 유지한다.

개별 양식 선택·보기와 ‘추천 모두 선택’을 제공한다. 모두 선택하면 각 양식의 환자 확인·서명을 개별적으로 받아 저장한 후 다음 양식으로 이동한다. 체크·서명은 자동 입력하지 않으며 양식 전환 시 그리기 영역도 초기화한다. 미저장 체크·서명을 지우는 전환에는 확인을 받는다. 기존 서명 기록에 양식명·버전·한국시간을 표시한다. 별도 LLM 호출이나 토큰 사용은 없다.
