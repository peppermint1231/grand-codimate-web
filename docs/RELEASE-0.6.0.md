# 코디메이트 0.6.0 — 상담·견적 흐름 검토

Android versionCode 10. 기존 앱과 같은 서명 키를 사용합니다.

## 시술 선택

- 시술명·분류·설명에 더해 옵션명과 구성을 검색합니다. 검색어 양끝 공백을 제외합니다.
- 상품 70개 이후를 볼 수 없던 문제를 수정했습니다. 검색 결과 수와 표시 수를 안내하고 ‘시술 더 보기’로 나머지를 선택할 수 있습니다.
- 카테고리는 현재 상담의 미용/보험 구분과 활성 상품에 맞게 표시합니다. 검색 결과 없음과 게시 상품 없음의 안내를 구분합니다.
- 옵션 선택 전에 단위와 VAT 포함·별도·면세 기준을 확인할 수 있습니다. 상품 설명·구성도 작업 중 견적에 포함합니다.
- 기존 상담의 게시 단가표 버전과 저장 가격을 유지합니다. 단가표 없이 만든 상담에서 처음 상품을 선택할 때는 실제 선택한 게시본 버전을 연결합니다. 최신 단가표 가져오기는 수정 권한이 있을 때 사용합니다.

## 견적·저장·확정

- 장바구니와 견적서에서 시술 금액, 할인 합계, 공급가액·면세금액, 부가세, 최종 금액을 동일하게 표시합니다. 기존 항목별 할인 → 전체 할인 배분 → 상품별 부가세 계산 규칙을 유지합니다.
- 수량·할인 오류가 있을 때 과거 합계를 표시하거나 PDF/JPG/인쇄로 내보내던 문제를 수정했습니다. ‘계산 불가’를 표시하고 저장·출력·확정을 차단합니다. 할인 사유 누락도 저장 전에 안내합니다.
- 변경 내용을 저장하고 최신 금액을 확인한 뒤 성공·실패를 확정합니다. 미저장 상태·수정 권한 없음·빈 견적 성공 확정은 버튼에서 차단합니다.
- 서버에서 중복 견적 항목 ID, 존재하지 않는 게시본 버전, 기존 항목의 상품 ID 불일치를 검증합니다. 가격은 서버의 게시 단가와 저장 스냅샷을 사용합니다.
- 상담에서 로그아웃하고 다른 계정으로 로그인했을 때 빈 화면이 나오던 문제를 수정했습니다.

## 검증·검토 대기

자동 테스트 63개와 TypeScript/Vite 빌드, `scripts/verify-consultation-060.ts`의 합성 데이터 브라우저 검증을 수행했습니다. 혼합 과세·할인 배분·원 단위 반올림, 입력 오류, 검색·더 보기, 가로/세로 화면, 저장 후 재열람, 새 단가표 게시 후 기존 가격 유지, 성공·실패 확정, 다른 직원의 읽기 전용 화면을 확인합니다. 실제 병원 OneDrive 저장 및 태블릿 설치 시험은 별도입니다.

단가표는 기존 비공개 Excel 변환 후보 494개 상품·1,043개 가격을 분석했습니다. 모든 후보는 검토 대기 상태이며 실제 운영 게시본을 조회하거나 가격을 변경하지 않았습니다. 정가/원내가/이벤트가 관계, 문장 속 금액, 추가금, 멤버십 적용 관계는 병원 확인이 필요합니다. 원본 위치와 확인 항목은 Git 제외 `private/catalog-review-060.md`에 정리했습니다.
