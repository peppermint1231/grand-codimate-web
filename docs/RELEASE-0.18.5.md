# 0.18.5 — 추천기 상품 설명

추천 카드의 선택 답변 반복 문구를 SSOT 상품 설명으로 교체했습니다. 긴 설명은 세 줄로 접고 펼칠 수 있으며 줄바꿈을 보존합니다. 일반 문자열로 렌더링하여 HTML 실행을 허용하지 않습니다. 상품 편집 칸에 환자에게 공개되는 설명임을 안내합니다. 미용·보험 설명의 금액은 공개 응답에서만 ‘맞춤 상담 후 안내’로 치환하고 원문을 보존합니다. 홈페이지 가격 공개 정책은 유지합니다.

VAT 별도·부가세 포함 등 중복 안내는 설명에서 제거합니다. 팁 비용·제외 부위 등 별도 조건은 유지하고 가격 옆의 세금 안내는 그대로입니다. 홈페이지 갱신 시 원본 서명과 비교하여 병원이 수정한 설명을 보존하되, 수정하지 않은 홈페이지 설명은 최신 원문으로 갱신합니다.

병원 승인에 따라 빈 설명/비용 공지만 있는 154개 상품에 1–2줄 초안을 작성해 바로 적용했습니다(미용 102 / 보험 4 / 홈페이지 48). 기존 설명 정리를 합쳐 524개 상품의 설명만 변경했습니다. 가격·옵션·판매 상태·추천 노출 상태·폴더는 저장 전후 동일함을 검증했습니다. Cd 약어와 루비스타 명칭 등은 임의로 구체화하지 않고 검토 사항으로 남겼습니다. 검토 목록은 `artifacts/상품설명-검토목록.xlsx` 및 HTML이며 SSOT·상품명·분류·설명·검토 항목으로 검색할 수 있습니다. 원본과 변경 내역은 비공개 로컬 스냅샷에 보관했습니다.

적용 직전 최신 게시본과 전체 내용/CAS를 재확인했습니다. 미용 f2e2c3c3-4ada-49b4-9ffe-cef46df11c02, 보험 d0d2281d-d72c-4f5a-b1a0-396f32ed3b44, 홈페이지 46f3d24c-0325-4551-a2c2-c0baeded0aae. 이전 버전은 이력으로 남습니다. 분류 비교에서 VAT 문구 제거로 피코 MLA pore 1회/5회의 기존 모공·피지 설명이 블랙헤드 답변에도 연결되는 2개 변화가 있었고, 새 설명에 의한 다른 고민 확장은 없었습니다.

검증: 443개 테스트(69개 파일) 통과, TypeScript/Vite 빌드 성공. 1440/768/390px 브라우저에서 설명 원문·펼치기·금액 비공개·VAT 제거·HTML 안전 렌더링·가로 넘침 없음을 확인했습니다. 서명 APK 버전 코드 75.

추가: 환자용 패키지 표시를 공통 설명과 옵션별 일정으로 분리했습니다. 단가표는 전체 일정을 한 번 저장하고 옵션 회차 수로 잘라 표시합니다. 구성별 포함 회차를 재집계하여 5회 옵션에 10회 합계가 남지 않게 했습니다. 신규 장바구니/견적 구성 스냅샷에도 같은 함수를 사용하며 과거 상담은 변경하지 않습니다. 관리자 편집에 자동 회차 표시 설정, 옵션 회차 수, 결과 미리보기를 추가했습니다. 환자 화면은 상품명 크기/굵기/대비, 설명 가독성, 주차별 목록, 구성 합계 펼치기와 선택 안내를 개선했습니다.

명확한 51상품/84옵션에 설정을 적용하며, 원문 중복 블록은 내용이 일치하는 경우에만 통합했습니다. 제공 예시의 ED재생레이저 오타만 LED로 정정했습니다. 23상품은 누락·충돌·회차 불일치가 있어 임의 구성을 만들지 않고 관리자 확인 문구와 `artifacts/패키지-회차별구성-검토목록.xlsx`에 남겼습니다. 주차 번호에 빈 구간이 있는 장기 프로그램은 ‘빠짐’인지 간격 진료인지 임의 판정하지 않습니다.

홈페이지 갱신은 VAT 정리, 빈 설명의 결정적 템플릿 초안, 명확한 일정 추출·옵션 범위 확인을 자동 적용합니다. 직접 편집한 설명은 원본과 비교해 보존하고 자동 생성 설명은 갱신된 상품명에 맞춰 재생성합니다. LLM 호출 없음. 최종 전체 447테스트(70파일) 통과 및 3해상도 회차별 표시 확인.
