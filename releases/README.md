[코디메이트 0.2.1 APK 다운로드](https://raw.githubusercontent.com/peppermint1231/grand-codimate-web/main/releases/codimate-0.2.1.apk)

Android 7.0 이상 · versionCode 4 · 기존 앱과 동일 서명. 안드로이드 기기의 브라우저에서 다운로드한 뒤 다운로드 목록에서 APK를 엽니다.

APK는 웹 정적 파일(public/dist)과 분리해 앱 빌드에 이전 APK가 중복 포함되지 않도록 합니다. 빌드 증거와 기능 설명은 docs/RELEASE-0.2.1.md를 참고하세요.

앱 시작 시 배포 서버의 `/api/app-release`를 확인합니다. 이번 버전은 0.2.0 앱의 상단 업데이트 버튼으로 설치할 수 있으며, 설치 후부터 시작 시 자동 알림을 지원합니다.
