# 0.12.2 · 초진설문지 연결 암호화 호환 수정

정상 초진설문지 관리자 비밀번호를 입력해도 연결 확인에서 비밀번호/손상 오류가 나타나던 서버 문제를 수정합니다. 태블릿의 PBKDF2-SHA256 120000회 형식이 Cloudflare 운영 Web Crypto 및 node:crypto의 100000회 제한에 걸렸습니다. 로컬 Node/독립 workerd는 같은 제한을 적용하지 않아 이전 테스트에서 드러나지 않았습니다.

서버의 해당 키 생성만 고정 버전 @noble/hashes 2.0.1의 PBKDF2 구현으로 처리하고, AES-GCM과 기존 salt/IV/120000회 연산을 그대로 유지합니다. 원본 설문지는 변환하거나 다시 저장하지 않습니다. 서버 암호화 처리 실패는 비밀번호 오류와 분리해 503으로 안내합니다.

서버 전용 수정입니다. Android 0.12.1/versionCode42와 웹 화면은 그대로 사용할 수 있으며 APK 재설치가 필요하지 않습니다.

검증: 운영 오류 재현, native PBKDF2 사용 불가 조건에서 기존 암호문 해독/잘못된 비밀번호 거부 회귀 테스트, 서버 오류 분리, 전체 42개 파일 280개 테스트와 빌드 통과.

근거: https://github.com/cloudflare/workerd/issues/1346 및 https://github.com/cloudflare/workerd/pull/7550

배포 완료: 서버 0.12.2, 원격 커밋 `7f2b885229413d0513082f1648b70abc51f75688`. 실제 OneDrive의 같은 자료·같은 관리자 비밀번호로 수정 전 HTTP400 → 수정 후 HTTP200 연결 성공 확인. 연동 설정 저장 완료. 독립 workerd에서 native PBKDF2를 차단한 상태로 복호화 성공(512ms), 운영 정적 파일 48개 일치. APK는 기존 0.12.1을 사용합니다.
