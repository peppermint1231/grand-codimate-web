# 0.18.8 — 패키지 블록 한 줄 표시와 회차 내 순서 변경

회차에 배치된 블록을 이동 손잡이·상품명·회차 선택이 한 줄에 표시되도록 압축했습니다. 긴 이름은 말줄임과 전체 이름 툴팁으로 처리하고, 좁은 화면에서는 회차 컬럼 수를 줄여 컨트롤 너비를 유지합니다.

손잡이를 끌어 같은 회차 내 순서를 바꾸거나 다른 회차의 원하는 위치에 삽입할 수 있습니다. 삽입 위치를 선으로 표시하고 마우스·터치·펜 포인터를 지원합니다. 손잡이에 초점을 둔 뒤 Alt+↑/↓로도 순서를 바꿀 수 있습니다. 단순 클릭은 순서를 변경하지 않습니다. 배열 순서를 패키지 계획과 회차별 구성 설명에 보존하며, 수량 변경 시 남아 있는 기존 블록의 순서도 유지합니다. 같은 블록이 연속될 때만 설명에서 수량을 합쳐 표시합니다.

블록 목록·개별 단가·블록 합계·할인 후 가격·상품 생성 확인 화면의 중복 ‘원’ 표기를 제거했습니다. 기존 상품 데이터나 가격은 변경하지 않습니다.

검증: 전체 456개 테스트/71파일 및 TypeScript/Vite 빌드 통과. 1440/768/390px 브라우저에서 한 줄 정렬과 50px 행 높이, 마우스·터치·키보드 순서 이동, 회차 간 이동, 저장한 구성 순서와 금액, ‘원원’ 미노출을 확인했습니다. 서명 APK와 웹 빌드 자산 48개 일치를 확인했습니다. 배포 검증은 완료 시 추가 기록합니다.
