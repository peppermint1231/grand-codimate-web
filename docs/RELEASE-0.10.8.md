# 0.10.8 — 저장 상태·상담 판매·한국시간 안내

상단 고정 저장 안내를 없애고 상품 편집칸 안으로 저장 상태와 버튼을 옮겼습니다. ‘저장하지 않은 변경사항’, ‘초안 저장됨’, ‘게시됨’을 구분하며 저장할 변경이 없으면 초안 저장 버튼이 비활성화됩니다. 게시 버튼은 저장한 초안에서 사용할 수 있습니다.

상담에 상품을 표시하려면 상품을 선택하고 **선택 상품 일괄 수정 → 상담 판매: 활성화 → 일괄 적용 → 초안 저장 → 검증 후 게시** 순서로 진행하세요. 검토완료와 맞춤 시술 찾기 표시는 상담 판매 활성화와 별도입니다. 옵션명·가격·부가세·검토가 미확정이면 일괄 판매 활성화를 막고 안내합니다. 상품 편집칸에는 초안/게시본의 판매 활성 상품 수가 표시됩니다.

기존 상담이 이전 단가표를 사용하면 시술 선택 영역에서 **최신 이벤트 단가표 불러오기** 등 해당 단가표를 불러올 수 있습니다. 해당 구분의 장바구니가 비어 있을 때만 가능하며, 다른 구분의 장바구니와 작성 중 메모·사진을 유지합니다. 변경한 상담 내용은 기존 상담 저장으로 저장하세요.

버전 목록에서 초안은 마지막 저장 시각, 게시본은 게시 시각을 한국시간으로 표시합니다. 예전 버전에서 복제한 초안에도 원본 버전의 오래된 시각 대신 실제 저장 시각이 나옵니다. 수정 이력 시간도 한국시간으로 통일했습니다.
