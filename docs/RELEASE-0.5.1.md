# 코디메이트 0.5.1 — 사진 설정과 터치 스크롤

Android versionCode 9. 기존 설치와 같은 서명 키를 사용합니다.

- 텍스트 박스의 글자 크기를 숫자 입력과 슬라이더 모두로 조정할 수 있습니다. 두 입력과 사진 미리보기가 함께 갱신됩니다. 투명도 슬라이더 옆에는 현재 백분율을 표시합니다.
- 환자 상담이력을 `상담 종류·날짜 → 대표사진 썸네일 → 상태 → 금액` 순서로 배치했습니다. 여러 대표사진과 정사각형 전체 사진 맞춤은 유지합니다.
- 전체화면 편집기 상단의 닫기 버튼 왼쪽에 사진 편집 저장 버튼을 추가했습니다. 하단 버튼과 같은 저장 동작·활성화 조건을 사용합니다. 최종 보관에는 상담 저장이 필요합니다.
- 비교 크게 보기와 상담 탭 비교 뷰어에서 사진 위를 밀면 스크롤합니다. 사진 순서는 이동 손잡이를 누른 채 끌어 변경합니다. 편집기 왼쪽 썸네일의 드래그 정렬은 유지합니다.

[0.5.1 APK 다운로드](https://raw.githubusercontent.com/peppermint1231/grand-codimate-web/main/releases/codimate-0.5.1.apk)

검증은 `scripts/verify-workspace-050.ts`에 최신 동작을 반영했습니다. 글자 크기 입력 동기화·투명도 표시·상하단 저장 상태·실제 Chromium 터치 스크롤과 순서 유지·손잡이 정렬·이력 표시 순서 및 기존 사진 편집 흐름을 확인합니다. 실제 Android 태블릿 설치 시험은 별도입니다.
