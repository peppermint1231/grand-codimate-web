# 0.18.2 — 상담요청 관리·초진설문지 조회·S펜 입력 보완

상담요청 캘린더 아래 목록에 미배정, 배정, 상담으로 연결된 요청과 완료 항목을 함께 표시합니다. 접수 순서가 최근인 항목부터 10개씩 보고 페이지를 이동할 수 있습니다. 각 행에서 상담자 변경과 삭제를 제공합니다. 연결된 상담의 담당자는 기존 권한대로 담당자 본인 또는 관리자가 변경합니다. 미배정 요청 삭제는 접수 자료와 OneDrive 사본을 제거하며, 연결된 항목 삭제는 캘린더·목록에서만 숨겨 환자와 상담 기록을 보존합니다. 변경 충돌과 삭제 재시도도 처리합니다.

초진설문지의 전체 JSON을 한꺼번에 읽던 32MB 제한을 서버 스트리밍 조회로 대체했습니다. 검색은 이름·연락처 등 메타데이터만 유지하고, 선택한 기록만 복호화하여 환자등록 필드를 전달합니다. 임상 답변·서명·주민번호 원문은 전달하지 않습니다. 기존 파일이 하나의 JSON이므로 서버에서 파일을 순차 조회해야 하지만, 전체 답변을 메모리에 쌓지 않습니다. eTag 기반 60초 메타데이터 캐시, 삭제 기록 반영, 512MB 보관 파일/12MB 개별 레코드 상한을 적용합니다. 원본 설문지는 변경하지 않습니다.

설문지 외부 조회가 상담 저장 대기열을 막지 않도록 분리했습니다. 상담 연결 시 불필요한 단가표 수정 이력 로딩을 제외하고, 현재 게시된 단가표만 사용합니다. 종료된 이벤트는 상담 메모에 남기고 장바구니에서는 제외합니다. 연결 중 안내와 버튼 옆 오류·재시도 표시를 추가했습니다.

Android S펜 버튼의 원시 버튼 비트를 WebView의 보조 버튼으로 변환하고, 버튼 상태를 편집기 도구 표시에도 전달합니다. 기존 작성자별 주석 보호와 버튼 해제 후 펜 복귀 동작은 유지합니다. 이 변경은 새 APK 설치가 필요합니다. 실제 Galaxy Tab/S펜 기기는 작업 환경에 없어 물리 기기 동작을 확인하지 못했습니다.

검증: 전체 431개 테스트(66개 파일), 웹 빌드, Worker 번들 검사. 1440/768/390px 브라우저에서 배정 항목 표시, 10개 단위 페이지, 상담자 변경, 양쪽 유형 삭제, 마지막 페이지 보정, 연결 진행·오류·재시도, 초진 후보 연동을 확인했습니다. CDP 펜 입력과 Android→편집기 상태 이벤트로 임시 지우개·펜 복귀·도중 전환·작성자 보호를 확인했습니다. 합성 자료로 32MB 초과 설문지 스트리밍, 캐시 무효화, 권한, 저장 대기열 분리, 수정 충돌과 보존 동작을 검증했습니다.
