# 0.18.36 — 환자 영구삭제 오류 진단과 연결 자료 검증

OneDrive 영구삭제 실패 시 HTTP 상태만 남기던 처리를 보완해 오류 코드와 요청 ID를 표시합니다. 원문 오류에 들어갈 수 있는 환자명·경로는 저장하지 않습니다. 문서에 명시된 Accept 헤더를 보내며, 영구삭제 요청의 404는 파일 존재 여부를 다시 확인한 뒤에만 완료로 취급합니다. 일반 휴지통 삭제로 대체하지 않습니다. 실제 400 응답의 근본 원인은 배포 후 운영 응답 확인이 필요합니다.

환자목록에서 실패 상태를 ‘정리 중단’으로 표시하고 확인 건수가 삭제 완료 건수가 아님을 안내합니다. 사진 영구삭제는 사진별 의사 코멘트도 제거하며 다른 의사 의견은 보존합니다. 파일 청크 정리는 ID의 `_`·`%`를 SQL 패턴으로 해석하지 않도록 바꿔 다른 파일을 보존합니다.

원격 main의 PR #54에 포함된 지연 메모 수정 차단, 정리 중 백업·폴더/계정 변경 보호, 과거 상담 폴더 추적과 복구 검증을 통합했습니다. 사용법과 변경 안내를 함께 갱신했고 학습 수료 버전·실습 ID는 유지했습니다.

검증 범위:

- 전체 자동 테스트 94개 파일, 597개 테스트: 삭제목록 이동·복원, 범위 6종, 다른 환자 자료 보존, 상담·수납·환불·포인트·서명 연결, 통합 전 기록 정리.
- 가상 Drive와 실제 worker 라우트: 영구삭제 후 두 복구 경로에서 삭제 환자·상담·사진 부재, 다른 환자 보존, 오래된 상담·메모 저장 차단, QR 및 미디어 접근 차단, 중단 후 재시도.
- 원격 삭제 성공 후 정제본 재업로드 실패와 프로세스 재시작, 정리 도중의 새 상담 편집 보존, 파일 ID 특수문자 충돌.
- 사용법 동기화·검사, TypeScript·Vite/PWA 빌드, PC/태블릿/모바일 중단·재시도·완료 화면 검증.

운영 환자를 새로 삭제하거나 운영 복구를 실행하는 테스트는 하지 않습니다. 배포 전후 운영 상태는 섹션별 건수와 해시로 대조합니다. 기존 영구삭제 작업의 실제 실패 원인·재시도 결과는 별도 운영 확인 기록으로 남깁니다. 기기 사본, 다운로드, 외부 설문, 독립 백업 및 통합 전 환자 기본정보 등 잔여 범위는 `PATIENT-DELETION-AUDIT.md`를 따릅니다. Android APK는 이번 웹·서버 패치에서 다시 제작하지 않습니다.
