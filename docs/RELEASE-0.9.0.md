# 0.9.0 · 직무 역할과 권한등급 분리

설정 → 직원·권한에서 두 항목을 따로 지정합니다.

- 역할: 의사 / 코디네이터 / 피부관리사 / 데스크
- 권한등급: 관리자 / 임원 / 일반

역할은 직무를 표시하고 의사 주석·의견 요청 대상 등 임상 기능에 사용합니다. 12개 세부권한의 기본값은 직무와 관계없이 권한등급을 따릅니다.

| 세부권한 | 관리자 | 임원 | 일반 |
|---|---|---|---|
| 환자정보 편집 | 허용 | 허용 | 허용 |
| 금액 열람 | 허용 | 허용 | 허용 |
| 수납 등록 | 허용 | 허용 | 허용 |
| 환불 등록 | 허용 | 허용 | 허용 |
| 금액 정정 | 허용 | 허용 | 허용 |
| 환자 메모 열람 | 허용 | 허용 | 허용 |
| 메모 작성 | 허용 | 허용 | 허용 |
| 등급 지정 | 허용 | 허용 | 허용 |
| 단가표 관리 | 허용 | 허용 | 차단 |
| 통계 | 허용 | 차단 | 차단 |
| 내보내기 | 허용 | 허용 | 허용 |
| 후속 상태 변경 | 허용 | 허용 | 허용 |

세부권한의 개별 허용·차단은 모든 등급에서 기본값보다 우선합니다. ‘등급 기본값 적용’을 누르면 12개 개별 설정을 현재 등급의 기본값으로 초기화하며, 계정 저장 후 반영됩니다. 역할 변경은 권한등급이나 개별 설정을 바꾸지 않습니다. 등급 변경도 기존 개별 설정을 유지합니다.

단가표 CSV·Excel은 **내보내기 + 단가표 관리**, 통계 Excel은 **내보내기 + 통계**가 모두 허용되어야 합니다. 내보내기를 허용해도 해당 기능을 차단하면 그 자료는 내보낼 수 없습니다. 설정 화면에서 자료별 내보내기 적용 상태도 확인할 수 있습니다.

## 등급 전용 기능

설정 화면에 기능 내용과 현재 사용 가능 여부를 표시합니다. 전용 기능은 세부권한 선택지와 별개로 권한등급을 검사합니다.

**관리자 전용**

- 직원 계정 생성·수정·중지, 비밀번호 재설정, 역할·권한등급·세부권한 관리
- 환자 등급명·금액 기준·색상 설정
- 상담 취소·재작성 및 다른 담당자의 상담 수정
- 다른 작성자의 메모·사진 주석 수정, 담당 의사 제한 없는 의견 답변
- OneDrive 연결·저장 폴더 변경, 앱 업데이트 게시

**임원 전용 — 관리자도 사용 가능**

- 환자 삭제·복원·병합
- 동의서 양식 등록·수정·게시
- 암호화 백업 내보내기·OneDrive 원본 복구

임원의 설정 화면에는 동의서 양식과 백업·복구 메뉴만 표시합니다. 계정·권한, 등급 기준, 저장 폴더 변경, OneDrive 연결, 업데이트 게시는 관리자에게만 표시하고 서버에서도 제한합니다. 수납·후속 변경의 담당자 조건, 메모 작성자 조건, 사용 중지 계정 차단은 유지합니다.

## 기존 계정 전환

기존 관리자 계정은 관리자 등급을 유지합니다. 기존 관리자라는 정보만으로 직무를 추측하지 않으며, 직무 미지정으로 표시하고 계정 수정 시 선택하게 합니다. 기존 의사·코디네이터 계정은 해당 직무와 일반 등급으로 읽습니다.

기존 계정의 실제 접근 범위는 필요한 개별 설정으로 보존합니다. 새 등급 기본값을 사용하려면 ‘등급 기본값 적용’ 후 저장하세요. 기본 수납·후속 권한을 개별 허용으로 오인해 다른 담당자의 상담 접근까지 늘어나지 않도록 명시적 허용 여부도 보존합니다. 기존 관리자에서 무시됐던 차단값은 기존의 실제 허용 상태로 전환하고, 이후 새로 지정하는 차단부터 적용합니다.

읽을 때 호환 형식으로 변환하며 저장 전까지 암호화 계정 원본은 변경하지 않습니다. 계정을 저장하면 새 권한등급을 OneDrive에도 저장합니다. 현재 로그인한 관리자의 자기 계정 중지·강등은 차단하며 복구 원본에 활성 관리자 등급 계정이 있는지도 검사합니다. 계정 저장에는 새 권한등급이 필요하므로 앱을 0.9.0으로 업데이트하세요.

검증: 140개 자동 테스트, 직무 4종×등급 3종 기본값, 개별 차단, 기존 권한·담당자 범위 보존, API 권한 상승 차단, 임원 복구·일반 복구 차단, 신규 계정 생성·재로그인·메뉴 제한·모바일 표시. `tests/permission-levels.test.ts`, `tests/account-levels-api.test.ts`, `scripts/verify-permission-levels-090.ts` 참고.
