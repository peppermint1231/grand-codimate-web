# 초진설문지 환자 불러오기

코디메이트의 **새 환자 등록 → 초진설문지에서 환자 불러오기**에서 이름 또는 전화번호를 검색한다. 설문지를 선택하면 이름, 성별, 생년월일, 전화번호, 주소, 내원경로를 등록 양식에 채운다. 내용을 확인하고 저장하면 기존 환자 등록·감사·OneDrive 백업 경로를 사용한다.

## 처음 연결

관리자 계정으로 환자 불러오기를 열고 **초진설문지 연동 설정**에 다음을 입력한다.

- OneDrive 폴더: 기본 `동의서/초진설문지`
- 초진설문지 관리자 비밀번호: 설문지 환자목록을 열 때 쓰는 비밀번호. APK 서명 비밀번호와 별개다.

코디메이트에 연결한 OneDrive 계정에서 `<폴더>/data/records.json`을 읽을 수 있어야 한다. 연결 확인 시 파일과 암호화 기록 한 건을 확인한 후 비밀번호를 서버의 암호화된 secrets 저장소에 보관한다. 일반 직원에게 비밀번호를 반환하지 않는다. 서버를 새로 복구한 경우 이 연동 설정은 다시 입력한다.

## 중복과 누락 정보

- 코디메이트에 같은 이름·생년월일 또는 같은 전화번호가 있으면 후보를 표시한다. 기존 환자를 선택하면 최신 코디메이트 자료를 조회한 뒤 해당 환자를 연다.
- 가족 연락처·동명이인은 자동 병합하지 않는다. 별도 환자임을 확인한 경우에만 새 등록 양식으로 불러온다.
- 동일 설문지의 등록 ID는 고정되어 두 직원이 동시에 등록해도 같은 설문지로 환자 두 명이 생성되지 않는다. 동시 등록 충돌 시 다시 검색하면 기존 환자를 선택할 수 있다.
- 보관된 환자는 복원 필요를 안내한다. 이미 가져온 설문지로 새 환자를 다시 생성하지 않는다.
- 주민/외국인등록번호에서 유효한 생년월일을 얻을 수 없으면 생년월일을 비워 직접 보완한다. 나이로 생년월일을 추정하지 않는다.
- 검색 때마다 OneDrive 원본을 다시 읽고 삭제 이력을 적용한다. 선택 전에 삭제된 설문지는 불러오지 않는다.

## 데이터 범위와 제한

검색은 기존 파일의 이름·전화번호 메타데이터를 사용하고 선택한 기록만 PBKDF2-SHA256(120000회)/AES-GCM으로 복호화한다. 목록은 30건씩 표시한다. 주민등록번호 원문, 서명, 병력, 동의서 본문은 브라우저에 보내거나 코디메이트 환자에 복사하지 않는다. 원본 설문지에는 쓰지 않는다. 전체 파일은 32MiB까지 지원하고 초과 시 오류를 안내한다. 검색어와 비밀번호는 접근 이력에 남기지 않는다.

## 통합 릴리스

0.12.0의 견적서·가격·의사 의견 변경(d22b2ba)과 환자 불러오기 변경(57c9aa8)을 별도 작업 폴더에서 병합했다. 통합 버전은 0.12.1, Android versionCode는 42다. 다른 작업의 미커밋 파일은 변경하지 않았다.

## 검증

- `npm run check`: 42개 테스트 파일, 278개 테스트 통과 및 TypeScript/Vite/PWA 빌드 성공.
- `tests/intake.test.ts`: 암호화 호환, 개인정보 최소화, 내외국인 날짜, 삭제 이력, 로그인/관리자 권한, 암호화 설정, 오류 시 설정 보존, 검색/선택, 일반 등록 경로, 중복 등록 방지, 기존/보관 환자 후보, 페이지 및 연동 해제 검증.
- 별도 Vite 포트 5197에서 `npx tsx scripts/verify-intake-import.ts`: 합성 API 데이터로 실제 앱의 연결 설정, 자동 입력, 등록, 삭제된 설문지 오류, 기존 환자 열기를 1024×1366과 390×844에서 검증. 가로 넘침·브라우저 오류 없음. 결과는 `artifacts/intake-browser.json` 및 화면 PNG에 저장.
- 실제 환자 정보나 운영 OneDrive를 사용한 조회·등록, 물리 Android 설치 검증은 수행하지 않았다.
