# 0.18.17 · 법정동 지역 통계와 전국 지도

도로명 조회로 얻은 법정동과 기존 행정동 표기가 별도 집계되던 문제를 해결했다. 춘천 후평1·2·3동은 후평동, 효자1·2·3동은 효자동으로 합산하고 시도 약칭·옛 명칭도 통일한다. 원본 주소와 환자·수납 기록은 수정하지 않는다. 저장된 지역 집계 행을 읽을 때 통일하므로 6만 명 환자 원본 재조회나 인덱스 재구축이 필요하지 않다. 이후 변경되는 주소에도 같은 규칙이 적용된다.

전체 환자 지역에 시·군·구, 춘천 동·읍·면, 유입 권역 도넛을 추가했다. 선택하면 상세 막대그래프와 해당 지역 지도가 열린다. 전국 → 시도 → 시군구 → 법정동으로 확대하고 단계별 복귀, 확대·축소, 방향 이동, 키보드 선택을 지원한다. 100명 미만 묶음 목록은 접어서 보존하며 지도는 묶기 전 합계를 사용한다. 주소 미입력·확인 필요는 비율 분모에서 제외하고 인원을 표시한다.

지역 인구 대비가 아닌 환자 수 지도이다. 로그 색상 척도로 편중을 완화하며 실제 인원·비율을 같이 표시한다. 법정동 경계가 확인되지 않는 행정동/주소는 상위 지역 합계에 포함하되 동 지도에 임의 배정하지 않는다. 전국 경계는 V-World 2023 배포 자료의 출처 표시 조건 GeoJSON 가공본이며, 화면에 기준 연도·출처를 명시했다. 268개 정적 지도 파일은 선택한 범위만 지연 로드하고 최대 32개 메모리 캐시를 사용한다. 지도 조회에 환자 정보 전송, 별도 지도 API 키, LLM 호출은 없다. 원본 해시를 고정한 생성 스크립트와 NOTICE를 포함한다.

환자 Excel에 시군구·권역·법정동 상세 시트를 추가했다. LLM 프롬프트에는 새 원시 세부 집계를 넣지 않아 기존 소수 집계 보호를 유지한다. Android 87 / 0.18.17.

검증: 82개 파일의 501개 테스트 및 TypeScript/Vite 빌드 통과. 기존 SQL 집계 행만으로 통합하며 원본 재조회·집계 행 변경이 없음을 검증했다. 지도 17 시도/250 시군구/5,065 법정동과 부모-자식 파일 연결을 검증했다. 브라우저 1440/800/390px에서 전국→강원→춘천→후평동, 키보드 선택, 도넛→상세 막대, 가로 넘침 없음을 확인했다.
