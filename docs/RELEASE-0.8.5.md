# 0.8.5 · 편집 단축키와 폴더 단계 이동

폴더 목록 수정 또는 상품 초안 편집을 시작하면 되돌리기 옆에 **? 배지**가 나타납니다. 누르면 기능별 단축키 안내가 열리며, `?`로도 열 수 있습니다. 안내는 모바일에서도 스크롤해 볼 수 있으며 Escape·닫기로 닫으면 배지로 초점이 돌아옵니다.

| 위치 | 동작 | 단축키 |
|---|---|---|
| 공통 | 저장 / 되돌리기 / 다시 실행 | Ctrl+S / Ctrl+Z / Ctrl+Shift+Z 또는 Ctrl+Y |
| 폴더 목록 | 새 폴더 / 이름·색상 / 삭제 확인 | Alt+N / F2 / Delete |
| 폴더 목록 | 위·아래 순서 이동 | Alt+↑ / Alt+↓ |
| 폴더 목록 | 상위 단계로 꺼내기 / 이전 형제 폴더 안으로 넣기 | Alt+← / Alt+→ |
| 폴더 목록 | 지정한 위치로 이동 / 복사 / 링크 | Alt+M / Alt+C / Alt+L |
| 폴더 목록 | 복사 / 잘라내기 / 선택 위치에 붙여넣기 | Ctrl+C / Ctrl+X / Ctrl+V |
| 폴더 목록 | 선택 위치에 링크 붙여넣기 | Ctrl+Alt+V |
| 폴더 목록 | 링크 원본으로 / 최상위 선택 | Alt+G / Alt+Home |
| 폴더 목록 | 선택 상품을 지정한 위치로 이동 | Alt+P |
| 폴더 목록 | 이름 적용 / 이름·확인 창 취소 / 전체 편집 취소 | Enter / Escape / Alt+Escape |
| 폴더·상품 목록 | 모두 접기 / 모두 펼치기 | Alt+1 / Alt+2 |
| 상품 목록 | 전체 선택 / 선택 해제 | Ctrl+A / Ctrl+Shift+A |
| 상품 목록 | 새 상품 / 선택 가격 조정 / 선택 비활성화 | Alt+N / Alt+R / Alt+D |
| 상품 목록 | 붙여넣기 후보 행 추가 / 검증 후 게시 | Alt+V / Ctrl+Shift+Enter |
| 상품 편집 창 | 옵션 추가 / 상품 복제 / 내용 유지하고 닫기 | Alt+N / Alt+C / Alt+Enter |

- Mac에서는 Ctrl 대신 Cmd, Alt 대신 Option을 사용합니다. 작업할 목록을 먼저 클릭하세요. 입력칸에서는 일반 글자 편집을 유지하며 Tab으로 벗어나 명령을 사용합니다. 저장·상품 실행 취소는 입력 중에도 지원합니다. 한글/Option 문자 입력 배치에서도 명령 키의 물리 위치로 판별합니다.
- 폴더 순서·단계 이동 버튼도 함께 제공합니다. 상위로 꺼낸 폴더는 부모 바로 뒤에 놓습니다. 이동 후 선택·초점을 유지합니다. 더 이상 이동할 수 없는 경계에서는 브라우저 뒤로 가기를 실행하지 않습니다.
- 기존 폴더 이동 알고리즘을 공유하므로 깊이 제한·순환 참조 차단·중복 이름 합치기/덮어쓰기 확인이 유지됩니다. 연결된 가상 하위 폴더는 원본으로 이동해 편집합니다. 저장 전 되돌리기/다시 실행이 가능하며 폴더 저장 시 SSOT와 추천기에 반영됩니다.
- 삭제·게시·편집 취소의 확인 절차를 유지합니다. 안내·이력·이름 입력·충돌/삭제 확인 중에는 뒤쪽 편집 명령을 막습니다. 읽기 화면에서는 편집 명령을 실행하지 않습니다.
- 전체 상품 화면에서 새 상품을 추가할 때 실제 첫 폴더를 지정하도록 수정했습니다. 폴더가 하나도 없으면 폴더를 먼저 만들어야 합니다. 지정 폴더에서 추가할 때는 그 폴더를 사용합니다.

검증: `tests/catalog-arrow-shortcuts.test.ts`, `scripts/verify-catalog-shortcuts-085.ts`, 공유 링크 회귀 `scripts/verify-catalog-links-084.ts`. 테스트는 격리된 로컬 자료를 사용하며 운영 검증에서는 임시 편집 후 취소합니다.
