# 0.13.9 · 환자용 동의서 문구와 모두 동의

시술별 세부 주의사항의 기존 병원 기준·검토용 표현을 환자에게 직접 안내하는 문장으로 정리했다. 구체적인 기간, 합병증, 이상 증상과 연락 방법은 유지한다. 요청한 패키지 1년 사용·잔여 횟수 소멸 문구와 일반 시술 필수 확인 6개 항목을 개정 초안에 반영하고 중복되는 본문 확인·환불 문단을 삭제했다. 기존 양식에서 확인한 문구만 치환하며 병원이 추가한 별도 문장과 상품 연결은 유지한다. 약물치료의 피임·임신 검사·헌혈 금지 확인 항목은 유지한다.

책임 면제, 회차별 50%·30% 환불 및 3회 이후·개인 사유 환불 제한은 사용자가 제공한 원문을 반영한 계약 초안이다. 법적 효력을 보장하지 않는다. 약관법 제7·9·14조에 따른 무효 가능성과 전문가 검토 안내를 관리자 화면에 분리했다. 닥터플랜은 본인 사용·양도 제한·계약 기간과 시술 계획 조정, 멤버십은 등급별 기간·보험 진료 제외·혜택금 현금 환급 제외·실결제금과 사용 내역 기준 정산을 유지하며 회차별 패키지 환불률을 일괄 적용하지 않는다.

개정 기준 `2026-10-02.1`. 이미 게시된 양식은 별도 개정 초안을 만들며 게시본 및 서명 당시 스냅샷은 변경하지 않는다. 최신 미게시 .2~.4 초안은 내용을 보완하고 재설치해도 중복 생성하지 않는다. 기존 검토 후 게시 흐름은 유지한다.

서명 화면의 필수 확인 항목에 ‘모두 동의’를 추가했다. 기본 미선택, 부분 선택 표시, 전체 해제, 개별 체크 연동, 다음 양식 전환 시 체크·서명 초기화를 지원한다. 모든 필수 항목과 직접 서명이 있어야 저장할 수 있다. 서버도 각 필수 확인과 서명 스냅샷을 계속 검증한다.
