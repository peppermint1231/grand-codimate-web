# 0.8.6 · 직원 권한 설명

설정 → 직원·권한에서 계정을 선택하거나 계정 추가를 누르면 12개 권한 이름 아래에 실제 기능과 적용 범위를 표시합니다. 수납·환불 등록의 의미, 금액 정정의 기록 보존, 등급 지정과 관리자 기준 설정의 구분, 단가표 편집·게시·복원 범위 등을 설명합니다.

‘역할 기본값’ 선택지에 허용·차단을 함께 표시하며, 각 항목 아래에는 현재 선택 기준의 적용 상태를 표시합니다. 역할이나 개별 설정을 바꾸면 즉시 갱신되고, 계정 저장 후 실제 반영됩니다. 기존 `allowed` 함수를 사용해 서버와 같은 기준으로 표시합니다.

관리자 역할이 개별 차단보다 우선한다는 안내와 사용 중지 계정의 차단 상태를 표시합니다. 현재 권한 목록과 권한 판정 방식은 변경하지 않았습니다. 설명은 항목을 펼치지 않아도 보이며 모바일에서는 설명 아래에 선택지를 배치합니다.
