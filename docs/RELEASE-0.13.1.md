# 0.13.1 · 단가표 버전 식별 보강

0.13.0의 홈페이지 SSOT 전체 연동, 미용 독립 구성 및 일괄 검토 개선을 포함한다. 미용 독립 구성 게시 시 날짜만 사용하던 버전명을 게시 시각과 작업 ID로 구분한다. 같은 날 분리를 다시 수행해도 상담의 단가표 버전 참조가 겹치지 않는다. 기존에 저장된 상담·가격·단가표 버전은 변경하지 않는다.

검증: 0.13.0 전체 311개 테스트·웹/반응형 브라우저 검사에 이어, 게시 버전 분리 회귀 검증을 포함한 홈페이지 단가표 테스트 12개와 웹 재빌드. 운영 자료 분리는 0.13.0에서 2개 명령으로 완료했고 이 보강 배포에서는 다시 실행하지 않는다.

운영 검증 완료: 웹/API 0.13.1 및 GitHub 검사·Workers 배포 성공. 운영 파일 48개와 빌드 결과가 일치하며, 서명 APK(코드 54)의 공개 다운로드와 SHA-256을 확인했다. 실제 Android 기기 설치 검사는 수행하지 않았다.

운영 브라우저에서 홈페이지 기본 선택, 전체 645개 중 현재 홈페이지 게시 417개, 미용 503개 유지, 미검토 463개 선택, 미용 갱신 UI 제거, 추천기 홈페이지 표기를 확인했다. 1440/768/390px 화면에 가로 넘침·스크립트 오류가 없었으며, 확인 중 업무 데이터 쓰기는 0회였다. 홈페이지 갱신 결과는 검토용 초안이고 기존 게시본은 유지한다. 전체 검증 기록: `artifacts/deployment-0.13.1.json`.
