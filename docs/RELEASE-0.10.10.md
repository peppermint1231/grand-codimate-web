# 0.10.10 — 상담 화면·견적서 출력·환자 동의

정가·할인가가 함께 있는 상품을 장바구니에 담으면 두 가격을 함께 기록합니다. 시술 금액은 정가×수량, 상품 할인은 (정가 합계−할인가 합계)이며, 추가 할인과 전체 할인은 할인가에서 차감합니다. 공급가액과 부가세는 기존 상품별 포함/별도/면세 기준에 따라 할인 후 금액으로 계산합니다.

예: VAT 별도, 정가 100,000원·할인가 70,000원 상품 1개는 시술 금액 100,000원, 상품 할인 30,000원, 공급가액 70,000원, 부가세 7,000원, 최종 안내금액 77,000원입니다. VAT 포함 상품은 할인가에서 부가세를 분리하며 중복 가산하지 않습니다.

장바구니·견적서 화면·병원용 PDF·환자용 JPG에 정가, 상품 할인, 할인가와 합계를 표시합니다. 합계에는 상품 할인과 추가·전체 할인을 구분합니다. 상품의 기본 할인에는 별도 사유 입력을 요구하지 않으며, 추가 할인과 확정 상담 변경은 기존 사유 입력 규칙을 유지합니다.

기존 저장 상담은 당시 금액과 가격 기록을 유지합니다. 정가 기록이 없던 기존 항목에 최신 정가를 소급 적용하지 않습니다. 새로 담거나 연장한 상품은 선택한 게시 단가표의 정가를 기록하며 이후 단가표 변경에도 상담 가격을 유지합니다. 정가 미확정 또는 판매가보다 낮은 자료는 할인으로 표시하지 않습니다.

상담 오른쪽 컬럼은 시술 선택만 표시합니다. 하단의 메모·의견 요청·장바구니 버튼을 누르면 각각 팝업이 열립니다. 닫았다 다시 열어도 입력 내용과 수량·할인 변경은 유지되며, 상담 저장 버튼으로 사진·메모·견적을 함께 저장합니다. 의견 요청은 보내기 버튼으로 별도 전송합니다.

상담 상단의 영문 문구와 넓은 여백, 사진/시술 선택 등의 바로가기 줄을 제거했습니다. 상태 배지는 환자명 옆에 표시하고, 환자 상세와 상담에 성별·나이를 함께 표시합니다. 사진 헤더는 사진 수·선택/추가·크게 보기를 한 줄로 배치했습니다.

사진뷰어 아래의 높이 조절 막대를 마우스·터치로 끌거나 위/아래 방향키로 조절하세요. 초기화 버튼으로 기본 높이로 돌아갑니다. 사진을 누르면 해당 사진만 크게 보이며, 아래 썸네일로 다른 사진을 선택하거나 전체 비교로 돌아갈 수 있습니다. 사진의 상담 포함 여부와 순서는 바뀌지 않습니다.

화면 상단 ‘가’ 버튼에서 UI 글자 크기를 80~120%로 조절할 수 있습니다. 작게 85%·기본 100%·크게 115% 프리셋을 제공하고, 글자 크기와 뷰어 높이는 이 기기에 저장합니다. 사진 주석과 PDF/JPG 출력 글자 크기는 이 설정의 영향을 받지 않습니다.

상담에 진입하면 PC·태블릿의 왼쪽 메뉴가 부드럽게 접힙니다. 상단 메뉴 펼치기로 다시 열 수 있습니다. 휴대폰 하단 메뉴는 유지하며, 기기의 동작 줄이기 설정에서는 애니메이션을 생략합니다.

병원용 PDF의 한글 글자가 빠지던 문제는 글꼴 축약 삽입 과정에서 발생했습니다. 정적 한글 글꼴 전체를 포함하도록 수정하고 PDF를 실제 이미지로 변환해 글자·숫자 표시를 확인했습니다. Android에서는 저장 위치를 고르는 시스템 창을 열며, 여러 JPG는 폴더를 선택해 함께 저장합니다. 웹에서는 여러 페이지를 각각 저장할 수 있습니다. 저장 취소·실패 시 재시도 버튼을 제공합니다.

환자용 견적서는 **03 견적서 → 환자용 JPG·인쇄·QR → 유출방지 안내 확인 → 환자 본인 서명 → 동의·서명 저장** 순서입니다. 저장되지 않은 상담 변경이 있으면 먼저 저장합니다. 동의 후 JPG 다운로드, 서명된 견적서 인쇄, QR 다운로드 링크 발급을 사용할 수 있습니다. 동의 문구·서명자·시각·서명 이미지가 모든 JPG 페이지에 포함되며, 시술·수량·금액·환자명 등이 변경되면 다시 서명받습니다. 메모·사진만 변경하면 견적서 서명은 유지됩니다. 한 페이지에는 시술 최대 6개를 배치합니다.

QR 다운로드 링크는 발급 시점부터 **7일** 유효합니다. 환자는 로그인 없이 견적서 페이지만 다운로드합니다. ‘발급된 링크 관리’에서 즉시 만료할 수 있고, 견적 변경·환자 보관/병합·발급 직원의 내보내기/금액 권한 해제에도 접근을 차단합니다. 링크와 파일은 환자 본인에게만 전달하세요. 링크 만료는 이미 내려받은 파일을 삭제하지 않습니다.

동의·서명 기록은 기존 암호화된 상담 저장/OneDrive 동기화에 포함됩니다. 다운로드 링크와 이미지 사본은 서버에 암호화하여 임시 저장하고 만료 시 정리합니다. 백업을 복구하면 이전 다운로드 링크는 폐기되므로 새로 발급합니다. 환자용 출력은 서버에 동의 기록과 내보내기 확인을 저장할 수 있는 온라인 상태에서 사용합니다.
