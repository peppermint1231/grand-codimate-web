# 0.13.3 · 보험 SSOT 급여·실비 구분 및 조갑백선 단가표

병원 제공 이미지 2장의 레이저 베이직·프리미엄, 제균 단독, 조갑백선 피부밀봉붕대요법(Fu) 4개 상품·7개 옵션을 보험 SSOT의 급여/비급여 폴더에 추가한다. 기존 보험 항목·가격과 다른 SSOT는 보존한다. 병원 확인에 따라 신규 옵션은 모두 면세다.

베이직은 1회 16만원, 10회 정가 160만원/할인가 144만원이고 프리미엄은 1회 20만원, 10회 정가 200만원/할인가 180만원이다. 둘 다 비급여·실비 청구 가능으로, 단독 제균은 5만원·비급여·실비 불가로 표시한다. 주기와 1·6회/2·7회/3·8회/4·9회/5·10회 시술 구성을 원자료대로 기록한다.

드레싱은 급여·실비 청구 가능이며 1회 1지 환자 본인부담금 3,330원, 공단 청구액 7,770원을 분리한다. 10발가락+COSCAN 예시는 환자 부담 37,200원(33,300원+전자 치료비 3,900원), 공단 청구액 77,700원이다. 공단 청구액은 참조 정보이며 장바구니·견적 계산에 더하지 않는다. ODT 구성, 3~4주 간격, 실비 미가입/한도 초과·거절·내원 어려움·3 Cycle 이상 추적 관리 대상 설명을 보존한다.

급여 구분, 실비 청구 가능 여부, 확인 조건을 상품 편집에서 수정할 수 있고 단가표·상담 시술 선택에 배지로 표시한다. 급여를 실손보험금 지급 보장으로 오인하지 않도록 약관·특약·공제금액·보험사 심사에 따른다는 설명을 제공한다. Excel 내보내기에 구분·실비 안내·공단 청구액을 포함하며 변경이력에도 기록한다. 검토 근거: 금융위원회 4세대 실손 안내 https://www.fsc.go.kr/no010101/76157

검증: 49개 파일/319개 테스트, 웹 빌드, PC 1440·태블릿 768·모바일 390px에서 표시·편집·상담 화면 확인. 서명 APK 코드 56. 실제 Android 기기 설치 검사는 수행하지 않았다.

운영 등록·게시 완료: 기존 보험 검토 대기 4개 유지, 신규 상품 4개·옵션 7개 추가(급여 1개/비급여 3개). 신규 4개는 모두 활성·면세, 실비 청구 가능 3개/불가 1개다. 기존 단가표 버전 및 그 외 업무 데이터가 유지됐고 서버 대기 0건이다. 실제 운영 화면에서도 8개 전체 항목, 급여·실비 배지, 공단 청구액과 상품 편집 입력값, 3개 화면 너비를 읽기 전용으로 확인했다. 업무 명령은 저장·게시 2회, 확인 중 추가 업무 쓰기는 0회였다. 운영 웹 파일 48개와 공개 APK 해시도 로컬 빌드와 일치한다.

배포 시 앱과 같은 버전 번호의 의존성까지 변경된 lockfile 오류는 원래 regjsparser 0.13.2로 복구했다. 격리된 새 설치와 최종 GitHub/Workers 검사 모두 통과했다. 전체 검증 기록: `artifacts/deployment-0.13.3.json`.
