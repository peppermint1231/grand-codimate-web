# 0.12.7 · 동의서 검토 항목 작성 예시

빨간 검토 항목 아래에 항목별 작성 방법과 문장 예시를 추가했다. 연락처/진료시간, 시술별 확인사항, 계약 기간·차감·양도·환급 기준을 구분해 표시한다. 병원이 직접 추가한 검토 항목에도 일반 작성 안내를 제공한다.

예시는 별도 도움말이며 기존 동의서·서명을 변경하지 않는다. 예시의 미확정 값은 기존 검토 표식으로 남겨 수동으로 복사한 미완성 예시도 바로 게시할 수 없도록 한다.

검증: 44개 테스트 파일·288개 테스트 및 웹 빌드 통과. 기본 23종의 모든 검토 표식에 전용 예시가 제공되고 미완성 예시는 게시가 차단됨을 검사했다. 1440/768/390px 브라우저에서 예시 표시·본문 보존·미리보기 분리·편집 위치 이동·게시 검증·가로 넘침 없음 확인.
