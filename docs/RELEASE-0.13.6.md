# 0.13.6 · 상담 이탈 보호와 홈페이지 갱신 안정화

상담에서 환자 상세·다른 메뉴·뒤로가기·로그아웃으로 이동할 때 보류 저장, 성공·실패 완료, 계속 상담을 선택한다. 저장 실패 시 이동하지 않으며 성공·실패 선택도 변경 내용을 먼저 저장한다. 브라우저 창 닫기·새로고침은 브라우저 기본 확인창으로 보호한다. 브라우저가 강제 종료되는 경우에는 확인창을 보장할 수 없다. 암호화 기기 보관이 설정되어 있으면 상담 초안을 즉시 기록하고, 암호화 쓰기 순서를 보장하여 이전 초안이 최신 초안을 덮어쓰지 않게 한다.

환자 상세의 상담이력과 전체 상담이력에 성공 확정 상담의 미수납 금액을 강조한다. 부분 수납·환불·정정은 기존 원장 계산을 사용하고 전액 수납·취소·실패·보류 상담에는 표시하지 않는다. 금액 열람 권한이 없으면 금액과 미수납 표시를 숨긴다.

홈페이지 응답 대기를 15초에서 45초로 늘리고 일시적인 연결 실패는 해당 페이지를 최대 두 번 자동 재시도한다. 읽기 전용 외부 홈페이지 조회를 병원 자료 저장 대기열에서 분리하되 로그인·단가표 권한 검사는 유지한다. 한 페이지라도 실패하면 부분 결과를 단가표에 적용하지 않는다.

단가표의 별도 검토완료 체크를 제거했다. 비활성으로 등록한 상품을 확인하고 판매 활성으로 바꿔 저장하면 된다. 가격·옵션·부가세 등의 필수 입력 검사는 유지한다. 홈페이지 갱신은 기존 활성·비활성 선택을 유지하며 새 상품·가격 또는 구성 변경 상품은 비활성으로 등록한다. 홈페이지에서 삭제된 항목은 최신 목록에서 제외하지만 이전 버전과 상담은 보존한다. 내부 과거 데이터의 review 필드는 호환성 때문에 남지만 판매 여부를 차단하지 않는다. 기존 운영 SSOT를 일괄 변경하는 마이그레이션은 수행하지 않는다.
