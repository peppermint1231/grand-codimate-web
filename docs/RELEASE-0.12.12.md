# 0.12.12 · 서명 없는 동의서 영구삭제

설정 → 동의서 양식에서 저장된 초안과 게시본을 영구삭제할 수 있다. 이전 게시본은 ‘이전 초안·게시본 함께 보기’를 켜고 선택한다. 본문 아래에 받은 서명 건수와 ‘양식 영구삭제’를 표시하며 확인창을 거친다. 서명 기록이 하나라도 있으면 비활성화한다. 관리자·임원의 동의서 관리 권한을 그대로 적용한다.

서버가 삭제 시 전체 서명을 다시 확인하고 양식 버전을 검사한다. 상담 취소나 버전 차이가 있어도 해당 양식 ID의 서명은 삭제를 막는다. 서명 저장과 삭제를 직렬 처리하여 동시 요청에서도 기록을 보호한다. 개정 초안은 함께 삭제하지 않는다. 삭제 후 오래된 편집 요청으로 같은 양식이 재생성되는 것도 차단한다.

삭제 변경을 기기 캐시·서버 저장·OneDrive 변경 기록·일반/단계별 복구에 반영한다. 네트워크 실패 시 삭제 성공으로 표시하지 않고 암호화 대기열에 보관한 경우에만 동기화 대기를 안내한다. 작업 이력은 남으며 과거 암호화 백업 파일을 소급하여 지우는 기능은 아니다. 삭제 기록을 포함한 복구에서는 삭제한 양식을 되살리지 않는다.

검증: 자동 테스트 48개 파일·305개 통과, 웹 및 서명된 APK code52 빌드. 합성 데이터로 무서명 게시본/초안 삭제, 권한·확인·리비전 검사, 서명 보호, 동시 요청, 재전송, 캐시 삭제, 두 복구 경로를 검사한다. 실제 운영 양식은 검증 과정에서 삭제하지 않는다.
