# 시술동의서 초안 검토 안내

작성 기준: 2026-09-30.2. 병원 검토용 초안이며, 검토 및 게시 전에는 환자 서명에 사용할 수 없다.

## 사용 순서

1. 관리자·임원 계정에서 설정 → 동의서 양식을 연다.
2. 초안 등록·업그레이드를 누른다. 최신 보완본 23종을 등록하며, 이전 초안·게시본·서명은 유지한다. 동일 작성 기준의 초안은 중복 등록하지 않는다. 이전 초안은 ‘이전 초안 함께 보기’에서 확인한다.
3. 목록의 양식을 열어 본문과 필수 확인 항목을 수정한다. 초안 저장은 게시와 다르다.
4. 빨간 ‘검토 필요’ 목록에서 항목을 누르면 해당 편집 위치가 선택된다. 미리보기의 빨간 강조 부분과 본문·필수 확인 항목의 `[병원 확인: …]`을 실제 제품·장비·부위별 기준과 병원 연락처로 대체한다. 참고 자료는 편집 화면의 ‘검토할 내용·참고 자료’에서 확인한다.
5. 담당 의료진이 검토한 내용을 확인하고 ‘검토 완료·게시’를 누른다. 수정하면 검토 확인은 해제된다.
6. 상담의 시술동의서에서 게시된 양식을 선택하여 설명·확인·전자서명을 진행한다.
7. 게시 후 변경이 필요하면 ‘복제하여 수정’을 사용한다. 원본과 기존 서명은 유지하고 새 버전을 초안으로 저장한다.

각 양식은 목적·방법, 효과의 한계·대안, 부작용·위험, 사전 고지, 사후 관리·연락, 환자의 선택, 필수 확인 항목으로 구성한다. 일반적인 위험 설명을 제공하며 개별 제품의 위험을 모두 망라하지 않는다. 권리 포기나 병원 책임 면제 문구는 포함하지 않는다. 홍보 사진 동의·개인정보 동의·견적서 유출방지 동의는 별개다.

## 의료진이 보완할 내용

- 실제 사용 제품의 성분·국내 허가 목적·부위·투여 경로, 장비의 사용설명서와 금기.
- 환자별 진단·계획·부위·용량·회복기간·개인별 추가 위험 및 설명한 의사/시술 의사의 기록. 양식만으로 이 진료기록을 대신하지 않는다.
- 제품별 허가 외 사용 여부와 필요성, 대안·위험 설명. 해외 허가를 국내 허가로 취급하지 않는다.
- 마취·응급 대응·전원·야간 연락 체계 및 법정대리인이 필요한 경우의 절차.
- 복합 상품의 각 구성 시술에 맞는 별도 설명. 상품명 자동 연결은 하지 않으며, 해당 시술에 필요한 게시 양식을 각각 선택한다.

이 초안은 특정 병원의 확정 양식이나 법적 적합성의 보증이 아니다. 출처는 FDA·AAD·ASPS·NHS의 환자 안전 자료이며 각 양식에 연결되어 있다. 국내 제품 허가와 개별 시술의 의학적 적합성은 병원에서 확인한다.

## 구현·검증

본문 원본: `src/core/treatmentConsents.ts`. 관리자·임원만 초안 등록/수정/게시 가능. 서버에서 미확정 표식, 필수 확인 항목, 검토 확인과 수정 충돌을 검사한다. 게시본은 불변이며 복제본에는 새 버전이 부여된다. 게시 담당 계정과 시각을 기록한다.

`tests/treatment-consents.test.ts`, `scripts/verify-treatment-consents.ts`로 중복 등록·권한·게시 차단·변경 후 재검토·초안 재편집·복제 및 원본 보존·모바일 화면을 검증한다.

신설 7종을 합쳐 총 23종. 닥터플랜·멤버십은 개별 시술 동의를 대체하지 않는 이용 안내다.

원문의 일괄 책임 면제, 횟수별 고정 환불률, 자동 소멸, 모든 환자에게 같은 시술 간격/회복기간을 적용하는 문구는 그대로 옮기지 않았다. 병원별 계약 조건·정산 근거는 별도 검토 항목으로 남긴다. 리팟 드레싱의 일률적인 장기 미교환/덧붙이기도 기본 지침으로 확정하지 않았다.

이소트레티노인 임신예방은 [식약처 환자용 안내](https://www.mfds.go.kr/brd/m_580/view.do?seq=76)를 참고했다. 검사 일정·제품별 허가사항·병원 절차는 의료진이 확인해야 한다. 일반 위험·사후관리 참고자료는 각 초안에 연결했다. 계약 정산 검토에는 [한국소비자원 선납 진료비 피해예방 안내](https://www.kca.go.kr/home/sub.do?menukey=4005&mode=view&no=1003881199)를 참고했다.

보완본도 모두 초안으로 등록하며 자동 게시하지 않는다. 미확정 표식은 빨간 배지·목록·미리보기 강조로 표시하고, 해결하지 않으면 서버에서도 게시를 차단한다. 초안 업그레이드는 새 버전을 만들어 기존 병원 수정 내용을 보존한다. 기존 수정 내용을 새 보완본에 자동 합성하지 않으므로 비교 검토 후 필요한 병원 문구를 반영한다.

## 검토 항목 작성 예시 (0.12.7)

각 빨간 검토 항목 아래에 ‘작성 방법’과 ‘작성 예시’를 표시한다. 연락처·진료시간·진료시간 외 대응, 21개 시술/치료 양식의 제품·장비·방법, 닥터플랜·멤버십의 이용기간·차감순서·양도·적용 범위·정산을 구분한다. 병원이 추가한 항목에는 일반 작성 가이드를 제공한다.

예시는 작성 형식을 보여주는 별도 도움말이며 본문에 자동 삽입되거나 환자 동의서에 출력되지 않는다. 예시의 `[병원 확인: …]`은 실제 병원 기준으로 바꿔야 하며, 미완성 예시를 수동으로 붙여 넣어도 기존 게시 검증에서 차단한다. 이 변경으로 기존 초안·게시본·서명을 수정하거나 초안을 재등록하지 않는다.

0.12.8에서 사용자가 제공한 병원 안내 이미지의 병원명·대표전화·주소·월~금/토요일 진료시간을 연락처 예시에 채웠다. 이미지에 명시되지 않은 일요일·공휴일, 야간 대응과 계약 접수·정산 운영 기준은 계속 `[병원 확인: …]`으로 남긴다.

## 연락처 확정 및 원문 재대조 (0.12.9)

2026-09-30 사용자가 연락처·진료시간·평일 점심시간·일요일/공휴일 및 진료시간 외 상담 미운영을 확정했다. 해당 연락처 표식만 확정 문구로 치환한다. 새 양식의 기본 본문과 도움말에 반영하고, 운영에서는 최신 미게시 임상 초안 13개에 적용했다. 사용자가 이미 같은 정보를 작성·게시한 8개 양식, 이전 초안 16개, 계약 안내 2개 및 서명은 보존했다. 시술별 검토 표식은 유지한다.

병원 원문 11개 양식군의 번호 항목 87개를 실제 운영 최신 양식과 다시 대조했다. 반영 17개, 축약·부분 반영 48개, 누락 7개, 확인 항목 전환 9개, 표현 수정·제외 6개다. 복합 항목 단위의 분류이며 부분 반영에도 빠진 세부 주의사항이 있다. 이전 보완에서 음주·흡연, 세안·화장, 사우나·수영 등 행동 안내가 개별 안내 문구로 지나치게 축약됐다. 기존의 ‘반영’ 표는 원문 주의사항 전체가 반영됐다는 의미로 해석하면 안 된다.

이번 변경은 확정 연락처만 수정한다. 원문 대조 결과는 로컬 감사 CSV로 제공하며 의료 주의사항 전체를 다시 작성하거나 자동 게시하지 않는다. 원문의 구체적인 기간은 제품·시술 기준 검토가 필요하고, 책임 면제·정액 환불 문구는 그대로 복원하지 않는다. 원문 전체와 운영 양식 본문은 공개 저장소에 포함하지 않는다.

## 누락 주의사항 보완 (0.12.10 / 2026-09-30.3)

사용자의 미게시·게시본 보완 요청에 따라 `consentPrecautions.ts`에 시술별 행동·위험·경과 설명을 추가했다. 원문의 구체적인 기간·횟수와 계약 운영 기준은 별도 검토 도움말에 보존하고, 환자 본문에는 해당 시술에 맞는 행동 안내 및 ‘보완 주의사항의 적용·기간·회복 경과’ 확인 항목을 넣는다. 확정 연락처는 그대로 유지한다.

업그레이드는 병원 작성 본문과 확인란·상품 연결을 유지한다. 직전 병원 보완본의 미게시 초안은 같은 양식에서 업데이트하며, 게시본은 다음 버전의 개정 초안으로 만든다. 옛 초안과 게시본·서명은 덮어쓰지 않는다. 양식 23종 중 해당 원문이 없는 정맥 주사는 주의사항을 추가하지 않고 라이브러리 버전만 갱신한다. 임상 20종과 계약 안내 2종에 보완 본문 또는 원문 기준 확인을 추가한다. 자동 게시하지 않으며 미확정 항목 해결과 병원 검토 후 게시해야 새 서명에 사용할 수 있다.

## 세부 내용 본문 복원 (0.12.11 / 2026-09-30.4)

이전 보완은 기간·횟수를 도움말로 이동해 실제 본문이 부족했다. `consentDetailedPrecautions.ts`는 원문의 87개 번호 항목과 5개 공통 항목을 식별하여 해당 양식 본문에 구체적 행동·수치·경과를 보존한다. 보톡스 전용 효과 시점을 지방분해에 옮기거나 바늘 자국 안내를 HIFU에 적용하지 않는다. 양식별 대조 목록에서 표현 변경 이유와 현재 본문 포함 여부를 확인한다. 원문 수치는 병원 기존 기준의 초안이며 임상적으로 검증된 보편적 기준이라고 표시하지 않는다.

현재 .3 초안을 갱신하므로 게시본에서 만든 개정 초안을 불필요하게 또 복제하지 않는다. 자동 생성된 이전 보완 문단과 정확하게 일치할 때만 교체하며 사용자 편집 문구는 삭제하지 않는다. 최신 개정안을 기본 표시하고 과거 게시본·초안은 이력 보기를 통해 확인한다. 기존 서명과 게시본의 내용·연결은 유지한다.

## 서명 없는 양식 삭제 (0.12.12)

관리자·임원은 설정 → 동의서 양식에서 받은 서명 0건인 저장된 초안 또는 게시본을 선택해 ‘양식 영구삭제’를 누른다. 이전 게시본은 ‘이전 초안·게시본 함께 보기’에서 찾는다. 확인창에서 취소할 수 있으며 서명 기록이 있으면 서버에서도 거부한다. 파생 개정 초안과 서명은 보존한다. 삭제 변경은 동기화와 전체 변경 기록 복구에 반영되며, 과거 암호화 백업 파일의 소급 파기는 포함하지 않는다.
