# 0.12.1 · 초진설문지 환자 검색과 등록

새 환자 등록에서 초진설문지의 이름·전화번호로 검색하고 이름, 성별, 생년월일, 전화번호, 주소, 내원경로를 불러옵니다. 기존 코디메이트 환자가 있으면 해당 환자를 열 수 있으며 동일 설문지의 중복 등록을 방지합니다. 최초 1회 관리자가 초진설문지 OneDrive 폴더와 관리자 비밀번호를 설정합니다.

0.12.0의 항목별 할인·임의 가격·공통 사유와 의사 직접 의견 기능을 함께 포함합니다. 초진설문지 원본에는 쓰지 않으며 주민등록번호 원문·병력·서명·동의서 본문은 복사하지 않습니다. 기존 업무 자료의 스키마 변경은 없습니다.

검증: 통합 자동 테스트 42개 파일 278개 통과, TypeScript/Vite 빌드. 합성 브라우저에서 연결 설정·검색·자동 입력·등록·삭제된 기록 오류·기존 환자 열기를 태블릿/모바일 화면으로 확인했습니다. 실제 OneDrive 연동은 관리자가 최초 설정한 후 이용합니다. 물리 Android 설치 검증은 별도입니다.
