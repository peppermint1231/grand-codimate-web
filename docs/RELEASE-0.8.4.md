# 0.8.4 · 공유 폴더 링크와 단가표 단축키

단가표 관리 → 폴더 목록 수정에서 원본 폴더를 선택하고 이동·복사·링크할 위치를 고른 뒤 **폴더 링크**를 누릅니다. 같은 SSOT 안의 여러 위치에 같은 원본 링크를 만들 수 있습니다. 폴더 저장을 눌러야 게시 SSOT와 추천기에 반영됩니다.

- 링크는 상품을 복제하지 않습니다. 원본 이름·색상·하위 폴더·상품·옵션·가격 변경을 함께 사용합니다. 링크를 펼쳐 하위 분류를 탐색할 수 있습니다.
- 링크 및 연결된 하위 폴더의 연결 아이콘을 누르면 원본 위치로 이동하고 상위 폴더를 펼칩니다. 이름·색상·폴더 이동은 원본에서 수정합니다.
- 링크에 상품을 추가하거나 옮기면 원본 폴더에 저장되어 모든 링크에 반영됩니다. 상담·추천기는 링크가 있는 분류에서도 같은 상품을 찾으며 목록과 장바구니의 상품 ID는 중복 생성하지 않습니다.
- 링크 삭제는 바로가기만 지웁니다. 원본을 삭제/덮어쓰면 하위 상품과 해당 원본을 참조하는 링크가 제거되며 영향받는 링크 수를 경고합니다. 폴더 병합은 원본 링크를 합쳐진 대상에 연결합니다.
- 일반 폴더 복사는 기존처럼 별도 상품을 만듭니다. 복사 범위 내부에 원본과 링크가 함께 있으면 복사한 원본에 연결하고, 범위 밖 원본을 참조하는 링크는 그대로 유지합니다.
- 순환 참조, 존재하지 않는 원본과 3단계 세부 폴더 깊이 초과를 서버에서도 차단합니다. 저장 이력·복원과 편집 되돌리기/다시 실행에 링크가 함께 보존됩니다.

단축키 안내는 단가표 관리 상단에서 펼쳐 확인합니다. Ctrl은 Mac에서 Cmd로 사용할 수 있습니다.

| 동작 | 단축키 |
|---|---|
| 폴더 저장 / 상품 초안 저장 | Ctrl+S |
| 되돌리기 / 다시 실행 | Ctrl+Z / Ctrl+Shift+Z 또는 Ctrl+Y |
| 폴더 이름 변경 | F2 |
| 폴더 복사 / 잘라내기 | Ctrl+C / Ctrl+X |
| 대상 폴더 안으로 붙여넣기 | Ctrl+V |
| 대상 폴더 안에 링크 붙여넣기 | Ctrl+Alt+V |
| 폴더 삭제 확인 | Delete |
| 현재 상품 목록 전체 선택 | Ctrl+A |

폴더 명령은 편집 모드에서 폴더 목록에 초점이 있을 때 동작하며, 복사 후 대상 폴더를 선택합니다. 폴더 클립보드는 현재 단가표 편집 안에서 사용합니다. 상품 전체 선택은 상품 목록에서 동작합니다. 입력칸의 일반 복사·붙여넣기·전체 선택은 유지됩니다. Ctrl+S는 게시 전 상품 초안을 저장하며 판매 반영은 별도 검증 후 게시가 필요합니다.

검증: 119개 자동 테스트, 브라우저 링크 생성/원본 이동/연결된 하위 분류/상품 공유/추천기 중복 방지/삭제 보호/단축키/되돌리기/모바일 검사. `tests/catalog-folder-links.test.ts`, `scripts/verify-catalog-links-084.ts` 참고.
