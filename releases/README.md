# Android 설치 파일

[코디메이트 0.4.0 APK 다운로드](https://raw.githubusercontent.com/peppermint1231/grand-codimate-web/main/releases/codimate-0.4.0.apk)

Android 7.0 이상 · versionCode 6 · 기존 앱과 동일 서명. 안드로이드 기기의 브라우저에서 다운로드한 뒤 다운로드 목록에서 APK를 엽니다.

APK는 웹 정적 파일(public/dist)과 분리해 앱 빌드에 이전 APK가 중복 포함되지 않도록 합니다. 빌드 증거와 기능 설명은 docs/RELEASE-0.4.0.md를 참고하세요.

0.2.1 이상에서는 시작 시 새 버전을 확인합니다. 0.2.0은 상단 업데이트 버튼을 이용합니다. 업데이트 후 한 번 로그인하면 30일 로그인 유지가 활성화됩니다.
