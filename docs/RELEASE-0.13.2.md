# 0.13.2 · 홈페이지 SSOT 완전 동기화

홈페이지 갱신은 현재 홈페이지에 게시된 상품만으로 새 버전을 구성한다. 홈페이지에서 사라진 상품, 중복 원본, 수동 추가 상품은 최신 목록에서 제거하고 상품명·설명·가격·정가·기간·포스터를 원문 기준으로 맞춘다. 상품/옵션 ID와 직접 배치한 폴더는 유지하며, 비어 있는 자동 생성 폴더를 정리한다. 과거 단가표와 상담·견적 기록, 미용 SSOT는 보존한다.

갱신 미리보기에서 제거 수와 활성화 가능/미완료 수·사유를 표시한다. ‘동기화·활성화 후 게시’는 갱신, 검토완료, 판매 활성화와 게시를 한 명령으로 처리한다. ‘동기화·활성화 초안 저장’으로 게시 전 보관할 수도 있다. 확인된 홈페이지 가격·부가세를 사용하고, 미표기 VAT는 사용자가 지정한 기본값인 부가세 별도로 처리하고 필요하면 화면에서 정책을 변경할 수 있다. 가격 미확정·원문 파싱 이슈·기간 종료/시작 전 상품은 사유를 남기고 비활성으로 유지한다. 미표기 VAT에 일괄 정책을 선택하면 해당 정책을 적용하며, 항목별 확인을 선택하면 이전 검토 결정을 유지한다.

검증: 48개 파일/315개 테스트, TypeScript·웹 빌드, PC(1440)·태블릿(768)·모바일(390) 브라우저에서 동기화·이전 상품 제거·VAT 선택·즉시 게시·재갱신·초안 저장을 확인했다. 서명 APK 코드 55. 실제 Android 기기 설치 검사는 수행하지 않았다.

운영 반영 완료: 0.13.2 웹·APK 배포 후 홈페이지 현재 상품 417개로 동기화·전체 활성화·게시했다. 이전 목록 645개에서 홈페이지 미게시 228개를 제외했다. 미표기 VAT 47개는 사용자가 지정한 부가세 별도로 적용했으며 미완료 0개, 서버 대기 0건이다. 업무 명령은 1회였고 이전 단가표 버전과 그 외 업무 데이터는 동일함을 확인했다. 운영 브라우저에서도 417개 전체 활성·미검토 0개 및 미용 503개 유지, 3개 화면 너비를 확인했다. 배포 파일 48개·공개 APK 해시가 로컬 빌드와 일치한다. 전체 검증 기록: `artifacts/deployment-0.13.2.json`.
