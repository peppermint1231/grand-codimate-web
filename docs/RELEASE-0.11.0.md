# 0.11.0 — 기기 저장·상세 통계·견적 디자인

## 사용 방법

- **빠른 상담 저장:** 로그인 화면의 ‘병원 기기에서 오프라인 보관 사용’을 열고 암호화 보관과 기기 암호를 설정한다. 보류 상담의 저장 버튼은 사진·변경 내용을 이 기기에 보관한 뒤 전송한다. 상단에 기기 저장 / 전송 대기 / 전송 중을 구분한다. 다른 기기에서는 서버 전송 완료 후 보인다. 앱 종료·브라우저 중단 중에는 전송이 보장되지 않으며, 다시 열어 기기 보관을 해제하면 대기 자료를 이어 보낸다. 기기 저장소를 지우면 미전송 자료를 잃을 수 있다. 수납·환불·상담 확정은 서버 확인 후 반영한다.
- **충돌 복구:** 다른 직원이 먼저 저장했거나 권한이 바뀌면 자동 덮어쓰기 대신 ‘복구 자료’에 내 변경을 남긴다. 최신 서버 자료와 비교한다. 업로드와 저장 요청에는 고유 ID를 사용해 재시도 중 중복 기록을 막는다.
- **견적 디자인:** 03 견적서의 출력 디자인에서 ‘그랜드 시그니처’ 또는 ‘클래식 네이비’를 고른다. 선택한 기기의 PDF/JPG/환자 인쇄에 적용된다. 환자용 동의·서명과 7일 QR 링크, 정가·상품 할인·추가 할인·공급가액·VAT 표시를 유지한다.
- **전액 수납/환불:** 환자 상세 → 수납·환불 → 금액 기록에서 전액을 체크한다. 수납은 해당 상담 미수 잔액, 환불은 선택한 원수납의 미환불 잔액이다. 원수납을 바꾸면 전액도 다시 계산한다. 서버 확인 중 잔액이 달라지면 다시 확인하도록 막는다.
- **통계:** 직원 성과 / 환자·마케팅으로 나누고 기간·직원·미용/보험/이벤트를 필터링한다. 직원별 성과와 분야별 강점, 월별 추이, 금액 지표, 환자 분포·유입경로·재상담 코호트를 제공한다. 각 탭의 Excel은 용도에 맞는 별도 시트로 만든다.
- **인센티브:** 직원 통계의 시뮬레이션을 펼쳐 실수납 / 수납 / 계약금액과 기본 지급률, 직원·분야별 개별 비율을 지정한다. 3%는 예시이며 실제 지급을 확정하지 않는다. 음수 환불 이월을 포함하거나 분야별 0원 하한을 설정할 수 있다. 기기 보관이 열려 있으면 설정도 암호화 보관한다.
- **LLM 해석:** ‘통계 해석 프롬프트’를 열고 목적을 적은 뒤 복사하거나 텍스트 파일로 저장한다. 환자별 신원은 제외하고 직원 이름은 별칭으로 바꾼다. 작은 환자 분포는 5명 미만으로 표현한다. 코드가 문안을 만들며 외부 LLM 호출·자동 전송은 하지 않는다. 내보내기에는 통계 열람 권한도 필요하다.

## 기존 대기 기능

- 환자 검색은 서버에서 30명씩 반환한다. 상담·수납별로 묶은 조회용 메모리 인덱스를 사용하고 변경 시 갱신한다. 연결이 안 되면 기기에 이미 있는 자료로 검색한다. 초기 임상 자료는 아직 전체 상태에 포함되며, 단가표 원본과 이력 원문은 필요한 화면에서 따로 읽는다.
- 로그인 전 촬영 사진을 이 기기에 암호화 보관한다. 같은 기기의 촬영 화면에서 복구할 수 있다. 상담에 연결한 사진은 서버 저장 확인 후 임시 보관에서 정리한다. 이는 로그인 전 공용 촬영 영역이며 직원별 비공개 보관함은 아니다.
- 환자 메모 수정 시 이전 내용·작성자·수정자를 보존하고 펼쳐 확인한다. 도입 전 과거 편집 내용은 소급 생성하지 않는다.
- 단가표 상품에 패키지 구성·횟수·기간, 멤버십 이용금액·추가 혜택·안내를 구조화한다. 기존 설명과 함께 새 상담에 복사한다. 자동 회차 차감·포인트 회계는 포함하지 않는다.
- 단가표 게시 전에 기존 게시본과 변경 목록 및 시험 장바구니를 확인한다. 미확정 단가·VAT를 임의 확정하지 않는다.
- 설정에 관리자 인계와 조회 기록을 추가했다. 인계는 현재 관리자 비밀번호와 사유를 확인하고 원본 보관 후 적용한다. 환자·상담 상세·통계 열람과 인계를 암호화 기록하고 OneDrive `_codimate/access`에 순차 보관한다. 기록은 도입 이후부터 생성된다.
- 7.8MB를 넘는 사진·문서는 최대 25MB 원본을 나누어 전송하고 확인된 위치에서 이어 보낸다. 업로드 세션 만료 시 새 세션에서 원본을 다시 전송한다. 기존 파일을 덮어쓰지 않는다.
- OneDrive 재구축은 원본을 4개씩 확인하고 위치를 저장한다. 도중에 화면을 닫거나 오류가 나도 다시 이어갈 수 있다. 확인 중에는 서버 변경을 제한하며, 확인 완료 후 별도 ‘복구 완료’에서만 현재 자료를 교체한다. 취소하면 현재 자료를 유지한다. 복구 후 원본 관리자 계정으로 다시 로그인한다.

## 지표 해석

상담·계약은 상담 작성일(한국시간)과 현재 결과 상태로 집계하며 취소·중간상담은 상담 수에서 제외한다. 전환율은 성공/(성공+실패)로 보류를 제외한다. 현금 흐름은 처리일과 원래 담당 상담자 기준이며, 입력 직원의 매출로 세지 않는다. 정정 취소된 기록은 제외하고 취소·중간상담에 실제 발생한 수납·환불은 포함한다.

한 상담의 여러 분야에는 견적 금액 비율로 계약·수납·환불을 배분한다. 이 분야별 배분은 추정치이며 원 단위 합계를 보존한다. 미수는 종료일 기준 현재 유효 계약 잔액이다. 첫 상담/재상담은 선택한 직원·단가표 범위에서 첫 상담일이 조회 기간 안/이전인지로 구분한다. 30·90일 재상담률은 관찰기간이 지난 신규 환자만 분모에 넣는다. 실제 내원율이나 광고 기여도를 뜻하지 않는다. 환자당 누적 실수납은 해당 환자의 종료일 이전 전체 수납·환불 기준이다.

## 검증 범위

자동 테스트와 합성 자료 브라우저 시험으로 변경 응답·충돌/재시도·권한·분할 전송·복구 원본 오류·관리자 보존·통계 합계와 Excel·동의/서명·QR·출력 페이지를 확인한다. PC/태블릿/휴대폰 해상도에서 가로 넘침과 주요 흐름을 확인한다. 실제 병원 자료는 조회로만 확인하며 시험 수납·환불·복구·계정 인계를 운영 서버에 실행하지 않는다.

물리 Android 기기·카메라·펜·프린터가 연결되지 않아 실기기 검증은 미완료다. 병원 인센티브율·미확정 단가/VAT·동의 문안은 실제 운영 기준으로 확정해야 하며 이번 배포에서 대신 확정하지 않는다.
