# 0.3.0 — 환자 관리·로그인 유지·사진 제스처

Android versionCode 5. 기존 서명 키를 유지하며, 배포 정보 갱신 후 0.2.1 앱에서 자동 업데이트를 안내합니다. 0.2.0은 상단 업데이트 버튼으로 확인합니다.

## 변경된 사용 흐름

1. 상단 왼쪽 **메뉴 접기 / 펼치기** 버튼으로 사이드바 전체를 숨기거나 표시합니다. 선택은 기기에 저장됩니다.
2. 환자목록 행에 **수정 / 삭제** 버튼을 추가했습니다. 수정은 환자정보 편집 권한, 삭제·복원·병합은 관리자 권한을 따릅니다. 삭제는 목록에서 숨기는 방식이며 상담·수납·사진을 지우지 않습니다. **삭제된 환자** 필터에서 복원합니다.
3. 이름+생년월일 또는 전화번호가 같은 환자에 **중복 의심 · 비교**가 표시됩니다. **중복 의심만** 필터도 지원합니다. 후보 기록을 열거나, 남길 환자를 선택하고 사유를 적어 병합합니다. 같은 연락처를 사용하는 가족은 자동 병합하지 않습니다.
4. 15분 무활동 자동 로그아웃을 제거했습니다. 새 로그인은 30일간 유지되며 앱 재시작 시 복원됩니다. 웹은 HttpOnly 쿠키, Android는 기존 Keystore 암호화 기능으로 감싼 토큰을 사용합니다. 비밀번호를 저장하지 않습니다. 직접 로그아웃·계정 비활성화·서버 세션 만료 시에는 다시 로그인합니다. 기존 APK에서 넘어온 경우 한 번 로그인해야 저장됩니다.
5. 로그인 유지와 오프라인 초안 보관은 별개입니다. 앱이 재시작돼 보관 키가 잠기면 **설정 → 이 기기의 오프라인 보관 → 기기 보관 잠금 해제·설정**에서 기존 보관 암호로 대기 자료를 열 수 있습니다. 직원 계정도 이 개인 기기 설정은 사용할 수 있습니다.
6. 썸네일에는 사진과 반투명 **✎ 편집 / ℹ 정보 / ⠿ 이동** 버튼만 표시합니다. 이름·촬영 시각·출처·선택 상태·주석 개수는 ℹ에서 확인합니다. 비교 사진 아래 설명도 사진 위 버튼으로 정리했습니다.
7. 도구 사용 중에도 두 손가락으로 **핀치 확대·축소와 이동**이 됩니다. 두 번째 손가락이 닿으면 아직 확정하지 않은 획·지우기·텍스트 이동을 취소하고 화면 조작으로 전환합니다. 모든 손가락을 뗀 뒤에만 새 획을 시작하므로 한 손가락을 먼저 떼도 잔여 획이 생기지 않습니다.
8. 글자는 사진에서 위치를 누르고 **텍스트 내용 → 글자 적용**으로 추가합니다. **글자(T) 또는 선택(V)** 도구로 박스를 끌어 이동하고 오른쪽 아래 손잡이로 확대하면 글자 크기도 함께 커집니다. 글자 도구에서 기존 박스를 선택해 내용·폰트·크기를 다시 적용할 수 있습니다. 다른 작성자의 주석 편집 제한은 유지합니다.
9. 폰트는 고딕·고운 명조·고정폭·개구 손글씨·주아 둥근체·나눔 펜글씨를 제공합니다. 추가 한글 폰트는 앱에 포함해 오프라인에서도 사용합니다. 폰트 파일은 고정 원본과 SHA-256으로 빌드 시 검증하며 라이선스를 동봉합니다.
10. **스탬프(S)**에서 이모지 24종을 선택해 사진에 놓습니다. **선택(V)** 도구로 이동·크기 조절이 가능합니다. Google Noto Emoji 원본 SVG를 포함해 PC·Android와 출력물에서 동일하게 렌더링합니다. SVG 출처·라이선스는 `public/stamps/README.txt`, `LICENSE.txt`에 있습니다.
11. 좌 90° / 우 90° 다음의 **0° 원래 회전**은 촬영 원본 방향으로 복귀합니다. 회전 값만 바꾸며 주석·자르기를 삭제하지 않습니다.
12. 사진·장바구니 비율 슬라이더를 제거했습니다. 가운데 구분선을 끌어 조절하고, 키보드로는 구분선에 초점을 두고 방향키를 사용합니다. 세로 화면은 사진 영역 높이, 가로 화면은 너비를 조절합니다.

## 데이터 보존과 호환성

- 병합은 기존 상담·메모·수납의 환자 연결과 리비전을 함께 갱신합니다. 이전 화면의 저장은 충돌로 처리하여 병합 결과를 오래된 자료로 덮어쓰지 않습니다. 대상 환자도 최신 리비전을 검사합니다.
- 원본 사진·주석·수납 ID를 유지합니다. 이미 OneDrive에 있던 사진을 삭제하거나 물리적으로 이동하지 않으며, 병합 후 상담 JSON은 남긴 환자의 폴더에 기존 파일 경로를 참조해 기록합니다. 중복 수납을 자동으로 합산 제거하지 않습니다.
- 기존 텍스트 주석도 읽고 이동할 수 있습니다. 신규 텍스트·스탬프는 박스 치수와 글자 크기를 저장합니다. 새 주석 도구를 편집하는 기기는 0.3.0으로 업데이트하세요.

## 제스처 참고 자료

포인터 ID별 추적과 다중 터치 전환은 [Android 다중 터치 가이드](https://developer.android.com/develop/ui/views/touch-and-input/gestures/multi) 및 [드래그·확대 가이드](https://developer.android.com/develop/ui/views/touch-and-input/gestures/scale)를 참고했습니다. 웹 구현은 [W3C Pointer Events](https://www.w3.org/TR/pointerevents/)의 포인터 캡처·취소와 `touch-action`에 맞춰 처리합니다. Noto 이모지의 원본은 [Google Noto Emoji](https://github.com/googlefonts/noto-emoji)입니다.

## 확인한 범위

- 자동 테스트 46개: 삭제/복원과 권한, 병합 후 연결·리비전 보존, 중복 후보, 텍스트/스탬프 직렬화·범위 검사, 박스 확대·히트 테스트, 핀치 중심 유지, 30일 세션과 로그아웃 폐기 등.
- PC/세로 브라우저: 목록 수정·삭제·복원·병합, 메뉴 상태 저장, 재접속/20분 무활동 로그인 유지, 간결한 썸네일, 정보 보기, 텍스트 이동/확대, 스탬프, CDP 실제 터치 이벤트로 핀치 시 잔여 획 없음, 회전 초기화, 가로·세로 구분선 드래그, 저장 후 재열람.
- Android 로그인 브리지 모의 시험: 암호화 저장 호출, 쿠키 없이 토큰 복원, 명시적 로그아웃 시 삭제. 실제 암호화는 기존 Android Keystore 구현을 사용하며 실기기 전환은 추가 확인이 필요합니다.
- 기존 5장 사진 비교·중간/연장상담·PDF 출력 브라우저 회귀 통과.
- 실기기 백그라운드/프로세스 종료·복귀와 실제 병원 OneDrive 병합 저장은 테스트 환자로 확인해야 합니다.

## 사용자 빠른 체크

- [ ] 업데이트 후 한 번 로그인 → 다른 앱으로 이동 → 다시 들어와도 로그인 유지.
- [ ] 앱을 완전히 종료하고 다시 열어 로그인 복원 확인.
- [ ] 메뉴 접기/펼치기 후 사진 화면 공간 확인.
- [ ] 테스트 환자 목록에서 수정 → 삭제 → 삭제된 환자 필터 → 복원.
- [ ] 같은 전화번호의 테스트 환자 둘을 비교하고 남길 환자 선택 → 병합 → 상담·수납·사진 확인.
- [ ] 썸네일 ℹ에서 정보 확인, 썸네일 선택·순서 이동 확인.
- [ ] 펜으로 그리다가 두 손가락 확대/축소·이동 → 한 손가락부터 떼어도 선이 생기지 않는지 확인.
- [ ] 글자 입력 → 박스 이동/크기 조절 → 다른 폰트 적용 → 저장·재열람.
- [ ] 스탬프 추가 → 이동/확대 → PDF 출력에서 모양 확인.
- [ ] 사진 회전 후 0° 복귀, 가운데 구분선으로 가로·세로 비율 조절.
