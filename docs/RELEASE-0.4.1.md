# 코디메이트 0.4.1 — 사진 편집 유실 방지

Android versionCode 7. 기존 0.4.0과 같은 서명 키로 업데이트합니다.

- 처음 자동으로 열린 사진을 편집한 뒤 선택을 해제하거나 순서를 변경할 때, 편집 대상이 바뀌면 미저장 편집 확인을 표시합니다.
- 취소하면 사진 선택·순서와 편집 내용이 유지됩니다. 버리기를 승인하면 다른 사진으로 이동합니다.
- **사진 편집 저장 → 상담 저장** 방식은 유지합니다. 상담 저장까지 눌러야 다시 열었을 때 변경이 남습니다.
- 로그인 복원 시험은 현재 배포 버전을 기준으로 Android 정보를 모의합니다.

## 설치

[0.4.1 APK 다운로드](https://raw.githubusercontent.com/peppermint1231/grand-codimate-web/main/releases/codimate-0.4.1.apk)

기존 앱을 삭제하지 않고 위에 설치합니다. 0.2.1 이상 앱에서는 새 버전 안내로도 설치할 수 있습니다.

## 검증

51개 자동 테스트, 타입 검사와 웹 빌드, 사진 선택 해제·순서 변경 시 취소/버리기 회귀 및 로그인 복원 브라우저 시험을 통과한 수정입니다. APK는 서명·기존 인증서 일치·버전·내장 웹 파일 일치를 검증합니다. 실제 Android 시스템 동작과 병원 OneDrive 검증 범위는 기존 0.4.0 인계와 같습니다.
