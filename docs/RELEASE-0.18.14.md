# 0.18.14 — 도로명 주소와 동 단위 통계 연결

- 춘천 동·읍·면만 입력한 주소와 우편번호·춘천시 생략·띄어쓰기 변형을 통계 지역으로 인식한다. 이관 자료 비교에서 36개 주소를 추가 인식했고, 기존에 인식하던 주소의 누락은 없었다.
- 관리자 설정 → 연결·복구 → 주소 자동 연결에서 카카오 로컬 REST API 키를 연결하면 기존·신규 도로명 주소를 지번 주소의 법정동·읍·면에 자동 연결한다. 원래 환자 주소는 유지한다.
- 조회는 도로명·건물번호·시군구가 일치하는 결과만 사용한다. 주소가 불완전하거나 여러 동으로 해석되면 확인 필요로 남긴다. 키를 연결하지 않은 상태에서는 외부 조회를 하지 않는다.
- 외부 서비스에는 이름·연락처·상세 동호수를 보내지 않는다. 키와 조회 대기 주소는 서버에서 암호화한다. 동일 건물 조회 결과를 재사용하고, 기존 자료와 조회 결과 적용은 제한된 분량으로 나누어 처리한다. 외부 조회는 상담 저장 대기열 밖에서 실행한다.
- 자동 테스트 493개 통과. 암호화·접근 권한·도로명 일치·동명이인 지역·조회 오류·주소 수정 중 결과 도착·원본 보존을 검증했다. Android 0.18.14 (84).

운영 연결 전에는 도로명 자동 변환이 완료되지 않는다. 관리자가 조회 키를 입력해야 하며, 조회 실패와 불명확한 주소는 통계 비교에서 계속 제외한다.
