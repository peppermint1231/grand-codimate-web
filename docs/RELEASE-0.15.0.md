# 0.15.0 — 연장상담·수납 동선·상담자·등급 혜택

- 연장상담에서 현재 판매 중인 상품은 최신 단가로, 삭제·비활성·기간 종료·상담가격 입력으로 바뀐 상품은 이전 상담의 가격·부가세를 서버 스냅샷으로 불러옵니다. 이전 단가 적용 안내를 장바구니에 표시하며, 이전 할인은 초기화합니다. 임의 가격으로 저장했던 이전 항목은 당시 실제 단가를 기준으로 합니다. 단가표 구분·버전 위조는 계속 차단합니다.
- 환자목록의 등급을 색상·테두리로 강조하고 VIP는 금색 별 배지로 표시합니다. 모바일에서도 바로 보이도록 환자 이름 옆에도 표시합니다.
- 환자 상담이력의 대표사진 아래에 상담자 이름과 변경 메뉴가 표시됩니다. 전체 상담이력과 상담 상세에서도 상담자를 확인·변경합니다. 본인 또는 관리자만 활성 직원에게 인계할 수 있으며 변경 사유와 이력을 남깁니다. 성과 집계는 현재 상담자로 귀속하고 수납 입력자·의견 요청 작성자는 유지합니다. 미저장 상담은 저장 후 인계합니다.
- 상담이력 미수납 배지는 해당 상담이 선택된 수납·환불 화면으로 이동합니다. 수납 입력란을 먼저 배치하고 미수납 상담을 상단에 표시합니다. 선택 시 잔여 금액이 입력되며 확정은 별도 버튼으로 합니다.
- 여러 의사를 체크해 같은 의견을 한 번에 요청합니다. 유효하지 않은 수신자가 있으면 전체를 저장하지 않으며, 선택 중복을 제거합니다. 의사마다 별도의 요청·답변·읽음 상태를 유지합니다.
- 설정 → 환자 등급·세부 혜택에서 등급별 최초 달성·생일·기간별 이용 달성·소개 포인트, 이용금액 기준, 집계 개월 수, 포인트 유효 개월 수, 기타 안내를 설정합니다. 새 일반 등급의 자동 혜택은 기본 비활성입니다. VIP 운영 설정과 VIP 등급의 혜택·기준금액은 같은 정책에 반영됩니다.
- 기간은 등급 달성일 기준 개월 단위이며 기간별 한 번 보상합니다. 이미 보상한 구간과 겹치는 집계기간으로 변경해도 추가 보상하지 않습니다. VIP는 영구 유지하고 기존 적립을 환불 사유로 회수하지 않습니다. 다른 등급은 현재 적용되는 등급의 혜택을 지급합니다.
- 기존 적립 금액·유효기간은 유지하고 변경된 규칙은 이후 적립에 적용합니다. 0개월은 무기한입니다. 유효기간이 가까운 포인트부터 사용하고, 반환에도 원래 적립의 유효기간을 유지합니다. 만료일 당일까지 사용 가능하며 만료된 미사용분만 이력으로 소멸 처리합니다. 기존 VIP 100,000P는 계속 무기한입니다.

자동 테스트에는 이전 메뉴 연장·저장, 상담자 변경 권한·동시수정, 다중 수신자 원자성, 기간별 혜택·소멸·원래 유효기간 반환·기간 변경 중복 방지를 포함합니다. PC 1440 / 태블릿 768 / 모바일 390에서 등급 강조, 혜택 저장, 미수납 바로가기, 인계, 이전 메뉴 연장, 의사 2명 동시 요청 흐름을 확인했습니다.
