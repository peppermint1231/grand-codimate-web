# 0.18.1 — 상담자 캘린더 색상 구분

계정 ID의 임의 색상 계산 때문에 여러 상담자가 비슷한 초록색으로 표시되던 문제를 개선했습니다. 파랑·주황·보라·청록·분홍 등 서로 다른 16색 팔레트를 계정 목록에 중복 없이 배정합니다. 계정 목록 순서와 활성 여부가 바뀌어도 같은 계정 집합의 색상은 유지됩니다. 계정 추가/삭제로 전체 집합이 바뀌면 재배정될 수 있으며 16개를 초과하면 팔레트를 반복합니다. 상담자 이름과 상태 문구는 계속 함께 표시합니다.

미배정은 밝은 중립색과 점선 테두리, 취소는 회색으로 구분합니다. 이름 배지 크기와 간격을 늘렸습니다. 완료 일정은 해당 상담자 색상을 어둡게 표시합니다.

검증: 전체 424개 테스트 및 웹 빌드 통과. 1440/768/390px 브라우저에서 16개 계정의 색상 중복 없음, 이름 배지와 일정 색상 일치, 배지 줄바꿈 및 화면 너비 준수 확인. 모든 팔레트의 흰 글자 대비는 최소 4.92:1입니다.
