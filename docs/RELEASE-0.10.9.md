# 0.10.9 — 상담 화면과 터치 조작 개선

환자 상세의 활동 타임라인은 최신 기록부터 20개씩 표시합니다. 목록 안에서 스크롤하고 이전·다음 버튼으로 페이지를 이동합니다.

상담 탭에서 시술 선택과 장바구니 사이의 가로 막대를 위아래로 끌면 높이를 조절할 수 있습니다. 키보드는 막대에 초점을 둔 뒤 위·아래 화살표, Home/End를 사용하세요. 초기화 버튼 또는 더블클릭으로 기본 비율로 돌아갑니다. 비율은 기기에 저장됩니다. 두 목록은 각각 스크롤합니다.

상담 메모와 의사 의견 요청은 상담 사진 아래로 이동했습니다. 상단의 사진·시술 선택·장바구니·메모·의견 요청 바로가기로 원하는 영역에 바로 이동할 수 있습니다.

휴대폰에서는 주 메뉴가 화면 하단에 표시됩니다. 태블릿 가로 화면은 간결한 옆 메뉴, 세로·좁은 화면은 세로 배치를 사용합니다. 터치 조작 영역과 입력 글자 크기를 확보했습니다.

터치 화면의 페이지 맨 위에서 빈 영역을 아래로 충분히 당긴 뒤 놓으면 최신 자료를 불러옵니다. 페이지를 재시작하지 않아 작성 중인 상담 메모·장바구니·의견 요청은 유지됩니다. 사진 조작·입력칸·목록 내부 스크롤·크기 조절은 새로고침과 구분하며, 처리 중이거나 미전송 변경이 있으면 제스처를 실행하지 않습니다.
