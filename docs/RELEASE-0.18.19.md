# 0.18.19 — 따라 하는 사용법 · 연결 복구

## 사용법

사이드바에 실무자 17개·관리자 13개 과정의 사용법을 추가했습니다. 총 119개의 따라 하기 단계에 실행 위치·확인 결과·복습 문제를 제공합니다. 목차와 본문 검색, 학습 진도, 실제 화면 열기·돌아오기, 모바일 목차 이동을 지원합니다. 실제 자료를 바꾸지 않는 체크·문제 풀이와 운영 화면 이동을 구분합니다.

새 안내·수정된 안내는 과정별 내용/연결 소스 개정 정보를 이전 확인 기록과 비교해 표시합니다. 변경된 안내만 보기와 버전·변경 설명을 제공합니다. 안내 확인과 학습 완료는 별개이며, 개정된 과정은 기존 완료 상태를 그대로 적용하지 않습니다. 진도는 계정별로 현재 기기에 저장되며 환자 정보나 서버 쓰기를 사용하지 않습니다.

기능 소스 101개 및 도메인 명령 44개를 안내에 연결했습니다. 새 TSX 구성요소·명령 또는 연결된 소스 변경이 안내 검토에 반영되지 않으면 pretest/prebuild가 실패합니다. 기능 변경 시 개발자가 안내 본문과 변경 설명을 갱신하고 검토한 뒤 `npm run guide:sync`로 버전·지문을 생성합니다. 정적 검사만으로 기능의 의미를 이해해 새 문장을 작성하는 것은 아니며, `AGENTS.md`에 동반 수정 의무를 명시했습니다. 사용자가 사용법을 읽거나 변경 배지를 확인할 때 LLM 호출은 없습니다.

검증: 1440/800/390px 브라우저에서 검색, 과정 전환, 단계 확인·문제 풀이, 새로고침 후 진도 복원, 이전 버전 완료 무효화와 수정 배지, 화면 이동·복귀, 관리자 실행 권한을 확인했습니다. 별도 복제 작업공간에서 새 기능 누락과 오래된 안내가 실제로 검사를 실패시키는 것을 확인했습니다.

## 연결 복구


운영 서버가 일시적으로 HTML 오류 응답을 반환하면 로그인 복원이 즉시 중단되고 재연결 화면에 머물던 동작을 보완했습니다. 2026-10-12 점검 당시 운영 서버의 로그인·workspace 조회는 정상 응답했으며, 최초 장애의 공급자 측 원인은 재현되지 않았습니다.

- 읽기 전용 workspace 복원만 최대 3회, 요청별 15초 제한과 1초/3초 대기 후 재시도합니다. 화면에 재연결 횟수를 표시하고 이후에는 수동 재연결을 제공합니다.
- 정상 JSON 401만 로그인 만료로 처리합니다. 중간 서버의 HTML 401이나 HTML 5xx 응답은 로그인 정보를 지우지 않습니다.
- 인증·권한 오류, 읽기 폭주 차단(429), 일일 저장소 한도는 자동 재시도하지 않습니다. 저장·수납 등 쓰기 요청에는 재시도를 추가하지 않습니다.
- Durable Object가 응답 전에 실패해도 외부 Worker에서 JSON 503 및 태블릿 앱 CORS 헤더를 반환합니다. 환자·수납 데이터 변경이나 데이터베이스 초기화는 없습니다.

검증: 517개 자동 테스트와 TypeScript/Vite 빌드. 실제 운영 workspace 응답을 사용한 브라우저 오류 주입에서 502 두 번 후 자동 복원, 지속 오류 시 3회 후 중지, JSON 401 시 로그인 화면 이동을 확인했습니다.
