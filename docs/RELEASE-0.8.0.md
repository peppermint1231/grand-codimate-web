# 0.8.0 · 세 단가표와 맞춤 시술 찾기

미용·보험·이벤트 SSOT을 각각 관리하고, 상담에서는 세 단가표의 상품을 한 장바구니에 담습니다. 각 항목에 단가표 구분·게시 버전을 저장하므로 과거 상담 가격을 유지하고 연장 상담에서는 해당 단가표의 최신 게시 가격을 확인합니다.

단가표 관리의 고정 상위 분류는 첨부 추천기의 13개 고민과 보험용 ‘피부·손발톱 진료’입니다. 그 아래 세부 폴더를 3단계까지 만들 수 있습니다. 상품을 여러 개 선택한 뒤 이동 손잡이를 폴더로 끌거나 이동할 폴더를 선택합니다. 폴더의 자기 하위 이동·중복 이름·깊이 초과를 차단합니다. 상품별 모든 옵션·가격·부가세가 목록에 표시됩니다. 게시본을 복제해 수정하고 초안 저장 → 검증 후 게시 순으로 적용합니다.

홈과 사이드 메뉴의 **맞춤 시술 찾기**에서 환자용 주소와 접수함을 엽니다.

- 환자용 웹: https://grand-codimate.peppermint-3.workers.dev/discover
- 원내 태블릿: https://grand-codimate.peppermint-3.workers.dev/discover?kiosk=1
- 홈페이지: 위 주소로 링크하거나 메뉴에 표시되는 iframe 코드를 사용합니다.

환자는 고민·세부 질문·관심 옵션을 고르고 이름·연락처를 입력합니다. 생년월일·성별·주소는 선택 입력입니다. 개인정보와 건강 관련 정보 동의를 각각 받고 접수합니다. 직원은 접수함에서 기존 환자에 연결하거나 신규 등록에 필요한 정보를 보완하여 상담을 시작합니다. 검토 완료·판매 중인 옵션은 현재 게시 가격으로 담고 미확정 항목은 메모로 전달합니다. 고민별 상담 후보를 보여주는 기능이며 진단이나 시술 효과를 판정하지 않습니다.

공개 목록은 게시본에서 ‘맞춤 시술 찾기에 표시’를 켠 상품만 제공합니다. 내부 설명·원본 시트·검토 메모는 제외하고, 가격·부가세 검토가 끝나지 않은 상품은 ‘상담 후 비용 확인’으로 표시합니다. 원본 초안의 의학적 효과 문구와 하드코딩한 가격은 사용하지 않습니다.

접수는 별도의 암호화 파일로 OneDrive `코디메이트/_codimate/inquiries`에 저장합니다. OneDrive 저장 실패 시 완료로 표시하지 않으며 재시도는 같은 접수번호로 처리합니다. 미연결 접수의 보관 기간은 30일입니다. 서버의 정기 정리 작업은 만료된 접수 파일·행을 지우며, 상담 연결 후에는 접수함의 개인정보를 비우고 동의 출처를 상담 기록에 보관합니다. 원내 태블릿 주소는 3분 미입력 시 입력을 초기화하고 브라우저 저장소에 입력 정보를 남기지 않습니다.

검증: 자동 테스트 104개, TypeScript·웹 빌드, 공개 접수→직원 상담 연결·세 단가표 혼합 견적·3단계 폴더·다중 상품 드래그·저장 재열람·모바일 넘침·태블릿 초기화 브라우저 검증. 접수의 원격 저장/상담 저장 실패 후 재시도, 암호화 복구, 보관 만료도 검증합니다. 기존 사진 편집·글자 크기 슬라이더·투명도 표시·상단 저장·손잡이 이동/스크롤 회귀 검증을 통과했습니다. 실물 Android 기기 설치 검증은 별도입니다.

기존 미용 원본에서 명시적으로 이벤트인 옵션만 분리하며, 보험 원본이 없는 항목은 가격 미확정·비활성 초안으로 작성합니다. 가격과 VAT는 항목별 확인 후 활성화합니다. 실제 단가·환자·첨부 파일은 공개 소스 저장소에 포함하지 않습니다.
