# 0.8.2 · 단가표 목록과 상품 검토 개선

- 기본 폴더 너비에서도 제목과 수정 버튼의 글자가 쪼개지지 않습니다. 폭이 좁으면 버튼 전체가 다음 줄로 이동합니다.
- 폴더 아이콘을 제거하고 지정 색상을 폴더 이름에 적용합니다. 기본 그린·블루·퍼플·로즈·앰버 프리셋과 직접 색상 선택을 제공합니다.
- 최상위 폴더는 배경과 굵은 글자, 하위 폴더는 단계별 들여쓰기와 연결선으로 구분합니다. 상품은 소속 분류별로 묶고 상품 제목과 옵션의 배경·굵기·들여쓰기를 구분합니다.
- 폴더 목록은 처음에 접힌 상태, 상품 옵션은 펼친 상태입니다. 각 목록의 모두 접기·모두 펼치기 버튼과 개별 펼침 버튼을 사용할 수 있습니다. 하위 폴더가 선택된 상태에서도 모두 접기가 동작합니다.
- 상품명 또는 검토 중 · 검토하기를 누르면 상품 편집 화면을 엽니다. 게시본은 수정용 초안을 만들어 바로 검토할 수 있습니다. 원본 근거·가격·부가세를 확인하고 검토 완료를 표시한 뒤 검토 내용 초안 저장을 누르세요. 상담·추천기에 반영하려면 검증 후 게시를 누릅니다.
- 폴더 편집 중에는 상품 상세 조회만 허용하며 폴더를 저장하거나 취소한 뒤 상품을 수정할 수 있습니다. 기존 게시본과 상담 가격 스냅샷은 유지합니다.

브라우저 검증: 기본/최소 너비의 제목과 버튼, 텍스트 색상·5개 프리셋·저장 동기화, 접기/펼치기 기본값과 선택한 하위 폴더 접기, 게시본 상품 검토·초안 저장·재열람·게시, 태블릿/휴대폰 화면 넘침 없음. `scripts/verify-catalog-ui-082.ts` 참고.
