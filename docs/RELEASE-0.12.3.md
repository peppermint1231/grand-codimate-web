# 0.12.3 · 시술동의서 초안과 검토 화면

시술동의서 양식은 등록 기능만 있고 사전 작성된 문구와 저장 후 수정 화면이 없어 검토를 시작하기 어려웠다. 현재 단가표의 시술 방식을 기준으로 16종의 병원 검토용 초안을 작성하고, 설정 → 동의서 양식에서 등록·검색·본문/확인 항목 편집·미리보기·초안 저장·검토 후 게시·게시본 복제를 제공한다.

초안에 시술 목적·대안·부작용·사후 관리·필수 확인 항목을 포함한다. 제품·장비의 국내 허가 기준과 병원 연락처 등 확정되지 않은 부분은 `[병원 확인: …]`으로 표시하며 남아 있으면 서버에서 게시를 거절한다. 수정하면 검토 확인이 해제되고, 게시 시 담당 계정·시각을 기록한다. 기존 게시본과 서명 원문은 보존하며 복제는 새 버전의 초안을 만든다. 기본 초안 재등록은 병원이 편집한 내용을 덮어쓰지 않는다.

[양식 범위·검토 방법](TREATMENT-CONSENTS.md). FDA·AAD·ASPS·NHS 참고 자료는 편집 화면에 양식별 링크로 제공한다. 해외 자료를 국내 허가로 취급하거나 초안을 병원의 확정 동의서로 자동 게시하지 않는다. 복합 상품의 자동 매칭은 없으며 필요한 게시 양식을 상담에서 각각 선택한다.

검증: 43개 파일 284개 자동 테스트와 웹 빌드. 합성 브라우저 1440/768/390px에서 16종 등록, 저장 후 재편집, 미확정 문구·검토 확인에 따른 게시 제한, 변경 후 재검토, 게시본 복제 및 원본 보존, 새 양식 취소, 가로 넘침과 브라우저 오류 없음 확인. 초안 서명 거절 및 게시 원문 서명 스냅샷 테스트 포함. 물리 Android·프린터는 미검증.

배포 완료: 웹·APK 0.12.3/versionCode43, 원격 `d536fe68563702f6c49be3d6eab01a14e0365238`. GitHub 검사·Cloudflare 배포 성공, 운영 정적 파일 48개 및 공개 APK 다운로드 해시 일치. 기존 서명 인증서 유지. 운영에 16종을 초안으로 등록했고 게시 0건·미전송 0건이다. 등록 전후 동의서/감사 이벤트 외 모든 업무 상태의 해시가 동일하다. 검증 기록은 artifacts/consent-drafts-*.json.
