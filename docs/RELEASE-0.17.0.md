# 0.17.0 — 환자용 맞춤 시술 찾기 개편

- 제공된 추천기 초안의 아이보리·브라운 색상과 고민 → 상세 상태 → 추천 흐름을 반영했습니다. 큰 선택 카드, 큰 글씨, 잘 모르겠어요, 관심 시술 담기, 간단한 상담 접수를 제공합니다.
- 홈페이지·미용·보험 탭을 제거하고 공개된 상품을 통합 추천합니다. 기존 판매 활성·환자 공개 설정은 유지하며, 공개가 꺼진 상품을 자동 공개하지 않습니다.
- IVNT·닥터플랜·멤버십·미분류·관리 등 운영 폴더는 고민에서 제외합니다. 상품의 적응증·구성·옵션과 기존 고민 분류, 초안의 추천 시술명을 조합해 환자 고민에 연결합니다. 적응증 없는 일반 멤버십은 임의 추천하지 않습니다.
- 선택한 상세 상태와 관련 없는 시술은 제외하고, 적합한 상품이 없을 때도 고민만으로 상담 접수할 수 있습니다. 가격이 같은 동일 구성은 중복을 줄이고 서로 다른 가격·구성은 유지합니다.
- 환자 접수에는 원래 단가표·버전·상품·옵션 식별자를 유지합니다. 직원 접수 화면과 기존 접수 데이터 호환성을 유지했습니다.
- 공용 태블릿은 kiosk=1 주소에서 3분 미사용 시 초기화합니다. 초기화 이전의 늦은 응답이 환자 정보를 복원하지 못하도록 차단했습니다.
- 전체 411개 테스트, TypeScript 검사와 프로덕션 빌드 통과. 1440/768/390/320px 브라우저에서 세 단가표 통합·관심 담기·상담 접수·큰 글씨·가로 넘침·태블릿 초기화 검증 완료.
