# 0.18.9 — 베가스 환자 이관과 지역 통계

- 관리자 전용 `patient.import`: 최대 250명씩 검증·저장하고 정상 OneDrive 암호화 커밋에 기록한다. 같은 작업 재시도는 중복 생성하지 않으며 기존 환자는 덮어쓰지 않는다.
- 대량 이관 환자는 전체 작업 화면에서 제외하고 서버 검색(30명씩), 환자 선택 시 개별 조회한다. 상담·수납·노트·등급 계정에 연결된 환자는 해당 작업 자료에 포함한다.
- 원래 주소와 통계용 동·읍·면을 분리한다. 시군구가 생략되면 사용자 확인에 따라 춘천시 기준이며, 동을 확인할 수 없는 도로명 주소는 확인 필요로 남긴다. 원본에 동이 확인된 동일 도로·건물번호의 유일 매핑만 이관 시 활용한다.
- 환자목록 주소 확인 필터, 전체 환자 지역 그래프 및 환자 통계 Excel 시트, 참고용 이전 수납액·내원 이력을 추가한다. 기존 상담기간 통계와 전체 환자목록 통계를 구별한다.
- 주민등록번호 전체는 가져오기 스키마에서 받지 않는다. 생년월일·성별만 추출한다. 원본 누적 수납액은 참고정보와 VIP 자격 판정에 사용하며 매출 원장이나 직원 실적을 생성하지 않는다. 500만원 이상이면 VIP 최초 100,000포인트를 지급하고, 사용자 지정에 따라 연간 혜택 기준일은 이관일로 설정한다. 이전 누적액은 연간 이용금액에 합산하지 않는다.
- 동일 이름·생년월일에 서로 다른 연락처가 있는 기록 등은 확인 목록으로 보류한다. 원본/계획/실행 기록은 무시된 private 폴더에 보관하며 저장소에 환자 데이터를 게시하지 않는다.

검증: 기존 및 추가 테스트 460개 통과. 합성 환자 65,000명 검색 시험에서 초기 복호화·색인 약 12.6초, 이후 이름 검색 약 64ms, 증분 JS heap 약 51MB(로컬 Node 측정, 운영 환경과 다를 수 있음). APK 0.18.9 / 79.

상담 시술 검색은 입력·한글 조합을 별도 컴포넌트에서 처리하고 160ms 뒤 결과를 갱신한다. 분류 트리, 상품 검색 문구, 상담 변경 비교의 반복 계산을 메모이제이션한다.

검색 브라우저 검증: 1440/768/390px, 상품 2,000개에서 연속 입력 중 결과 목록 변경 0회, 입력 종료 후 정확한 1,000개 결과 표시, Chrome IME 조합 중 대기·조합 종료 후 갱신 확인.

운영 반영 확인(2026-10-08): PR #24 병합 및 Cloudflare 배포 성공. 웹 자산 48개와 공개 APK 해시 일치. 환자 64,980명 등록, VIP 40명에게 최초 포인트 합계 4,000,000점 지급. 기존 환자 정보·수납 원장 변경 없음, 저장 대기 0건. 원본 67,852행 중 기존 환자 일치 13행, 중복 추가 행 33행은 별도 생성하지 않았으며 동일인 확인이 필요한 2,826행은 보류했다. 확인 목록은 비공개 폴더에 보관한다.

가져온 주소 중 46,076명은 동·읍·면을 분류했고, 이 중 동일 도로·건물번호의 확정된 원본 매핑을 사용한 항목은 1,742명이다. 동 확인 필요 14,878명, 주소 미입력 4,026명은 추정하지 않고 별도로 표시한다. 운영 화면의 환자 검색·상세 조회를 PC·태블릿·모바일 크기에서 확인했다.
