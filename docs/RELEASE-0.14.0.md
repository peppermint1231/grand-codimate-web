# 0.14.0 — 영구 VIP · 포인트 · 친구 소개

환자 상세의 **VIP·포인트**에서 잔액, 인증 카드 발급 기록, 연간 실적, 지급·사용 이력을 확인합니다. 1P는 1원이며 유효기간이 없습니다. 수납·환불 화면의 방법에서 **VIP 포인트**를 선택해 사용하고, 포인트 결제 환불은 현금이 아닌 포인트로 반환합니다.

- 누적 기여매출 500만원 최초 달성 시 영구 VIP입니다. 과거 수납·환불 이력을 순서대로 재구성해 최초 달성일을 찾고, 승급 이후 환불이나 실적 감소로 강등하지 않습니다. 정정 취소한 원기록은 이력 재구성에서 제외합니다.
- 기존 VIP 포함 최초 100,000P, 생일마다 50,000P, 승급일 기준 각 1년 기간에 이용액 500만원 달성 시 100,000P를 기간별 한 번 적립합니다. 평년의 2월 29일 생일은 2월 28일 처리합니다.
- 신규 환자 등록의 **친구 소개**에서 기존 환자를 검색해 연결합니다. 새 환자의 첫 실제 수납 후 소개해 준 VIP에게 20,000P를 한 번 적립합니다. 등록만 하거나 포인트로만 결제하면 소개 혜택을 지급하지 않습니다.
- 환불·수납 정정·연간 실적 감소로 이미 적립한 혜택을 회수하지 않습니다. 새 연간 달성 여부는 해당 기간의 수납에서 연결된 환불을 뺀 금액으로 확인합니다.
- 도입 전 생일과 종료된 연간 기간의 혜택은 소급하지 않습니다. 현재 진행 중인 연간 기간에는 기존 수납 내역을 포함합니다. 최초 승급을 만든 수납까지는 연간 실적에 중복 산입하지 않습니다.
- 포인트 결제액은 미수금에서는 차감하되 현금 매출, 기여매출, 직원 실수납 실적·인센티브, VIP 달성 실적에는 중복 포함하지 않습니다.
- 관리자 설정의 **VIP 포인트 운영**에서 자동 지급과 향후 지급 금액을 설정합니다. 금액 정정 권한으로 사유를 기록한 수동 포인트 조정, 등급 지정 권한으로 카드 발급 기록이 가능합니다. 금액 열람이 없으면 포인트 자료를 반환하지 않습니다.
- 잔액을 덮어쓰지 않고 적립·사용·반환·조정 이력을 추가합니다. 수납과 포인트 변경을 같은 서버 작업으로 저장하고 OneDrive에 암호화하여 보관합니다. 명령 재시도와 서버의 한국시간 일별 자동 확인은 중복 지급을 막습니다. 환자 병합 시 중복 혜택만 정리합니다.

검증: 단위·저장 통합·통계 테스트 및 PC 1440 / 태블릿 768 / 모바일 390 너비에서 소개자 검색, 최초 지급, 카드 발급, 포인트 사용·반환, 운영 설정 저장을 확인했습니다. 실제 기기 카메라나 실물 카드 출력은 이번 변경에 포함되지 않습니다.
