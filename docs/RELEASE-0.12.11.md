# 0.12.11 · 동의서 세부 내용 본문 복원

0.12.10은 행동 안내를 보완했지만 구체적인 기간·횟수·경과를 도움말에만 남겨 환자 본문이 여전히 축약되어 있었다. 병원 원문의 번호 항목 87개와 공통 기록·계약·확인 조항 5개를 각각 연결해, 해당 시술의 본문에 상세 문장을 넣었다. 세부 기간은 기존 병원 기준의 초안임을 명시하며 실제 제품·부위별 적용을 검토한 후 게시한다.

쥬브젠의 접촉 1~3일·금연금주 1~2주·사우나수영 2~4주·마사지 1개월·효과 평가 4~12주, 보톡스의 세안 3~4시간·주름/근육 효과 시작 및 유지기간, 점 제거와 탈모 치료의 항목별 기간 등을 본문에서 확인할 수 있다. 리팟은 활동·수면·땀, 밴드 크기·덧붙임 조건, 각 세안 도구, 진피층 색소 잔여물, 단계별 색 변화까지 항목별로 작성했다. 숫자를 도움말에만 옮기는 방식은 중단했다.

동의서 편집 화면에 ‘원문 항목별 반영 내역’을 추가했다. 일반 반영과 표현 보완을 구분하고 바꾼 이유를 설명한다. 편집으로 대응 문장이 변경되면 ‘편집됨 · 본문 대조 필요’로 표시한다. 포괄 책임 면제·고정 환불률, 무조건 드레싱 장기 유지·덧붙임, 회복 보장은 그대로 확정하지 않는다. 원문의 해당 기준과 조정 이유는 누락하지 않고 대조표에서 확인할 수 있다. 원문 전체·실제 병원 편집 내용은 공개 저장소에 저장하지 않는다.

이전 자동 생성 보완 문단과 완전히 일치할 때만 상세 문단으로 교체한다. 병원이 수정한 문단은 보존하고 상세안을 추가한다. 현재 .3 개정 초안을 갱신하며 기존 게시본·서명은 유지한다. 목록은 최신 개정안 중심으로 표시하고 이전 초안·게시본은 함께 보기로 확인한다. 환자 서명에는 게시된 양식이 사용됨을 화면에 명시한다.

검증: 테스트 47개 파일·298개, 원본 추출 87개 ID와 상세 문장 간 전수 대응, 숫자 표기 정규화 후 숫자 누락 0건, 모든 대응 본문의 실제 양식 포함, 공통 5개 항목, 병원 편집 보존·정확한 자동 문단 교체·중복 실행·기존 게시본 보존 확인. 숫자 대조는 임상적 적합성 검증을 뜻하지 않는다.
