# 0.18.18 · 유입경로 복수 선택 집계

AI챗봇은 유지하고 '없음'은 현장 방문, 카카오는 기타에 합산한다. '네이버 블로그 · 지인 소개'와 같은 복수 선택 응답은 별도 조합 카테고리를 만들지 않고 각 경로에 한 명씩 포함한다. 한 응답에서 네이버 검색광고·플레이스를 함께 골랐다면 통합된 네이버 검색에 한 번만 집계한다. 빈 응답은 여전히 미입력으로 남는다.

누적 환자군, 기간별 상담, 연령·성별 교차 분석, Excel에 동일하게 적용했다. 응답 환자 수(중복 제외)와 경로 선택 건수(복수 선택 포함)를 구분해서 표시한다. 경로별 환자·상담·금액은 선택한 경로마다 연결하되 전체 환자 수와 매출 총계는 중복 없이 유지한다. 경로별 수치·금액을 전체 매출로 합산하면 안 된다는 설명을 화면·Excel·LLM 프롬프트 집계 기준에 추가했다.

과거 저장 집계 행에서 직접 분리하므로 환자 원본 수정이나 전체 스캔 없이 적용된다. Android 88 / 0.18.18.
