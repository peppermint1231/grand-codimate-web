# 0.18.12 — 조회 보호, 환자군 통합 분석, 추천기 설정

## 동작

- 환자 검색 색인과 중복·매출·지역 집계를 Durable Object SQLite에 저장한다. 최초 구축은 200~250명씩 진행하고 재시작 시 커서부터 이어간다. 이후에는 환자·상담·수납·등급 변경분만 갱신한다. 색인 준비 중 전체 환자 로드로 우회하지 않는다.
- 검색은 HMAC 문자 토큰의 FTS 구문 검색, 목록은 30명 페이지와 저장된 페이지 기준점을 사용한다. 전체 환자 행은 암호화되고 검색용 이름 정렬·집계 메타데이터는 같은 DB 내부에 저장된다.
- SQL cursor 읽기량을 요청별·분별로 기록한다. 읽기 급증 시 해당 조회를 429로 잠시 제한하고 로그인·저장 요청은 분별 조회 차단에서 제외한다. 관리자 설정의 조회 보호 화면에서 상태를 확인한다. 이 측정은 Cloudflare 청구량 전체와 같지 않으며 과금 상한을 보장하지 않는다.
- 통계 환자군 기본값: 코디메이트상담 / 베가스이관 / 초진설문지(미용) 활성, 초진설문지(진료) 비활성. 이름+연락처 일치 시 환자군 합집합에서 한 명으로 집계한다. 여러 설문 및 상담 전환도 중복하지 않는다.
- 등록 전 설문 제출자는 환자를 생성하지 않고 별도 통계 요약으로 포함한다. 연결된 원본의 consultType을 사용하며 미용+진료는 미용으로 분류한다. 구분 없는 설문은 추정하지 않고 제외 건수를 표시한다. 12건씩 재개 가능한 갱신, 원본 ETag 확인 및 삭제 반영을 지원한다. 서명·주민번호·병력은 통계 저장소에 보관하지 않는다. 첫 통계 화면에서 초기 갱신을 시작하며 이후 새 설문은 갱신 버튼으로 반영한다.
- 베가스 누적 수납액·최초/최근 방문·횟수·인구통계·지역을 누적 환자군 분석에 사용한다. 월별 수납·시술별 매출·직원 성과를 임의 생성하지 않는다.
- 코디메이트 상담은 연령·성별별 인기 카테고리, 유입경로, 성공률, 실수납을 비교한다. 전체 환자군 누적 분석과 기간별 실제 상담 분석을 구분한다. 환자 엑셀과 소수 표본을 제외하는 해석 프롬프트에 새 집계를 포함한다.
- 비중 도넛, 연령 막대, 연령×카테고리 히트맵, 클릭 가능한 월별 추이 및 모션 감소 설정을 지원한다.
- 추천기의 일반 피부증상 선택은 제거하고 손발톱 무좀만 남긴다. 추천기 설정에서 SSOT별 상품유형과 가격 공개를 설정한다. 비공개 가격은 공개 API의 옵션·이벤트 가격·설명에서도 가린다.

## 확인

- 자동 테스트 479개 통과(77개 파일), TypeScript·Vite 빌드 확인.
- 68,000행 DB에서 새 PatientDirectory 인스턴스가 원본 전체를 읽지 않고 30명 페이지만 조회하는 회귀 테스트.
- 단계별 색인 재개, 중복/보관 갱신, 조회 차단 복구, 권한과 금액 비공개, 미등록 설문 중복/삭제 반영 검증.
- 브라우저 1440 / 800 / 390px: 배지 필터, 그래프 클릭, 성별 필터, 모션·가로 넘침 확인.
- 배포 후 운영 색인 구축·설문 요약 갱신 및 기존 수납/VIP/포인트 보존 확인 예정.
