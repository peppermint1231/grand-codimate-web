# 0.18.15 — 번길 주소 인식 및 조회 완료 안내 수정

- `후석로 369번길 40 2층`과 `후석로369 번길40`을 `후석로369번길 40`으로 조회한다. 원본 주소를 유지하고 층·호수는 조회에 포함하지 않는다.
- 번호가 붙은 길 이름을 건물번호로 오인하지 않는다. `후석로 369번길`처럼 건물번호가 없는 주소는 임의로 동에 연결하지 않는다. 건물번호와 아파트 동 사이에 마침표가 들어간 표기도 처리한다.
- 주소 목록 점검, 외부 조회 대기, 통계 반영 중, 처리 종료를 구분한다. 자동 처리 종료가 모든 환자의 지역 연결 완료를 뜻하지 않는다고 명시한다.
- 관리자가 지정한 환자의 주소를 최대 200명씩 재점검할 수 있게 하여, 이전 해석이 달라지는 주소의 오래된 통계 지역도 원본 수정 없이 재계산한다.
- 이관 원본 전수 비교: 조회 대상 547개 추가, 기존 조회문 41개 수정, 건물번호 없는 주소 9개는 잘못된 조회 대상에서 제외. 이는 조회문 인식 결과이며 실제 동 연결 성공 수와 다르다.
- 자동 테스트 494개 및 타입 검사·프로덕션 빌드 통과. PC·태블릿·모바일에서 진행·종료 안내와 키 저장·해제 UI를 검증했다. Android 0.18.15 (85).
