# 코디메이트 0.7.0 — 중간·연장상담과 패키지 상태

Android versionCode 11. 기존 설치와 같은 서명 키를 사용합니다.

- 중간·연장상담 시작 전에 기준 상담의 종류·상태, 사진 수·열 배치, 이전 견적과 현재 게시 단가 견적을 확인합니다. 판매 중지·미검토 옵션은 시작 전에 안내합니다.
- 연장 견적은 게시된 SSOT 단가표에서 상품명·옵션·가격·과세 기준·단위·설명·구성을 가져옵니다. 수량은 유지하고 항목/전체 할인은 초기화합니다. 미리보기와 실제 생성은 같은 계산 함수를 사용합니다. 이전 시술 단위가 남던 문제를 수정했습니다.
- 이전 사진과 주석은 독립적으로 복사하고 비교 선택은 해제합니다. 기준 상담의 열 배치를 유지합니다. 중간상담의 편집·저장·완료가 원래 상담의 사진·견적·패키지 상태를 바꾸지 않습니다.
- 중간상담은 완료/중단으로 표시하고 시술 성공 건수에 포함하지 않습니다. 환자 상세에 시술 성공과 중간 완료 건수를 나누어 표시합니다.
- 연장 보류 중에는 기준 패키지를 유지합니다. 연장 확정은 기존 패키지를 완료하고 새 패키지를 진행 중으로 만들며, 연장 안 함은 해당 기준 패키지만 완료합니다. 다른 패키지와 미용·보험 상태는 독립적으로 유지합니다.
- 기준 상담이 취소되었거나 유효한 시술 상담이 아니면 연장 확정을 차단합니다. 생성/확정 시 화면에서 확인한 기준 상담의 버전을 검사해 다른 기기의 변경을 말없이 덮어쓰지 않습니다. 충돌 후 새로고침해 최신 상태를 확인하면 다시 확정할 수 있습니다.
- 신규 후속 상담에는 생성 시 기준 상담 버전도 보관합니다. 예전 앱이 이 상담을 확정할 때 버전을 보내지 않으면 보관된 버전으로 검사합니다. 기존 자료는 새 화면에서 확인한 버전으로 검사합니다.

검증: 신규 11개를 포함한 자동 테스트 74개, TypeScript·웹 빌드, `scripts/verify-followup-070.ts`의 브라우저 검증. 독립 사진 편집, 가격·단위·할인, 중간 완료, 동시 변경 409 충돌, 연장 확정/거절, 수동 상태 변경·재열람, 미용/보험 환자목록 표시, 가로·세로 화면을 확인했습니다. 실제 태블릿 설치와 병원 OneDrive 동작은 별도입니다.

SSOT 준비 상태: 저장 구조·관리자 수정 UI·초안 저장/게시·상담 연동은 구현되어 있습니다. 원본 Excel 29시트에서 만든 상품 494개·가격 1,043개 후보는 비공개 변환 초안입니다. 원본 전체를 운영 SSOT에 입력·검수·게시한 단계까지 완료한 것은 아니며, 후보 전체의 운영 등록·게시 여부는 별도 확인이 필요합니다. 다음 단가표 작업은 실제 관리 화면에서 이 후보를 검토·수정하도록 연결하고 저장→게시→상담 반영 흐름을 검증하는 것입니다.
