# 0.8.3 · 편집 되돌리기와 이력 선택 창

- 여러 상품을 선택해 이동 버튼으로 옮기거나 폴더에 드래그한 뒤에는 선택을 모두 해제합니다. 이동 실패 시 선택을 유지합니다.
- 폴더 편집 도구와 상품 편집 화면에 되돌리기·다시 실행을 추가했습니다. 폴더 생성/이름/색/이동/병합/삭제와 상품 이동/내용/옵션/가격 등 저장 전 변경을 되돌립니다. 되돌린 뒤 새로 수정하면 이전 다시 실행 항목은 지웁니다.
- 단축키: 되돌리기 Ctrl/Cmd+Z, 다시 실행 Ctrl/Cmd+Shift+Z 또는 Ctrl+Y. 같은 입력란에서 이어 입력한 내용은 묶어서 되돌립니다. 검색·붙여넣기 원문·적용 전 폴더 이름 입력은 기본 텍스트 편집 단축키를 유지합니다.
- 저장 전 편집은 최근 40단계까지 보관합니다. 저장·취소·단가표/버전 전환 시 편집 단계를 초기화하며 저장한 이전 시점은 수정 이력에서 복원합니다. 폴더 이름 적용이나 중복/삭제 선택이 진행 중이면 먼저 해당 동작을 마칩니다.
- 수정 이력 · 되돌리기는 버튼을 눌러야 별도 목록 창이 열립니다. 목록에서 저장 시점을 선택하면 변경 내용을 확인하고 전체 단가표를 복원할 수 있습니다. 이력이 늘어도 본문 카드 높이는 늘어나지 않습니다. 창 안에서 스크롤하며 닫기·Escape·앱 뒤로가기로 닫습니다.
- 저장하지 않은 편집이 있으면 이력 조회는 가능하지만 저장본 복원은 잠깁니다. 복원 완료 후 선택 창은 닫히며 복원 자체도 기존 저장 이력에 기록됩니다.

검증: 자동 테스트 113개, 버튼/드래그 다중 상품 이동 후 선택 해제, 폴더·상품 변경과 단축키/입력 묶음/다시 실행 분기/저장 후 초기화, 이력 선택·높이 제한·Escape/초점 복귀·모바일·복원 완료 브라우저 검증. `scripts/verify-catalog-undo-083.ts` 참고.
