# 0.10.0 — 홈페이지 미용·이벤트 통합 갱신

단가표 관리의 **미용 SSOT** 또는 **이벤트 SSOT**에서 **홈페이지 갱신**을 누릅니다. 홈페이지 전체 목록을 한 번 읽어 두 SSOT의 결과를 함께 보여줍니다. **미용·이벤트 갱신 초안 저장**으로 두 초안을 함께 저장한 뒤 각 SSOT에서 검토하고 게시합니다.

- 배너명·분류명·개별 상품명에 ‘이벤트’ 또는 ‘EVENT’가 있으면 이벤트, 나머지는 미용으로 구분합니다.
- 미용에 없는 상품은 최근 저장한 미용 SSOT의 대분류와 상품 배치를 기준으로 분류해 비활성 검토 후보로 추가합니다. 판단이 어려운 항목은 ‘미분류·검토 필요’에 둡니다.
- 기존 미용 가격·부가세·판매 상태·수동 폴더 배치는 유지합니다. 원문 가격/부가세 차이와 원문 변경은 상품의 ‘홈페이지 게시·가격 점검’에서 확인합니다.
- 두 SSOT의 하위 폴더에 같은 상태 색상을 적용합니다. 청록: 게시 확인, 회색: 홈페이지에서 제외, 보라: 미확인, 황토: 여러 상태가 혼합됨. 대분류 지정 색상은 유지합니다.
- 게시 여부는 마지막 갱신 기준입니다. 미확인은 이름/출처로 대응을 확인하지 못한 경우이며 홈페이지에 없다는 뜻은 아닙니다. 이벤트 기간 종료와 홈페이지 게시 여부는 별개입니다.
- 홈페이지에서 빠진 기존 미용 상품은 삭제/비활성화하지 않고 출처 상태를 표시합니다. 이벤트 대상에서 빠진 이벤트는 기존처럼 비활성화합니다. 일반 상품으로 전환되어 홈페이지에 계속 게시된 경우 실제 게시 상태는 청록색으로 표시합니다.
- 반복 갱신은 원본 상품 ID/저장된 연결을 사용합니다. 상품 이름을 수정해도 연결을 유지합니다. 포스터는 원본 URL로 표시합니다.
- 전체 조회 중 오류가 나면 저장하지 않습니다. 다른 기기가 미용 또는 이벤트 기준 단가표를 수정한 경우 통합 저장 전체를 거부하고 재조회하도록 안내합니다. 미용과 이벤트 수정 이력은 각각 남습니다.
- 수집·대조·분류는 코드로 실행하며 생성형 AI/API를 호출하지 않습니다.

기존 게시본과 추천기는 초안 저장만으로 변경되지 않습니다. 저장하지 않은 폴더/상품 편집이 있으면 먼저 저장하거나 취소해야 합니다. 보험 SSOT는 이 기능의 대상이 아닙니다.
