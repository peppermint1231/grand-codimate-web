# 0.10.5 — 사진별 의사 의견을 2열로 표시

사진별 답변 카드에서 파일명을 숨기고 왼쪽에 더 큰 사진과 번호, 오른쪽에 코멘트를 표시합니다. 상담상세와 의견 답변 작성 화면에 함께 적용하며 휴대폰에서도 2열을 유지합니다. 사진 전체가 보이도록 맞추고, 누르면 확대할 수 있습니다.

사진 번호의 자동 연동, 기본 접힘, 기존 코멘트와 연결 정보는 그대로 유지합니다. 이 변경은 표시 방식의 개선이며 기존 저장 자료를 변환하지 않습니다.

기존 자동 테스트 188개, 사진 지정/저장/읽음/재배치·제외·확대와 데스크톱/모바일의 2열 배치·사진 확대 크기·파일명 숨김을 확인했습니다.
