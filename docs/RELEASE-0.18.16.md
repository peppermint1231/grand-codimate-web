# 0.18.16 — 유입경로 통계 분류 통합

- 유입경로의 공백·숨은 공백 차이를 같은 항목으로 집계한다. 네이버 검색광고와 네이버 플레이스를 네이버 검색으로, 기존 환자를 재방문으로 통합한다. 네이버 예약·네이버 블로그는 각각 유지한다.
- 여러 경로를 함께 선택한 답변은 통합 후 같은 경로가 되면 하나로 줄이고, 서로 다른 경로는 조합으로 유지한다. 환자 한 명을 여러 경로에 중복 계산하지 않는다.
- 누적 환자군, 기간 내 상담환자, 연령·성별 교차 분석, Excel, 통계 해석 프롬프트에 공통 분류 기준을 적용한다. 원본 설문·환자 유입경로를 수정하지 않는다.
- 저장된 집계 행을 조회할 때 합치므로 환자 전체 재조회나 색인 재생성이 필요하지 않다. 총 환자 수·수납액을 유지한다.
- 497개 자동 테스트와 타입 검사·빌드 검증. 공백 변형, 복수 선택, 과거 집계 호환, 전환율 재계산, Excel의 통합 명칭·원본 보존을 확인한다. Android 0.18.16 (86).
