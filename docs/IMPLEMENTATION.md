# 코디메이트 구현·검증 현황

이 문서는 코드에 들어간 범위와 실제 운영 검증이 필요한 범위를 구분한다. 현재 산출물은 **병원 연결 전 통합 개발판**이며 운영 승인판이 아니다.

## 구현된 기능

- React/TypeScript 공통 UI, 가로·세로 상담 배치, 사진/상담/견적 탭, 환자 목록과 상세, 단가표 관리자, 통계, 계정별 권한 설정.
- 환자 등록·수정·검색, 중복 후보, 관리자 병합, 상담 당시 환자정보 보존, 메모·활동 이력.
- 환자별 계약·수납·환불·미수금, 원수납 연결 환불, 정정 기록, 중복 작업 차단, 자동 등급과 관리자 고정.
- 시술 옵션 선택·장바구니·할인·부가세 공통 계산과 서버 재계산. 과거 견적 가격 보존.
- 전체 XLSX 29개 시트·3,760개 원본 셀 보존, 상품/가격 후보 변환, 관리자 옵션·가격·세금·설명·구성 편집, 표 편집·선택 가격 조정·여러 행 붙여넣기, 검토·초안·게시·복원용 복제.
- 게시 JSON에서 카테고리별 Excel 생성: 목차 링크, 숫자 가격, 색상, 제목행 고정, 인쇄 반복 제목. 통계 Excel은 별도.
- 사진 원본 업로드, 선별·회전·영역 자르기·확대·비교, 펜·화살표·사각형·타원·텍스트, 실행취소/다시실행, 주석 숨기기. 의사 주석은 작성자별로 보존.
- 병원용 한글 PDF, 환자용 JPG, 웹/Android 인쇄 연결. PDF에 상담·사진·의견·서명 기록 포함.
- 동의서 초안과 검토 후 게시, 확인 항목·전자서명·내용 해시, 내용 변경 뒤 재서명 검사.
- Workers/SQLite Durable Object 직렬 처리, 서버 검증, 암호화 저장, OneDrive 작업 원본 업로드 후 서버 완료 처리. 작업 ID와 원본 기반 재구축, 사진·계정 메타데이터 복구.
- 신뢰 기기 암호화 저장과 상담 초안, 오프라인 대기열/사진, 앱 셸 캐시, 자동 잠금. Android Keystore 추가 암호화·스크린샷 방지·백업 제외.
- Android 카메라/회전/인쇄/업데이트 설치 연결, SHA-256 검증. 관리자 APK 업데이트 메타데이터 게시.
- GitHub Actions 테스트/웹 빌드/수동 배포/서명 APK 빌드 정의.

## XLSX 변환 결과의 의미

원본 29개 시트를 모두 읽고 494개 상품 **후보**, 1,043개 가격 **후보**를 만들었다. 원본의 병합 셀은 대표 셀을 보존한다. `private/catalog-import.json`의 `references`에는 설명·회차 구성 등 가격표 외 내용도 보존된다.

이 숫자는 판매 상품 확정 수가 아니다. 불규칙한 표의 제목·상품·옵션·정가·이벤트가 관계를 자동으로 확정하지 않았다. 가져온 후보는 모두 비활성/검토 필요이며, 관리자가 원본과 비교한 뒤 옵션·부가세·가격 적용 관계를 확정해야 판매할 수 있다. 멤버십 포인트·복합 패키지의 구조화 및 원본 전수 의미 대조는 추가 정리가 필요하다. 검토초안 Excel은 운영 게시본이 아니다.

## 반드시 남은 운영 검증

- 실제 Microsoft 앱 등록, 개인 OneDrive 연결과 권한/토큰 만료/용량 부족/부분 업로드 시험.
- Cloudflare 계정·무료 플랜 설정·실제 배포 및 2대 태블릿+PC 동시 복구 시험. 무료 한도에 따른 실측 부하 시험.
- Android 실기기 카메라·Keystore·앱 종료/재부팅·회전·프린터·APK 업데이트 대기열 보존 시험.
- 실제 단가표 판매 옵션 검수, 충돌 가격 적용 관계, 보험 분류, 부가세 확정. 등급 기준 설정과 병원 동의서 승인.
- 기존 G마크 원본 확인과 날개 아이콘. 현재 기본 개발용 아이콘/임시 UI 심볼은 최종 병원 아이콘이 아니다.

## 계획 대비 아직 부족한 부분

- 초기 구현은 서버 자료 전체를 읽어 UI에서 검색·집계한다. 장기간 대량 자료용 서버 페이지 검색·통계 인덱스 최적화가 남아 있다.
- 자유 영역 자르기·분할선 드래그·내 주석 표시를 구현했다. 실제 펜/터치 태블릿에서 조작성을 검증해야 한다.
- 게스트 촬영분은 현재 창 메모리에 보관한다. 로그인 전 촬영의 영속 암호화 저장/복구는 미완성이다.
- 게시 전 상세 변경 비교/상담 미리보기, 관리자 인계 확정 UI, 구조화된 패키지·멤버십 안내 편집은 추가 구현 필요.
- 환자 담당자·날짜·상태 필터와 최근 상담 정렬을 제공한다. 수납/환불 고급 통계·인센티브 파일, 과거 메모 버전 조회 UI가 제한적이다.
- 변경 이력은 원본 커밋으로 보존되지만 조회 감사 UI 및 모든 경로의 감사 기록은 완성되지 않았다.
- OneDrive 저장 이름에는 재시도 충돌을 피하기 위한 짧은 업로드 ID가 항상 붙는다. 요청한 ‘충돌할 때만’ 규칙과 차이가 있다.
- 사진/PDF 업로드는 현재 파일당 8MB 제한이다. 대용량 업로드 세션과 장시간 재구축 작업 분할이 남아 있다.
- Android 저장소 별도 분리·공통 코드 커밋 고정 배포는 아래 안내 방식이며 실제 GitHub 원격 저장소에 게시하지 않았다.

## 검증 산출물

메인 인계 후 정본 탐색·암호문 변조 테스트를 수정하고 복구 회귀 테스트를 추가했다. 현재 **24개 자동 테스트**, TypeScript/Vite 빌드, 브라우저 사진 업로드/회전/PDF/JPG 시험, API 수납/환불/권한 및 PDF 직접 접근 차단 시험을 통과했다. `codimate-0.1.1.apk`(versionCode 2)는 최신 웹 빌드를 포함하며 기존 키와 같은 인증서의 release 서명·SHA-256 검증을 마쳤다. 0.1.0 APK도 보존했다. APK 설치 후의 실기기 시험은 별도다.

OneDrive 복구의 계정 보존·임시 관리자 제거·세션 만료·다른 복구키 거부는 가짜 원격 저장소로 시험했다. 실제 Cloudflare/OneDrive 검증은 아직 수행하지 않았다. `npm audit --omit=dev`에서 보고된 운영 의존성 취약점은 0건이다. 등록 절차는 [최초 연결 안내](CLOUD-SETUP.md)에 정리했다.

`npm run check`는 도메인·암호화·Excel 테스트와 TypeScript/Vite 빌드를 실행한다. `scripts/verify-browser.ts`는 개발 서버에서 가짜 환자로 로그인·등록·상담 저장·가로/세로·PDF/JPG·단가표 화면을 확인하며 `artifacts/`에 결과를 남긴다. 실제 원본/병원 정보/산출물/키는 Git에서 제외한다.
