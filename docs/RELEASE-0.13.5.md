# 0.13.5 · 홈페이지 원본 분류 보기

홈페이지 SSOT에서 ‘고민별 / 홈페이지 분류’를 전환할 수 있다. 단가표 관리의 왼쪽 폴더와 상품 목록, 상담의 시술 선택·카테고리·검색에 동일하게 적용한다. 홈페이지 보기는 원본 분류 → 배너 → 상품 순서이며, 다른 SSOT는 기존 분류를 유지한다.

원본 상품의 `webEvent.categoryName`, `eventId`, `eventName`에서 읽기 전용 폴더를 구성한다. 홈페이지 갱신으로 이 정보가 바뀌면 자동으로 새 분류를 보여준다. 상품을 복제하거나 수동 고민별 폴더를 덮어쓰지 않는다. 홈페이지 보기에서도 가격·판매·일괄 수정은 원본 상품에 적용되며, 홈페이지 폴더의 수동 편집·상품 이동은 제공하지 않는다. 분류를 전환하면 폴더 필터만 초기화하고 장바구니·가격·할인과 선택 상품은 유지한다.

현재 운영 홈페이지 SSOT 417개 상품 모두 원본 분류가 있다. 특별 이벤트, 색소/점 레이저, 여드름, 보톡스/윤곽주사, 리프팅, 실리프팅, 필러, 콜라겐 스킨부스터, 제모, 비만의 10개 분류를 확인했다. 별도 데이터 변경이나 홈페이지 가격 재수집은 필요 없다.

검증: 52개 파일·328개 테스트 및 웹 빌드. 브라우저 1440·768·390px에서 두 화면의 전환·필터와 장바구니 유지, 홈페이지 보기에서 일괄수정 후 원본 고민별 폴더 보존을 확인했다. 홈페이지 갱신으로 분류명·배너가 바뀌는 테스트를 포함한다. 서명 APK 코드 58, 실제 Android 기기 설치 검사는 수행하지 않았다.
