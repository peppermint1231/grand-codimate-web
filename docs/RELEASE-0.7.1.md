# 코디메이트 0.7.1 — SSOT 단가표 후보 검토 지원

Android versionCode 12. 기존 설치와 같은 서명 키를 사용합니다.

단가표의 부가세 미표기를 임의로 별도로 처리하지 않고 ‘확인 필요’로 보관합니다. 사용자가 포함·별도·면세를 정하기 전에는 해당 활성 상품의 게시와 견적 계산을 차단합니다. 원본 변환·새 옵션·부가세가 빠진 붙여넣기도 같은 기준입니다.

단가표 관리에 가격·구성·판매 조건, 부가세 미확정, 가격 미기재·범위 필터를 추가했습니다. 상품·설명·구성·옵션으로 검색하며, 옵션별 원본 셀·금액을 펼쳐 대조하고 계산 단위를 수정할 수 있습니다. Excel에도 부가세 확인 필요를 표시합니다.

원본 후보 검토는 비공개 자료로 완료했습니다. 29시트·3,760셀과 기존 가격 후보 1,043개를 대조해 505개 상품/안내, 1,027개 옵션으로 정리했습니다. 누락 고정 가격 21개 옵션 복원, 완전 중복 37개 병합, 멤버십 숫자 후보 15개를 안내 5개로 분리했습니다. 부가세 미확정 1,026개와 부가세 외 확인 조건이 있는 190개 옵션은 검토 필요로 남깁니다. 원본으로 결정할 수 없는 가격·회차·구성은 추정해 수정하지 않았습니다.

검토 초안과 출처 대조표·검토 Excel은 `private/`에 보관하며 공개 저장소에 포함하지 않습니다. 모든 상품은 비활성 초안입니다. 로컬 개발 환경에서 실제 초안 가져오기·저장·재열람, 조건 필터, 원본 근거, 부가세·단위 편집 후 저장, 세로 화면을 확인했습니다. 운영 OneDrive의 기존 단가표는 변경하지 않았습니다.

검증: 자동 테스트 79개, TypeScript·웹 빌드, 원본 파일과 모든 출처·금액 대조, 브라우저 검증. 검증 산출물은 `artifacts/catalog-review-verification.json`, `artifacts/catalog-review-browser.json`, `artifacts/apk-verification-0.7.1.txt`, `artifacts/deployment-0.7.1.json`입니다.
