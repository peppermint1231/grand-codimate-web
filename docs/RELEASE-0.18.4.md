# 0.18.4 — 추천 분류·캘린더·S펜 입력

추천 분류는 상품의 명시된 목적과 병원의 수동 폴더를 우선합니다. 크라이오·LED 재생관리·진정팩 등의 보조 구성을 근거로 관련 없는 고민을 추가하지 않습니다. 모공만으로 활성 여드름을, 리프토닝만으로 색소를, 제모 설명의 멜라닌이나 제모 부위인 이중턱을 색소·지방 치료로 연결하던 문제를 수정했습니다. LDM 모드는 공통 배너 설명의 다른 모드와 분리합니다. 각 연결은 수동 분류·명시 목적·기존 추천기 후보·병원 지정 중 근거를 기록하는 순수 함수로 계산하며 LLM 호출은 없습니다.

병원 확정: 닥터플랜 흉터는 패인/여드름 흉터와 큰 흉터 양쪽, MD 제품은 건조·보습과 피부염·장벽관리, LDM 약물침투 및 오투덤은 건조·보습과 장벽·예민 피부. 스킨 배리어 SOS는 기존 폴더를 보존하면서 추천에서는 건조·보습과 장벽·예민 피부로 한정합니다. 일반 그랜드 멤버십은 고민별 시술 추천에서 제외합니다. 몸 제모에 맞는 세부 고민도 추가했습니다.

926개 운영 상품 스냅샷(미용 499 / 보험 10 / 홈페이지 417)을 대상으로 전후 연결·근거·폴더 경로를 기록했습니다. 390개의 고민 연결이 변경됐고, 특정 시술 목적 없는 그랜드 멤버십 외 모든 상품에 고민 경로가 있습니다. 이는 규칙·데이터의 연결 검증이며 독립적인 임상 적응증 인증을 뜻하지 않습니다. 서로 다른 목적이 섞인 폴더는 해당 상품만 하위 공유 폴더로 묶고 다른 고민에 링크합니다. 수동 폴더·수동 링크·상품 ID·가격·옵션·활성 상태는 보존합니다. 생성 링크를 다음 분류의 입력으로 사용하지 않아 피드백 누적을 막습니다. 홈페이지 갱신에도 같은 링크 규칙을 적용하며 500폴더·깊이 제한으로 보류된 항목은 반환합니다. 반복 적용의 동일성, 순환 검사, 상업 데이터 보존을 검증했습니다. 보고서: `artifacts/recommendation-audit.html`, 기계 판독 자료: `artifacts/recommendation-audit.json`.

상담 캘린더에 월별·주별·일별 토글, 주별 기본값, 기간별 이전/다음과 좌우 스와이프·전환 애니메이션을 추가했습니다. 세로 스크롤 및 핀치 확대를 보존하고 스와이프 직후 상담 클릭을 차단합니다. 모바일 주별은 날짜별 목록, 월별은 압축 격자입니다. 공휴일·상담자 색상·완료 상태·상담 열기는 유지됩니다. 움직임 감소 설정에서는 애니메이션을 끕니다.

S펜: Chromium의 StylusTextSelector는 native button=2/32의 펜 DOWN을 텍스트 선택으로 소비합니다. 0.18.2의 32/64→2 변환이 이를 유발했습니다. 편집기 활성 lease가 있을 때만 버튼 마스크를 제거해 일반 펜 좌표로 전달하고 별도 네이티브 지우개 상태를 유지합니다. 편집기 외부 입력은 보존합니다. S펜 설정에서 기능 사용 여부를 기기에 저장하고, 갤럭시 설정 안내와 Android 설정 열기를 제공합니다. 시스템 에어 액션/에어 커맨드는 앱이 자동으로 변경했다고 표시하지 않습니다.

원인·설정 근거: [Chromium StylusTextSelector](https://github.com/chromium/chromium/blob/main/content/browser/renderer_host/input/stylus_text_selector.cc), [Samsung Air Command 버튼 설정](https://www.samsung.com/us/support/troubleshoot/TSG10002409/), [Samsung Air Actions 기본 활성화 제한](https://developer.samsung.com/galaxy-spen-remote/faq.html).
