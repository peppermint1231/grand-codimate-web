# 코디메이트 0.5.0 — 사진 편집·비교와 상담이력

Android versionCode 8. 기존 설치와 같은 서명 키를 사용합니다.

- **01. 사진**은 사진 선택·정리를 기본으로 표시합니다. 사진 편집을 누르면 전체화면 편집기가 열리고, 왼쪽 썸네일을 끌어 순서를 바꿀 수 있습니다. 편집 중인 사진과 미저장 편집은 순서를 바꿔도 유지됩니다.
- 사진 이동은 드래그 시작 시점의 고정된 위치를 기준으로 미리 표시하고 손을 놓을 때 한 번 적용합니다. 애니메이션 중 사진이 반복해서 서로 바뀌는 문제를 수정했습니다. 이동 손잡이에 포커스를 두고 방향키로도 순서를 바꿀 수 있습니다.
- 펜·화살표·사각형·원·텍스트 등 편집 도구는 아이콘으로 표시합니다. 도구 이름은 툴팁과 접근성 이름으로 제공합니다.
- 텍스트 설정창에서 현재 사진 위에 폰트·크기·색상·줄바꿈을 바로 미리 볼 수 있습니다. 미리보기와 저장 결과에 같은 사진 렌더러를 사용합니다.
- 비교 크게 보기에 **넓이맞춤 / 높이맞춤 / 전체화면맞춤**을 추가했습니다. 비교 사진을 직접 끌어 순서를 바꿀 수 있습니다. 전체화면맞춤은 사진 전체가 보이도록 맞추고, 넓이·높이맞춤은 선택한 방향을 채워 필요하면 스크롤합니다.
- **02. 상담**의 사진 영역은 비교 뷰어 중심으로 구성했습니다. 사진 추가·선택은 사진 탭에서, 필요할 때만 전체화면 편집기를 엽니다.
- 대표사진의 별 표시를 여러 장에 지정할 수 있습니다. 상담이력에는 대표사진을 각각 1:1 썸네일로 표시하며, 잘라내지 않고 전체 사진이 들어가도록 맞춥니다. 대표사진이 많으면 가로로 스크롤합니다.

사진 편집 저장은 해당 사진의 편집을 상담 작업에 반영합니다. 사진 순서·대표사진을 포함한 최종 변경 사항은 **상담 저장**으로 보관합니다.

검증: 자동 테스트 54개, TypeScript·Vite 빌드, Chromium 브라우저에서 가로·세로 사진/화면, 마우스·터치 순서 변경, 미저장 변경 보호, 텍스트 미리보기와 적용 결과의 픽셀 일치, 비교 맞춤, 저장 후 재진입, 여러 대표사진을 확인했습니다. 현재 UI 검증 스크립트는 `scripts/verify-workspace-050.ts`이며 이전 `verify-editor-040.ts`는 과거 화면 기준입니다. 실제 Android 태블릿의 설치·터치 동작 확인은 별도입니다.
